## 
> [边沁（Bentham）的圆形监狱（panopticon）]是一种重要机制，因为它使权力自动化并去个体化。权力的原则与其说在于个人，不如说在于对身体、表面、光线、凝视的某种协同分布；在于一种其内部机制产生个体被卷入其中的关系的安排。彰显君主过剩权力的仪式、典礼、标记都变得无用。有一种机制确保了不对称、不平衡、差异……圆形监狱是一台奇妙的机器，无论人们希望将其用于何种用途，它都能产生同质的权力效果。[^1]
>
> ……人工智能（Artificial Intelligence）的幻想：大脑变成世界，世界变成大脑，以便在没有身体的情况下运行，万无一失，自动化，非人化。过于智能，过于超级高效以至于不真实。事实上，自然智能和人工智能没有共存的空间。世界与其双重体也没有共存的空间。[^2]
## 引言 Introduction
自20世纪70年代以来，经由米歇尔·福柯（Michel Foucault）过滤的杰里米·边沁（Jeremy Bentham）的圆形监狱理论，一直主导着文化研究对监控（surveillance）的分析。让·鲍德里亚（Jean Baudrillard）的拟像（simulation）理论并未发挥如此重要的作用。两者之间的相互作用在很大程度上被忽视了，除了威廉·博加德（William Bogard）在其1996年的著作《监控的模拟》（*The Simulation of Surveillance*）中有所涉及。本文将博加德和鲍德里亚的思想带入高度监控、高度模拟的拉斯维加斯“长街”（"Strip"）环境中。

在题为“模拟监控（Simveillance）”的部分，我追溯了杰里米·边沁所设想的圆形监狱的虚构性质。我将福柯对圆形监狱理论的重新构想与边沁的原始理念进行了简要比较，并描述了鲍德里亚如何回应福柯的概念。然后，我审视了模拟（simulation）与监控之间的连接点（articulation），以及这种连接对传统时间/空间和凝视（gaze）观念的影响。

尽管长街的超真实（hyperreal）性质使得诸如内部/外部的典型区分变得问题重重，但炎热的沙漠太阳仍然能够在这种虚拟环境中彰显其物理现实。因此，我在拉斯维加斯的经历和观察被分为两部分——“阳光之下”（"Under the Sun"）和“远离阳光”（"Away from the Sun"）。这两部分描述了发生在长街和赌场内的主体/环境互动的本质。

最后，在题为“拉斯维加斯中的模拟监控”的部分，我阐述了拉斯维加斯长街的超真实世界如何使潜在易变且危险的主体变得静止、僵化、可预测和惰性。在现代赌场看似混乱的环境中，可能性似乎无穷无尽且不可预测，但实际上，主体面临的可能性和选择比他在南边十英里处贫瘠的沙漠中要少。
## 模拟监控 Simveillance
考虑到现代监控话语的圆形监狱起源，模拟理论未能发挥更大的理论作用令人惊讶。边沁在其关于圆形监狱的著作中指出了表象（appearance）和景观（spectacle）相对于时间世界的重要性。圆形监狱既是监狱的一部分，也是剧院的一部分；当有访客在场时，那些过度可见的囚犯要戴上可怕的面具，以象征性地代表他们所犯罪行的严重性。^[3] <a name="back3"></a> 边沁对推断性实体（inferential entities）——即只能通过观察其效果而非直接观察其形式来推断其存在的存在物——感兴趣。^[4] <a name="back4"></a> 他认为，“虚构”（fictions）——如魔鬼、幽灵、小妖精或法律的权力——可以对活生生的主体产生可衡量的影响。^[5] <a name="back5"></a> 取代实际狱警存在的窗户上的“暗点”（"dark spot"），根据鲍德里亚在其1981年著作《拟像与模拟》（*Simulacra and Simulation*）中创建的等级体系，可以被视为第三级拟像（third order simulation）——它将掩盖基本现实（basic reality）的缺席。^[6] <a name="back6"></a> 囚犯们将不会遭受真实狱警的日常暴力和身体约束；相反，他们将被一个虚构的幽灵所困扰。对边沁而言，狱警的缺席将比他的在场更为有效，因为可感知的（实际的）实体的有限性相对于推断的（虚拟的）实体的无限范围而言。

米歇尔·福柯在《规训与惩罚：监狱的诞生》（*Discipline & Punish: the Birth of the Prison*）中专门用一整章来阐述边沁的思想，从而使圆形监狱的理想得以在学术界复兴。福柯利用圆形监狱的结构来说明他自己关于规训（discipline）和权力（power）的理论；对福柯而言，圆形监狱（其透明的主体易于成为知识生产的目标）是权力流动的导管，而非闹鬼的剧院。福柯版本中的鬼故事是囚犯被内化的规训机制所占有；这并不被视为虚构，而是权力运作的真实产物。

在《忘记福柯》（*Forget Foucault*）中，鲍德里亚摒弃了透明的圆形监狱主体作为权力生产场所的概念：“[福柯的圆形监狱是]一种权威但已过时的理论。这种通过使客体化的凝视进行控制的理论，即使被粉碎成微观装置（micro-devices），也已经过时了。”^[7] <a name="back7"></a> 对鲍德里亚而言，福柯对权力的分析实际上是一种事后剖析（post-mortem）：“……如果最终可能如此明确地谈论权力……那是因为在某个时刻，所有这一切在此刻都已结束……如果福柯关于权力对我们说得如此之好……仅仅是因为权力已死，那会怎样？”^[8] <a name="back8"></a> 由于未能认识到圆形监狱结构——以及权力本身——的虚构性质，福柯的理论失败了，尽管是令人印象深刻地失败了。要完全理解现代监控，必须处理并面对模拟。

监控机器的一个主要功能是使主体透明化——以便看到“表面另一侧”（"the other side of the surface"）的东西。^[9] <a name="back9"></a> 模拟技术通过有效地摧毁表面来实现这一点。模拟监控（或模拟监控）设备并不让观察者真正看到主体；相反，它创建了与*真实*（real）世界相对应的*超真实*（hyperreal）世界。在20世纪之交，亨利·柏格森（Henri Bergson）主张区分虚拟世界和实际世界，声称虚拟永远无法达到与实际同等的地位：
> 即使一个城镇的所有照片，从所有可能的视角拍摄，无限地相互补充，它们也永远不会等同于我们在其中行走的实体城镇……从某个特定视角拍摄的表征……与拍摄对象的原始状态相比，将永远是不完美的。……但是绝对（the absolute），作为对象而非其表征，作为原物而非其翻译，是完美的，因为它完美地是其所是。^[10] <a name="back10"></a>

然而，在21世纪之交，我们的技术产生了柏格森无法想象的超真实世界，而鲍德里亚声称，甚至不再可能争论等价性问题：
> 一切都始于不可能的交换（impossible exchange）。世界的不确定性在于它没有任何等价物；它不能与任何东西交换。思想的不确定性在于它既不能与真理交换，也不能与现实交换。是思想使世界陷入不确定性，还是反过来？这本身就是不确定性的一部分。……世界和它的双重体没有足够的共存空间。因此无法验证世界。这确实就是为什么‘现实’是一种欺骗。……任何试图与某物进行交换的东西，最终都会遇到不可能交换的障碍（Impossible Exchange Barrier）。为使世界在价值意义上变得有意义、赋予其意义而进行的最周密、最微妙的尝试，都在这个不可能的障碍上受挫……整个价值体系可以交换为无（Nothing）。^[11] <a name="back11"></a>

不可能置身于世界之外，以便回看世界。从认识论的角度来看，这使得确认世界或建立任何绝对的客观意义或价值变得不可能。超真实无法通过将现实简化为并替换为由0和1组成的二进制系统来验证现实。^[12] <a name="back12"></a> 然而，这种向虚拟转移的影响是重大的——这对21世纪黎明之际的现代个体来说是一个更值得关注的问题：他们的灵魂状态，还是他们的信用评级（credit rating）？灵魂，作为一个形而上学概念，不可能被量化，其价格也无法确定。它难以接近，并且不受审讯或操纵的影响。不仅如此，而且由于我们并未做任何事来赚取我们的灵魂，我们一旦存在就处于负债状态（这是一个我们无法偿还的债务）。另一方面，信用评级很容易量化和获取。身份的这两个方面都没有任何形式或现实，但个人的信用评级就像一个超真实的幽灵一样困扰着那个人。

这些超真实的存在和领域成为审查的焦点：“在最高层次上，模拟不再关乎现实与表象的问题，而是关乎实际世界和虚拟世界的重合。”^[13] <a name="back13"></a> 一个直接的例子是典型的闭路电视（CCTV）环境，其中观察者的凝视不再对准主体。相反，摄像机镜头对准主体，而观察者则观看电视屏幕：
> 镜像阶段（mirror-stage）已经让位于视频阶段（video-stage）。没有什么能逃脱这种图像记录、声音记录，这种即时、同步的意识记录。活生生的身份，主体的身份，暗示着镜子，反思的元素……我们不再有这样的好运。我们现在得到的并不是我们自己的形象，而是一种实时（real time）的瞬时记录。在实时中，甚至连一个图像的距离都没有。……那种距离的废除使我们注定要无限复制，注定要一种可笑的永生……^[14] <a name="back14"></a>

监视器上创建了一个与真实世界相对应的虚拟世界。然而，因为它是一个模拟环境，监视器中的图像比它们实际的对等物更具可塑性。虚拟图像可以被冻结、放大、快进、倒带或慢速播放。^[15] <a name="back15"></a> 此外，图像被捕获在媒介（无论是模拟的还是更常见的数字媒介）中，直到被允许停止存在。相反，观察者对于主体来说根本不存在：“这使得很难通过摄像机寻求帮助——摄像机*将其对象完全作为对象留下*：被动，没有任何能力影响局势。”^[16] <a name="back16"></a>

计算机模拟分析（profiling）和建模（modelling）技术的兴起导致了监控空间/时间的内爆（implosion）。说观察者与被观察者之间，或事件与其审查之间的距离已经缩短，甚至减少到零，已经不再准确。分析指的是构建模拟身份，然后可以将其与实际身份进行比较，以预测真实主体的潜在行动。这些模拟被用来取代对主体的实际知识和观察到的行为。它是一种分类装置，因为它根据种族、阶级、年龄、性别、生活状况、地点、消费习惯等对个体进行分类。^[17] <a name="back17"></a> 这种工具被用来预测疾病和障碍的身体表现，以及习惯、日常活动和犯罪倾向。分析可以被理解为“不仅仅是一种监控技术，而且是一种*在监控之前进行的监控*，一种‘事前观察’（'observation before the fact'）的技术”。^[18] <a name="back18"></a> 这些模拟身份在应用于个体时，不仅仅是准确或不准确：
> 分析既不会失败也不会成功……相反，无论它如何绘制，它都*保证或提供*一个供监控的违法者。这种高阶监控技术加速了信息的分类和分析。……它们实际上是一种在识别之前的识别形式……^[19] <a name="back19"></a>

主体所犯的罪行是他或她与模拟分析的相似性；因为分析*将已经*犯下该罪行。像甘迪（Gandy）的圆形监狱分类（panoptic sort）^[20] <a name="back20"></a> 一样，分析是一种预测技术。然而，圆形监狱分类根据人们的行为对他们进行分类，而分析则根据人们与模拟的相似性对他们进行分类。一旦观察到某些偶然的属性，模拟就被叠加到主体上，缺失的信息片段被填补。在某些情况下，计算机会自动将主体与虚拟分析进行比较，绕过视觉观察的需要。^[21] <a name="back21"></a>

计算机建模采用了相同的预测模拟概念，并将其应用于事件而非个体。通过使用模型，将军们可以提前进行整个虚拟战斗，以确定结果。不再需要等到战斗结束后才权衡得失；相反，战后监控将在第一枪打响之前就已经进行了数百次：
> 由于其在所有细节上都被预料到并被所有情景所穷尽，这场战争最终类似于《玫瑰意大利人》（*Italien des Roses*）中的英雄……他在一座建筑物的顶部犹豫是否要跳下一个半小时，面对一群起初关注他举动、然后失望并被悬念压倒的观众……就好像它已经发生了十次：我们为什么还想让它再次发生。……一个被精心编程的事情还有发生的可能吗？一个被精心证明的真理还有机会是真的吗？^[22] <a name="back22"></a>

模型的成功并不取决于它与事件的相似性；事件的成功取决于它与模型的相似性。

建模和分析一样，是一种预测技术，通过它创建一个虚拟的、超真实的世界，然后这个超真实世界成为监控的焦点。然而，与摄像机镜头创建的虚拟世界不同，分析和模型与实际世界是重合的，但以一种预期的方式。一个理想的模型将描述的不是事件正在发生或将要发生的方式，而是事件*将已经*发生的方式。在模型被开发和完善之后，所需要做的就是等待真实事件模仿已经在虚拟世界中发生的事情；结果不再有疑问。通过分析和建模，监控不是即时性的——相反，它先于实际事件发生。

模拟监控技术也有助于使主体及其环境无菌化（sterilize）。没有任何感染或污染的危险，也没有气味或身体接触的可能性。数字幽灵只有在被编程时才会老化：“无菌*可以*意味着模拟衰败……因为模拟，毕竟像监控一样，旨在追求真实，而*真实可以是任何东西*，甚至是腐蚀它的东西。”^[23] <a name="back23"></a> 即使这样做了，它也可以同样容易地被撤销；在超真实中只有模拟的恶化和萎缩。

虽然许多作者评论了人机交互在监控中的作用，但博加德通过审视赛博格（cyborg）的形象将这一点推进了一步。1988年，肖莎娜·祖博夫（Shoshanna Zuboff）撰文论述了计算机化工作场所和非计算机化工作场所之间明显的监控差异。然而，人与机器之间仍然存在分离——工人仅仅是在使用技术。赛博格的概念——“有机体与机械的融合，或分离的有机系统之间结合的工程化”^[24] <a name="back24"></a> ——使得人们能够更好地理解模拟增强监控的独特方式。

着眼于工作场所，博加德研究了赛博格劳动的普及如何强化了监控能力。首先，赛博格劳动摧毁了特定工作空间的概念：
> ……赛博格工作涵盖了后工业经济的各个层面和部门，不服从阶级区分或体力劳动与脑力劳动之间的等级划分；蓝领或白领职业；职员或一线……任何类型的劳动，即，潜在地都可以被模拟，可以被某种形式的生物远程信息处理（biotelematic）、模拟装置所中介……这也是……日益导致当代工作逐渐渗入以前被认为外在于或分离于工作的领域的原因。……随着计算机化和通信技术将办公室或工厂转变为任何空间或任何时间（any-space-or any-time-whatever）……^[25] <a name="back25"></a>

现代商务人士——配备手机、寻呼机、便携式电脑等——从未真正离开办公室，因为他们的实体办公室已被虚拟电信系统取代和超越；赛博格就是其自身的办公室。形式上非生产性的时间，如旅行，当赛博格工人保持“接入”状态时，就变得具有生产性。同时，实际旅行变得不那么必要，因为它被虚拟会议、电话会议和即时图像所取代。虚拟运动取代了实际运动，赛博格工人变成了一个静止的形象，在模拟空间中移动并与其他赛博格实体互动。

这并不是说主体被*阻止*移动。虚拟并不对移动施加物理限制。相反，移动通过被剥夺其必要性，从而被剥夺其*意义*而被消灭。鲍德里亚认为这种灭绝是一种完美罪行（perfect crime），没有动机或犯罪者：“……*灭绝*（exterminate）意味着剥夺某物自身的目的，剥夺其终点。……这就是罪行：我们达到了一种完全实现意义上的完美，而这种总体化（totalization）就是一个终点。任何地方都不再有目的地……”^[26] <a name="back26"></a> 移动没有被抑制，但它变得荒谬：
> 因此，这既是对现实世界的罪行，现实世界变成了一个无用的功能，但更深刻、更根本的是，这是对世界幻象（illusion of the world）的罪行，也就是说，对其根本的不确定性、其二元论、其对抗性——一切构成命运、冲突和死亡存在基础的东西的罪行。……我们最终可能会得到一个统一的、同质化的、完全*被验证*的世界，正如我所见，也因此被灭绝了。^[27] <a name="back27"></a>

没有什么比没有理由存在的东西更荒谬了。就这样，移动（以及随之而来的所有危险、不确定性、可能性和模糊性）被谋杀了。

赛博格凭借其对信息技术的依赖创造了自身的监控。不再需要记录工人的行为；赛博格工人通过其自身的运作创造了其实时文档：
> 提交订单、确认预订、编程任务：任何通过数据输入完成的工作都会自动留下痕迹。更重要的是，任何其任务本身可以被分解并转化为编码指令功能的工作，甚至在开始之前就已经受到监控。^[28] <a name="back28"></a>

在赛博格世界中，生产和观察不再是分离的力量；通常，产生可观察信息是赛博格工人的唯一功能。数据是赛博格所生产的东西，也是赛博格主管所监控的东西。赛博格的模拟劳动*就是*监控。

虽然模拟已成为监控的强大盟友，但它作为监控的对手有着更长的历史。监控旨在揭露表象，而模拟可以掩饰、歪曲、伪装、隐藏和分散注意力。这可以在巨大规模上进行——在二战战斗机工厂上建造一个模拟城镇——也可以在微不足道的规模上进行——一个学生假装对讲座感兴趣，甚至达到在笔记本上涂鸦以模拟做笔记的程度。特别是，博加德写道，模拟可以对抗工作场所的监控：
> 事实上，劳动人民一直知道如何利用模拟来逆转劳动控制的极性。在法国，他们称之为*假发*（*la perruque*），即工人们发明的所有巧妙方法，用来欺骗雇主或主管，让他们以为自己在工作，或者使他们的工作不那么繁重。^[29] <a name="back29"></a>

现代*假发*的例子包括阅读个人电子邮件、浏览互联网色情内容或在线书店、打电话，或者就学生而言，只是将大脑从执行所需任务中移除，同时让身体模仿正确的行为。虽然模拟的赛博格工人的时间性被窃取，但*假发*的模拟者为自己偷回时间。然而，假发和简单的偷懒（slacking）之间有一个重要的区别。偷懒涉及试图将自己隐藏起来以逃避监控，以便可以完全停止工作或以慢节奏进行。*假发*是在主管的完全视野下进行的，并不代表一种比工作更轻松的替代方案：“假发要求工人投入同等甚至更多的精力（作为其劳动的一种补充，一种‘伴随’生产的额外劳动）”。^[30] <a name="back30"></a> 假发表演者不是隐藏*于*监控之外，而是隐藏*在*监控之内，通过模拟高效工人的形象。

模拟与监控之间的最终关系是前者对后者的取代。博加德没有详细讨论这一点，但提供了一个例子：
> 开车……前往怀俄明州的拉勒米（Laramie），你会穿过百年镇（Centennial）。……你对自己开得多快毫无察觉。就在镇子尽头，你发现一辆巡逻车停在路边咖啡馆旁。……你肯定被发现了，很可能被雷达枪扫描过。你开始靠边停车。但当你靠近时，你注意到车里没有人，事实上它根本不是巡逻车，只是一辆涂成黑白相间的旧报废车，顶上装了一些假的闪光灯……^[31] <a name="back31"></a>
## III. 拉斯维加斯长街：阳光下 III. The Las Vegas Strip: Under the Sun
拉斯维加斯长街酒店的外部展示着令人眼花缭乱的各种建筑风格的拼贴。一些赌场，如凯撒宫（Caesars Palace）和神剑赌场（Excalibur），旨在模仿人类历史的特定时代，尽管历史准确性充其量是可疑的，更宽容的说法是，其建筑是基于好莱坞电影中对历史时代的描绘。例如，走在神剑赌场的护城河和吊桥周围，会让人想起B级片的罗宾汉系列电影。凯撒宫的人造大理石外观确实让人感觉仿佛穿越回了古代，但不是古罗马，而是回到了《宾虚》（Ben Hur）或充斥深夜电视有线频道的无数其他托加袍与剑电影的片场。

![](https://web.archive.org/web/20250104190043im_/https://baudrillardstudies.ubishops.ca/wp-content/uploads/2019/04/Returning-to-the-desert-at-sunrise.jpg)Jean Baudrillard. Las Vegas, “Returning to the desert at sunrise”, 1996.^[33] <a name="back33"></a>**

几家较新的赌场——特别是巴黎赌场（Paris）和威尼斯人赌场（the Venetian）——旨在模仿历史上的欧洲城市，同时仍让美国游客享受一个没有欧洲人的环境。巴黎赌场还设有凯旋门（Arc de Triomphe）和香榭丽舍大街（Champs Elysees），并被一个按比例缩小的埃菲尔铁塔（Eiffel tower）横跨。威尼斯人赌场更进一步；它旨在几乎按1:1的比例模仿威尼斯的庭院（Courtyard）。尽管威尼斯人赌场的运河里没有原始污水漂浮，但已采取煞费苦心的措施以确保准确性。尽管如此，沙漠中威尼斯人赌场的运河水同样不适合饮用；欧洲威尼斯运河的水含有有害细菌和其他生物，而威尼斯人赌场的水则经过氯化处理，达到闪闪发光的无菌状态。

威尼斯人赌场并非唯一使用外部水景的。长街上遍布着喷泉、水池、人工湖、泻湖、瀑布、泉水和间歇泉；长街上空的空气明显比四五条街区外的空气更潮湿。百乐宫（Bellagio）度假村用水上表演作为其主要景点；夜晚，数百万加仑的水通过加压喷射到空中，伴随着轻音乐或古典乐的声音。在沙漠的中心——一个水本应稀缺的环境——水却无处不在，尽管不能饮用——这是对水犯下的完美罪行（perfect crime）。

正如水被净化了不良的有机污染物，长街本身也没有不良生物。虽然企鹅、火烈鸟、老虎、狮子、鲨鱼、海豚和孔雀数量丰富，但没有沙漠野生动物侵入长街。如果有人想观看本土动植物，必须前往内华达大学的爬行动物动物园，或好时巧克力工厂的仙人掌公园，在那里，沙漠生命被分离、容纳，并可以在一个舒适的环境中轻松观赏，这让人想起鲍德里亚遭遇生物圈2号（Biosphere）项目时的情景：
> 自然——自然界——正在变得残余、微不足道、累赘，而我们不知道如何处理它。……生物圈2号的例子很有说服力：它希望提供我们星球的理想合成图像，其作为实验性人工制品的特性，是一种将我们的环境转化为 archaic 残留物、倒入自然历史垃圾箱的方式。^[34] <a name="back34"></a>

大多数长街赌场都有高大的棕榈树，但它们并非内华达州本土植物。棕榈树虽然昂贵，但对于强化拉斯维加斯作为天然绿洲的形象很重要。经典电影中对天然绿洲的描绘涉及大量的棕榈树覆盖。

拉斯维加斯警方也确保没有不良生物占据长街。该地区很少有乞丐或无家可归者，那些进入该地区的人也会被迅速清除。即使是合意的生物——如游客——也不被允许随意地在该地区自由漫步。据推测，拉斯维加斯当局对撞到路上行人的司机态度出奇地宽容，导游也确保访客大部分时间留在人行道上。然而，即使游客被安全限制在人行道上，他们仍然不被允许完全的位置自主权。一系列户外自动扶梯和自动人行道控制着行人的移动。例如，任何人踏上凯撒宫前的自动人行道，很快就会发现自己不可抗拒地被吸引穿过拱门进入赌场一百多英尺。

还采取了广泛的措施来防止建筑通过城市衰败过程自然化。例如，威尼斯人赌场设有老化、有缺口的柱子。然而，这些最近建造的柱子是人为凿出缺口以显得古老，然后被冻结在时间中。任何额外的风化都会立即被纠正。东西可能看起来古老，但不被允许真正老化。模拟帮助度假村实现了对时间性的暂时胜利。

拉斯维加斯的经典形象之一是挥手示意的牛仔广告牌，召唤赌客进入赌场。当人们走在长街上时，赌场建筑似乎不断发出运动。然而，已经采取措施来根除实际的运动。实际运动需要部件的物理互动；这种互动会产生磨损和衰败，因为部件相互摩擦。长街建筑上的运动在很大程度上被巨大的视频屏幕超表面（hypersurface）虚拟化了：这使得设计者能够以逼真的细节展示与周围环境无关的场景，例如播放几周前（或几天后）发生的表演片段，或者展示一位根本不在该城市附近（或已故）的名人。这种虚拟化也使得 drastically 改变赌场外部外观变得容易得多，因为不需要施工。视频屏幕比物理标志允许更直接的控制，就像光盘相对于黑胶唱片一样，视频屏幕提供了实际过程的生动模拟，而无需物理互动：
> 机器只生产机器。随着虚拟技术的发展，这一点越来越正确。在某种程度的机械化、沉浸于虚拟机械中时，不再存在人机区分：机器处于界面的两边。也许你现在确实只是在机器的空间里——人类已成为机器的虚拟现实，其镜像操作员。这与屏幕的本质有关。不像穿过镜子（looking-glass）或镜面那样有“穿过”屏幕。时间维度本身在“实时”中融合。而且，任何虚拟表面的特征首先是存在，是空的，因此能够被任何东西填充，留给你的是在实时中进入与虚空（void）的互动。^[35] <a name="back35"></a>

针对运动（以及死亡，因此也是生命）的完美罪行仍在继续。

长街上没有物理恶化的感觉；快速的建设和拆除确保了这一点。拆除球和建筑起重机在该地区的数量大致相等。每栋建筑都一尘不染，除了在每个主要十字路口散发的卖淫广告小册子外，街道上的垃圾少得令人惊讶。

拉斯维加斯给人一种生动、放纵、未经驯服的绿洲的印象，被贫瘠的西南沙漠所环绕。这是一种错觉。虽然沙漠实际上生机勃勃，但拉斯维加斯长街却被消毒、灭菌和控制。不良生物被移除，合意的生物被收容。甚至熵的物理定律也通过根除实际运动而被暂时抑制。鲍德里亚认为：“在一个超保护的空间里，身体失去了所有的防御能力；”^[36] <a name="back36"></a> 拉斯维加斯长街的超保护外部空间使主体易受占据拉斯维加斯赌场内部的诱人模拟监控（simveillance）狂潮的影响。
## IV. 拉斯维加斯长街：远离阳光 IV. The Las Vegas Strip: Away from the Sun
较老的长街赌场和较新的赌场在监控特性上存在显著差异，这些差异有助于说明模拟对监控的影响。当人们进入少数较老的长街赌场内部时，很明显视线决定了建筑结构。较新的赌场已经从非模拟观察的束缚中解放出来，因此外观截然不同。

甚至在进入里维埃拉赌场（Riviera casino）之前，就能明显看出它是一栋较老的建筑。从外面看，它像一个赌场，而不是城堡或金字塔。墙上的运动是由序列灯产生的错觉，而不是由超表面视频屏幕产生的。一旦进入内部，就更明显了。天花板非常低——离地面不到14英尺。很容易看出头顶上方的猫道（catwalks）在哪里；它们是被镜子包围的区域。由于从正上方很难识别面孔，因此使用了折射来补偿任何不良的视线。里维埃拉赌场多年来通过摄像头和智能卡（infocard）兼容的老虎机等较新的监控技术进行了更新，但这些设备是附加到建筑上的，而不是设计在建筑内的。从赌场内相对较少的摄像头吊舱（camera pods）数量来看，里维埃拉赌场的监控仍然非常依赖于猫道和在赌桌旁不停巡视的赌区主管（pit bosses）。

当人们踏入像百利赌场（Bally’s）这样的后期型号赌场时，差异是巨大的。虽然更大的赌场地面仍然像一个赌场，但天花板更高，镜子更少。最明显的变化是摄像头吊舱数量的增加；它们覆盖了赌桌和老虎机上方的天花板。它们不是均匀分布，有些区域在几英尺内有四五个，而其他区域可能只有一个吊舱覆盖相同的面积。这种不均匀的布置使得球茎状的黑色摄像头吊舱看起来像感染赌场天花板的瘟疫。虽然监视百利赌场赌场地面的眼睛比监视皇家赌场（Casino Royale）的少，但有数百个镜头自动扫描和记录一个重合的虚拟世界。监控室里的警官每人都有几十个视频摄像头作为假体（prostheses）；虽然双眼的皇家赌场警官通过专注于一个小区域而失去了周边视觉，但百利赌场的警官拥有视频屏幕墙昆虫般的复眼（compound eye）的优势。虽然皇家赌场的观察者与他们的主体保持物理上的临近性（imminence），但百利赌场的观察室可能位于赌场内的任何地方，在某些情况下，一名警官甚至可能不在赌场墙内，通过笔记本电脑观看直接馈送。由于监控的虚拟化，现代赌场中更大的区域可以由更少的人监视，这是圆形监狱的主要目标之一。尽管如此，百利赌场与经典的圆形监狱模型没有任何物理上的相似之处。

可以说赌场地面被划分为个体单元（cells），主体在其中被容纳并无法自由移动。这些单元实际上比边沁计划中的单元更小，因为它们只包括主体的椅子和一台老虎机或一部分牌桌。没有任何物理障碍阻止某人离开他们的赌场单元，尽管许多人用绳子将他们的常客身份证（frequent player ID cards）系在自己身上，当他们插入机器时，看起来像是从老虎机接了一条静脉注射管。但是，虽然没有单元墙，但仍然有一种强大的吸引力让人们长时间坐在座位上。根据拉斯维加斯的传说，当米高梅大酒店（MGM Grand Hotel）在1980年11月21日被烧毁时，发现烧焦的尸体仍然坐在他们的老虎机前。^[37] <a name="back37"></a> 然而，这不是圆形监狱明显和非自愿的禁闭，而是旋转卷轴创造的可能性幻觉和老虎机24小时发出的充满希望的声响的诱惑（seduction）。被赌场赌客内化的不是监控机制，而是枷锁、链条和墙壁。

圆形监狱模型甚至更不适用于新型城市拟像（simulacra）赌场。一旦进入高度模拟的环境，鲍德里亚关于模拟装置已使福柯的透明性和权力理论过时的论点似乎具有预言性；鲍德里亚的模拟理论照亮了展现在访客面前的嘈杂场景。确实，如果没有扎实的模拟理论基础，就不可能理解这些场所。

虽然百利赌场仍然像一个赌场，但附近巴黎赌场的内部被设计成类似于一个户外法国市场。天花板超过40英尺高，并被涂绘和纹理化以模仿一个阳光明媚的美丽日子，包括当人们在下面行走时似乎会移动的蓬松白云。没有任何地方有长长的镜子带；它们显然会破坏这种错觉。也没有摄像头吊舱的瘟疫点缀着午后的天空。起初，似乎赌场范围的户外模拟阻碍了该区域的监控。然而， upon closer inspection，可以检测到熟悉的摄像头吊舱。老虎机区域有许多灯柱，每个灯柱包含一个小黑色吊舱，而不是灯笼。牌桌坐落在一个细长的棚架下，设计成模仿户外花园建筑。隐藏在棚架中的是几十个吊舱，每个都隐藏着一个警惕的摄像头。

在百利赌场，没有采取任何措施使摄像头吊舱明显，而在巴黎赌场，它们几乎是隐蔽的。这与可见但无法验证的圆形监狱模型直接相反。在巴黎赌场，所有主体都在被持续观看、扫描、记录和比较，但却是秘密进行的。圆形监狱使用持续警惕的错觉是因为这种警惕会带来的物理问题；边沁认为，观察的虚构与实际观察一样有效。当模拟监控使持续警惕成为可能时，就不再需要强化虚构的错觉了。

取景器和摄像头镜头并非都指向拉斯维加斯的游客；许多指向别处。现代游客通过他或她的个人技术过滤器体验这座城市。在机场接人的旅游巴士在座位上方的闭路摄像机监视器实时播放与窗外可见相同的视图。对于坐在离监视器几排远的乘客来说，窗户就足够了；对于直接坐在监视器后面的乘客来说，很难不全程盯着闪烁的小电视机。即使是步行，也常见到游客走过拉斯维加斯的模拟地标，同时眼睛紧盯着摄像机上的两英寸屏幕。据推测，一旦游客回家，他或她将能够在他或她的大屏幕电视上体验拉斯维加斯。游客与其技术之间的这种关系说明了区分两者变得多么困难：
> 新技术，及其新机器、新图像和交互式屏幕，*并不*疏远我。相反，它们与我形成一个集成电路（integrated circuit）。……我们与网络和屏幕的所有关系，无论有意还是无意，都属于这种秩序。它们的结构是一种从属（subordination）结构，而不是异化（alienation）结构——集成电路的结构。人还是机器？无法分辨。……人对人的异化已成为过去：现在人通过机器陷入稳态（homeostasis）。^[38] <a name="back38"></a>

是游客带着他的摄像机去度假？还是摄像机带着它的游客？如果现代游客时间紧迫，他最好简单地送他的摄像机去而不亲自去。或者也许我们不能再谈论两者之间的区别；也许游客*就是*摄像机——当然他有机的记忆将被销毁并被录像带或数字存储卡捕获的虚拟记忆所取代。

在论坛商店（Forum Shops）购物中心，模拟视频体验达到了一个新的猥亵（obscenity）水平。庭院中心有一个大型圆形咸水鱼缸，里面有几十条色彩鲜艳的海洋鱼。长凳围绕着鱼缸，以便人们可以观察鱼，但长凳背对着鱼缸。沿着外墙，巨大的视频屏幕播放来自鱼缸内部摄像头的实时画面。人们背靠着鱼缸坐着，观看数字化的鱼游过超表面。一些人通过自己的取景器盯着电视上的鱼，而实际的鱼可能就在他们脑后几英寸远。虽然这看起来可能很极端，但并不罕见。摄像机的可用性增加和价格下降意味着圆形监狱的凝视不是单向地通过少数控制精英的镜头流动，而是同时从大众指向和被大众指向。人们在互相观察，人们通过将镜头转向自己来观察自己，以便日后审查自己的行为。现代主体受到来自四面八方的监控困扰，并沉浸在观察的海洋中。对福柯监控理论如此重要的凝视，被折射和分散，就像一束光穿过鲍德里亚式透明性和猥亵的破碎棱镜：
> 超政治（transpolitical）是所有结构在一个去结构化宇宙中的透明性和猥亵，是变化在一个去历史化宇宙中的透明性和猥亵，是信息在一个事件被掏空的宇宙中的透明性和猥亵，是空间在网络混杂中的透明性和猥亵，是社会在大众中的透明性和猥亵，是政治在恐怖中的透明性和猥亵，是身体在肥胖和基因克隆中的透明性和猥亵……历史场景的终结，政治场景的终结，幻想场景的终结，身体场景的终结——猥亵的爆发。秘密的终结——透明性的爆发。^[39] <a name="back39"></a>

福柯的透明性概念在描述论坛商店水族馆的超-猥亵（trans-obscenity）时显得严重不足。这里没有连贯的叙事，没有单向的焦点，没有基于知识的权力等级。只有透明性——而 beyond it 没有什么可看的。

类似地，经典的圆形监狱理论似乎无法容纳过去二十年来抹去拉斯维加斯赌场的模拟爆炸。这是一种非常基于物理身体在现有结构中实际运动的理论，因此它限制了对普通北美人士所处的日益虚拟化环境的理解。必须关注模拟和监控结合的特殊方式。
## V. 拉斯维加斯中的模拟监控 V. Simveillance in Las Vegas
一个移动且不可预测的主体是危险的主体，也将是监控的焦点。在拉斯维加斯，模拟有助于确保潜在危险的主体变得静止和可预测。

为了将城市从赌博区转变为全方位娱乐区，拉斯维加斯设有许多游乐设施。其中一个游乐设施是“争夺亚特兰蒂斯”（"Race for Atlantis"），位于论坛商店购物中心。该游乐设施具有一段激动人心且危险的水下追逐，穿过遗迹和建筑，以极快的速度进行。然而，观众移动得非常少。相反，他或她相对静止，而最新的模拟技术欺骗他或她的大脑，使其相信运动正在发生。大部分运动发生在3D穹顶屏幕上，而不是在现实世界中，但运动的印象仍然存在。

如前所述，结构运动在拉斯维加斯长街上在很大程度上被虚拟化了。个人的运动也同样被虚拟化。电子游戏厅很常见，部分原因是儿童不允许进入赌场地面，父母需要有一个地方长时间安置他们。游戏厅中的许多游戏用虚拟运动取代实际运动，导致主体静止。例如，考虑下山滑雪。当一个人下山滑雪时，很多事情都可能出错。他们可能迷路走错雪道，他们可能撞到树或另一个滑雪者，他们可能不付费就上山，他们可能拿起滑雪杖戳进另一个人的眼睛；这个列表几乎是无穷无尽的。观察滑雪者也十分困难，因为速度和行进距离。考虑在许多长街游戏厅流行的下山滑雪模拟游戏（顺便说一句，拟像（simulacrum）的存在在长街上如此普遍，以至于有人会来到沙漠中心体验高山滑雪的想法并不令人惊讶）。模拟滑雪者绑在一套固定的滑雪板上，周围是视频屏幕。设备和屏幕连接到一台计算机，计算滑雪者将收到的反馈。滑雪者不再可能迷路；除了模拟提供的路径外，没有其他路径。撞到障碍物或其他滑雪者也不再是问题，因为实际上没有障碍物或其他滑雪者在场。任何希望观察模拟滑雪者的人会发现任务非常容易，因为主体只是站着不动，而视频屏幕和人工器具提供运动的感觉。没有比这更容易的监控目标了。再次，我们看到了针对运动的完美罪行。没有什么阻止用户以有机的方式移动；然而，任何这样的原始运动都不会对模拟产生影响，因此不会从设备获得反馈。滑雪者没有理由尝试这样的运动，因为它与矩阵（matrix）没有对应关系；它是无意义和徒劳的，因此被消除。就这样，在追求冒险和刺激的过程中，用户将自己固定成一种无菌的安全状态。体验的价值（可能性的刺激，包括个人危险的可能性）被消灭，并被空洞的虚拟互动所取代。

虽然虚拟运动游乐设施和计算机化的游戏厅是长街的重要组成部分，但拉斯维加斯唯一最重要的机器是老虎机（slot machine）。拉斯维加斯机场大厅里到处都是老虎机，大多数杂货店门口都有几台，现代赌场用其大部分地面空间来展示它们。部分吸引力在于简单性；需要记住的规则很少，不需要担心人类庄家或其他玩家。相反，人们能够简单地坐着，观看虚拟卷轴旋转。

原始的老虎机是机械设备。拉动手柄物理激活机构内的钟表式齿轮，从而旋转卷轴。这些早期机器容易被操纵。用户可以在樱桃符号击中左上角时以某种方式挤压某些机器的手柄，机器会支付比设计更多的硬币。或者，在其他机器上，当玩家获胜时，他们可以稍微降低手柄，然后弹回以获得相同的赔付而无需再次旋转卷轴。最后，熟练的用户可以以某种方式操作手柄，使获胜组合在赔付线（payline）上对齐。^[40] <a name="back40"></a>

现代老虎机是一种计算机化设备，带有随机数生成器（random number generator）控制卷轴在任何一次旋转中将命中哪种组合。在赌场地面走动时，有很多机会在老虎机被维修或填充时查看其内部，它们更像个人电脑的内部而不是模拟时钟。微芯片和处理器板取代了齿轮；这些微芯片没有记忆，所以“热”机器（"hot" machine）的想法是赌徒的谬误（gambler’s fallacy）。手柄的运动与卷轴的旋转没有直接关系；事实上，很少看到有人在使用现代老虎机时拉动手柄。相反，老虎机配有一个标有“旋转”（"SPIN"）的大按钮。赌客通过简单地将一只手放在按钮上用指尖按下，而不是必须移动整个手臂来拉下手柄，从而最小化自己的运动。通过将老虎机虚拟化，赌场确保老年玩家能够并愿意花更长时间坐在老虎机前。这是一个完全受控的虚拟环境。

通过在赌客的运动和卷轴的运动之间放置一个虚拟过滤器，老虎机设计者减少了赌客的影响力，并减少了他或她的可能性。虽然机械机器的手柄可以被弹动、挤压或操作以给赌客优势，但这样的操作对虚拟机器内部的随机数生成器没有任何影响。赌客可能仍然试图通过物理互动影响机器，但这些尝试是徒劳的。因此，赌场监控人员不再需要寻找此类行为。

然而，现代老虎机仍然脆弱，因为它仍然必须向玩家分发实体硬币。因此，仍然可以使用物理手段确保机器支付比设计更多的钱。称为“猴爪”（"monkeypaws"）或“支架”（"kickstands"）的设备可以插入机器支付硬币的孔中，以物理提升老虎机中的硬币计数机制，或者可以在更先进的机器中插入一个小闪光灯以致盲光学计数器。在任何一种情况下，该设备通过攻击其脆弱的物理部件，使机器无法感知其支付的硬币数量。^[41] <a name="back41"></a>

虽然老虎机是赌场最受欢迎的游戏，但桌面游戏（table games）仍然是一种吸引力。每一个桌面游戏——无论是纸牌、轮盘赌还是掷骰子——都牢牢地停留在物理领域。在纸牌游戏中，关键变量是纸质牌的顺序和分发。在轮盘赌中，是金属球与移动容器的互动。在掷骰子中，玩家实际上可以在一定程度上触摸和控制变量，因为他或她掷出骰子。在每一个这些过程中，都有许多方式让赌客作弊。

例如，看看二十一点（blackjack）游戏。赌客可以通过在脑中记牌或使用隐藏的计算机玩同步虚拟游戏来获得优势。还有其他不那么先进的方式让赌客作弊。她可能能够与牌桌上的另一个赌客换牌，以便用两副弱牌组成一副强牌。她可能分散庄家的注意力，使其在分发赢款时犯错。她可能与庄家合谋，事先制定好侧计划。最后，她可能简单地抓住别人的赢款跑掉。

赌场中一个相对较新的设施是虚拟纸牌游戏；这些游戏将模拟推向比计算机化老虎机更远的程度。虽然老虎机保留了物理卷轴（以保留历史氛围并让赌客有物理性的错觉），但虚拟纸牌游戏摒弃了所有实际运动，转而采用视频屏幕。游戏位于凳前的计算机终端中。玩家从屏幕菜单中选择游戏后，一双幽灵般的、脱离实体的手将牌图像发到虚拟桌面上。玩家触摸屏幕来要牌或弃牌，并设置他想要下注的金额。游戏以与实际游戏相同的方式展开，并且似乎遵循相同的规则。

然而，虽然游戏规则相同，但虚拟化使游戏能够消除物理性规则。显然，由于机器将所有钱币保存在内部直到支付赢款，赌客不可能抢夺桌上别人的赢款跑掉。就此而言，没有其他人。只有赛博格赌客，与屏幕和微芯片互动。赌客同样不可能通过偷看庄家的牌来作弊；这些牌直到游戏结束“翻开”时才有价值。虽然他/她的牌背面出现在屏幕上，但它们只是占位符。没有另一面。在实际游戏中，一旦牌被洗好（尽管是由随机数生成自动洗牌机洗牌），就有一种必然性。所有牌最终都必须显示，一旦一张牌被打出，它就被耗尽，直到下一副牌被洗好。在虚拟游戏中，随机数生成器保留，但牌消失了。因此，识别算牌者（card counters）的困难被消除了，不是通过将算牌者赶出赌场，而是通过移除他计算的对象。虚拟设备减少了赌客的选择，同时保持了自由和随机性的错觉。

作弊的赌客仍然有办法击败现代赌场的模拟世界。这不是小镜子、对讲机或心算系统的方式。相反，这是病毒（virus）的方式：
> ……我们面临新的疾病，那些困扰被其人工、医疗或计算机生成屏障过度保护的身体的疾病……去符号化的机器语言对病毒感染提供的抵抗力，并不比去符号化的身体更多。^[42] <a name="back42"></a>

现实缺失的计算机世界容易受到内部虚拟病毒的攻击；虽然轮盘赌作弊者必须试图以某种方式物理改变游戏，但虚拟轮盘赌作弊者可能，如果他或她找到一个入口，在物理上不改变任何东西的情况下改变机器的矩阵。
## VI. 结论——第四面墙 VI. Conclusion – The Fourth Wall
拉斯维加斯是一个极端之地，但正如我们从鲍德里亚^[43] <a name="back43"></a> 所知，正是从极端中我们可以了解我们日常世界底层的趋势。那么，从长街可以学到什么？监控与模拟之间的连接点是复杂且矛盾的。模拟是监控的敌人，就像伪装是侦察的敌人。模拟技术可以显著增强监控，通过 dismantling 视线和时间性的物理问题。最后，模拟可以取代监控，通过将主体固定在一个选项有限、自由被想象的虚拟世界中。

传统的圆形监狱理论无法解释被模拟监控（simveilled）的对象；在虚拟化的超真实领域，物理结构和时间性几乎无关。福柯的权力概念窒息了他的理论，将其 relegating 为历史概念而非 vital 概念。被模拟监控的对象不像乔治·奥威尔（George Orwell）《1984》中圆形监狱世界里的受压迫角色，他们被迫违背自己的意愿将自己暴露在摄像机不眨眼的眼睛下。相反，他更类似于雷·布拉德伯里（Ray Bradbury）《华氏451度》（*Fahrenheit 451*）中的米尔德里德·蒙塔格（Mildred Montag）。蒙塔格自愿拥抱屏幕；她只希望被四面超表面墙包围，以便她自己可以成为一种模拟，完成针对真实的完美罪行：
> ……十分钟后，一场戏剧将在墙对墙电路上播放。他们今天早上邮寄了我的角色。……他们写剧本时缺了一个部分。这是一个新想法。家庭主妇，也就是我，是缺失的部分。当轮到缺失的台词时，他们都从三面墙外看着我，我说出台词。……真的很有趣。当我们能负担得起安装第四面墙时，会更有趣。^[44] <a name="back44"></a>

米尔德里德的生活已被虚拟生活取代。不需要实际的社会互动，不需要运动。她知道自己在盛会中的角色，虚拟人们正从超表面凝视着她，等待她完成程序中的部分。但是没有人从她那里夺走她的生命；她自愿将其作为牺牲献出。而且这似乎是一个非常微不足道的牺牲。

这是现代主体的命运吗？自愿将他生命牺牲给模拟的第四面墙，在留下一个虚拟残余的同时结束自己的生命？成为一个温顺静止的观察者，而不是一个积极移动的参与者？像拉斯维加斯和迪斯尼乐园这样的娱乐场所的巨大受欢迎程度似乎表明这是一种可能性。人们正在逃离不确定的世界，奔向其模拟的非等价物。

显然，该领域还有更多方面需要研究。虽然本文侧重于模拟环境中的被监控主体，但互联网使用的迅速崛起导致了*个体*的虚拟化，因为主体创建虚拟身份与不存在的场所中的其他网络幽灵互动。立法者一直在经历巨大的困难，试图为这些非区域立法，而网络空间使用的增加对监控理论的影响实际上是无限的。
