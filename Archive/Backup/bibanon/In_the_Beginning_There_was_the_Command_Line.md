# 起初是命令行
>https://wiki.bibanon.org/In_the_Beginning_There_was_the_Command_Line （中译：2023/11/22，排版有修改）
## 按
尼尔·斯蒂芬森（Neal Stephenson）于1999年出版的《起初是命令行》（In the Beginning There was the Command Line）是一部篇幅浩繁、内容丰富的著作，探讨了操作系统相关的诸多主题。他将图形用户界面（Graphical User Interface, GUI）仅仅视为一种隐喻，并运用了诸多有趣的类比（例如将其比作汽车），进而阐述了命令行的发展历程及其至今仍然存在的原因。书中还批判了当时微软（Microsoft）在操作系统领域的垄断地位，并将其与迪士尼（Disney）相提并论，认为两者都在向消费者兜售一种愿景，而消费者却乐于相信它，即便当时存在着更好、更便宜的替代方案。

请注意，其中很多内容都非常非常古老且过时。BeOS已经停止开发，而Mac OS X当时尚未问世。Linux如今不再仅仅拥有服务器架构、命令行界面（Command Line Interface, CLI）、一个小型驱动库或几个功能较弱的窗口管理器（Window Manager）。它现在拥有众多软件公司的大力支持、多种高级桌面环境（Desktop Environment），以及足以让任何系统正常运行的驱动程序，只需对一些较新的系统进行少量调整即可。
> > *你写《起初是命令行》的时候，对BeOS真是爱不释手。BeOS固然不错，但现在它已经基本退出历史舞台了。你还在用BeOS 5吗？还是已经从Zeta那里买了YellowTab？或者，你已经拥抱了基于UNIX的全新macOS X，把它当作你“只想去迪士尼乐园”时的理想操作系统？*
> >
> > 你猜对了：我一看到macOS X就立刻用了，而且从未后悔过。所以，《起初是命令行》里的很多内容现在都过时了。我一直想更新它，但说实话，我觉得不太可能。
> >
> > *——尼尔·斯蒂芬森（Neal Stephenson）在 http://slashdot.org/story/04/10/20/1518217/neal-stephenson-responds-with-wit-and-humor 上写道*
## 1. 介绍 Introduction
大约二十年前，苹果公司（Apple）的创始人史蒂夫·乔布斯（Steve Jobs）和史蒂夫·沃兹尼亚克（Steve Wozniak）提出了一个非常奇特的想法：销售家用信息处理设备。这项业务迅速发展，两位创始人赚得盆满钵满，并因其大胆的远见卓识而获得了应有的赞誉。但几乎在同一时期，比尔·盖茨（Bill Gates）和保罗·艾伦（Paul Allen）提出了一个更加奇特、更加天马行空的想法：销售计算机操作系统（Operating System）。这比乔布斯和沃兹尼亚克的想法要怪异得多。计算机至少还有一些实体存在。它装在一个盒子里，你可以打开它，插上电源，看着指示灯闪烁。而操作系统则完全没有实体。当然，它是以磁盘的形式提供的，但实际上，磁盘只不过是操作系统的包装盒而已。产品本身是一长串0和1，当正确安装和维护后，它就赋予了你操控其他同样长串0和1的能力。即使是少数真正了解计算机操作系统是什么的人，也倾向于将其视为一种极其深奥的工程奇迹，就像增殖反应堆或U-2侦察机一样，而不是（用高科技术语来说）可以“产品化”的东西。

然而，如今盖茨和艾伦创立的这家公司销售操作系统，就像吉列（Gillette）销售剃须刀片一样。新版操作系统的发布堪比好莱坞大片，名人代言、脱口秀亮相、全球巡回宣传，无不铺天盖地。操作系统市场如此庞大，以至于人们开始担心它是否已被一家公司垄断。即使是我们社会中最不懂技术的人，现在也至少对操作系统的功能略知一二；更重要的是，他们对操作系统的优劣有着强烈的看法。即使是技术水平不高的电脑用户也普遍明白，如果你把一个在麦金塔电脑（Macintosh）上运行的软件移植到视窗电脑（Windows）上，它是无法运行的。这实际上是一个非常可笑且愚蠢的错误，就像把马蹄铁钉在别克车（Buick）的轮胎上一样。

一个在微软成立之前陷入昏迷，如今醒来的人，可以拿起今天早上的《纽约时报》（New York Times），几乎能理解其中的所有内容：
*   问：世界首富的财富来自哪里？铁路？航运？石油？都不是，是操作系统。
*   项目：司法部（Department of Justice）正在利用法律工具来应对微软所谓的操作系统垄断，而这些法律工具最初是为了限制十九世纪强盗大亨（Robber Baron）的权力而发明的。
*   事情：我的一位女性朋友最近告诉我，她和一位年轻男子结束了一段（原本）颇有意思的电子邮件交流。她说，起初他看起来既聪明又有趣，但后来“他开始跟我争论PC和Mac哪个更好”。

这到底是怎么回事？操作系统行业还有未来吗？还是已经走向衰落？以下是我的个人观点，纯属个人看法；不过，我花了很多时间使用，也编写过Macintosh、Windows、Linux和BeOS的程序，所以我的观点或许并非完全无稽之谈。这是一篇主观评论，与其说是研究论文，不如说是评论，因此与PC杂志（PC Magazine）上的技术评测相比，它可能显得不够客观或带有偏见。但自从Mac问世以来，我们的操作系统就一直基于隐喻，在我看来，任何包含隐喻的东西都值得探讨。
## 2. MGB、坦克和蝙蝠车 MGBs, TANKS, AND BATMOBILES
在乔布斯、沃兹尼亚克、盖茨和艾伦构思这些看似不可能实现的计划时，我还是个住在爱荷华州艾姆斯市（Ames, Iowa）的少年。我一个朋友的爸爸车库里停着一辆锈迹斑斑的老式MGB跑车。有时候他居然能把它发动起来，然后带着我们绕着街区兜风，脸上总是洋溢着青春的狂野兴奋；在担心的乘客眼里，他简直是个疯子，在艾姆斯街头抛锚、回火，一路碾过锈迹斑斑的格雷姆林（Gremlin）和品托（Pinto），但他自己却觉得自己是达斯汀·霍夫曼（Dustin Hoffman），开着车驰骋在海湾大桥上，风吹拂着他的头发。

现在回想起来，这件事让我意识到人们与科技之间关系的两点。第一，浪漫情怀和形象塑造对人们的观点影响巨大。如果你对此有所怀疑（而且你又很闲），不妨问问那些拥有苹果电脑的人，看看他们是否也因此觉得自己属于受压迫的少数群体。

另一个略显微妙的点是，人机交互（Human-Computer Interaction）至关重要。诚然，MGB几乎在所有关键方面都糟糕透顶：反应迟钝、不可靠、动力不足。但它驾驶起来却乐趣十足。它反应灵敏。路上的每一颗小石子都能被清晰地传递到驾驶员的骨骼，路面的每一丝细微变化都能瞬间传递到驾驶员的双手。他可以聆听发动机的声音，并判断出它哪里出了问题。方向盘对他的手势指令反应迅速。对我们这些乘客来说，这不过是一场毫无意义的徒劳之旅——就像在别人身后窥视他往电子表格里输入数字一样无聊。但对驾驶员而言，这却是一次独特的体验。在短暂的时间里，他仿佛将自己的身体和感官延伸到了一个更广阔的领域，并完成了一些他独自一人无法完成的事情。

将汽车与操作系统进行类比还算不错，所以让我借此机会简要概括一下我们目前的情况。

想象一下，在一个十字路口，有四家相互竞争的汽车经销店。其中一家（微软）比其他两家规模大得多。微软多年前起步时，销售的是三速自行车（MS-DOS）；这些自行车并不完美，但能用，而且坏了也容易修。

隔壁有一家竞争对手自行车经销店（苹果公司），有一天开始销售机动车辆——价格昂贵但造型吸引人的汽车，其内部结构完全密封，因此其工作原理成了一个谜。

大型经销商迅速做出反应，推出了一款摩托车升级套件（最初的Windows系统）。这套装置结构复杂，就像鲁布·戈德堡机械（Rube Goldberg machine）一样，装在三速自行车上后，勉强能跟上苹果汽车的速度。使用者必须戴上护目镜，还得不停地从牙缝里抠虫子，而苹果车主则舒舒服服地坐在密封的车里飞驰，透过车窗冷笑。但与苹果汽车相比，微型摩托车价格低廉，维修也方便，因此市场份额迅速增长。

最终，这家大型经销商推出了一款完整的汽车：一辆庞大的旅行车（Windows 95）。它的外观就像苏联工人住宅楼一样丑陋，漏油漏垫圈，却取得了巨大的成功。不久之后，他们又推出了一款面向工业用户的笨重越野车（Windows NT），这款车的外观并不比旅行车好多少，可靠性也只是略胜一筹而已。

自那以后，虽然喧嚣声不断，但情况几乎没有改变。那家规模较小的经销商依然销售时尚的欧式轿车，并在广告宣传上投入巨资。他们的橱窗上贴着“即将倒闭！”的告示已经很久了，都泛黄卷曲了。而那家规模较大的经销商则不断生产越来越大的旅行车和越野车。

马路对面是两家最近才成立的竞争对手。

其中一家公司（Be公司）正在销售功能齐全的蝙蝠车（BeOS）。它们比欧洲轿车更漂亮、更时尚，设计更出色，技术更先进，可靠性至少与市场上其他任何产品一样好——而且价格比其他产品更便宜。

只有一个例外：Linux，它就在隔壁，而且根本不是一家公司。它是由一群房车、蒙古包、圆锥形帐篷和球形穹顶搭建在田野里，由大家协商组织而成。住在那里的人们正在制造坦克。这些可不是老式的苏联铸铁坦克；它们更像是美国陆军的M1坦克，采用太空时代材料制造，从头到尾都塞满了尖端科技。但它们比陆军坦克还要好。它们经过改装，永不发生故障，轻便灵活，足以在普通街道上行驶，而且油耗只比小型汽车低。这些坦克正在现场以惊人的速度批量生产，大量的坦克沿着路边一字排开，钥匙都插在点火开关上。任何人都可以免费坐进去开走。

日夜都有大批顾客涌向这个十字路口。其中90%的人会直接去最大的经销商那里购买旅行车或越野车。他们甚至都不会去看其他经销商。

剩下的百分之十人中，大多数人会去买一辆时尚的欧式轿车，他们只会停下来，对那些去买旅行车和越野车的庸俗之辈嗤之以鼻。如果他们注意到马路对面那些卖更便宜、技术更先进的车辆的人，这些顾客也会嘲笑他们是怪人和傻瓜。

蝙蝠车专卖店偶尔会卖一些车给想要第二辆车来搭配旅行车的汽车爱好者，但似乎也接受了自己只是个边缘玩家的现实，至少目前是这样。

这个免费发放坦克的组织之所以能维持下去，全靠志愿者们的辛勤付出。这些志愿者们手持扩音器，排成一排站在街边，努力吸引路人的注意，让他们了解这一不可思议的现象。典型的对话大概是这样的：
>黑客拿着扩音器：“省省钱吧！接受我们免费的坦克！它刀枪不入，能以每小时90英里的速度穿越岩石和沼泽，而且每加仑汽油能跑100英里！”
>
>一位想买旅行车的顾客：“我知道你说的是真的……但是……呃……我不知道怎么保养坦克！”
>
>扩音器：“你也不知道怎么保养旅行车！”
>
>顾客：“但是这家经销商有技工。如果我的旅行车出了问题，我可以请一天假，把它开过来，然后付钱让他们修，我只需要坐在候车室里听几个小时的电梯音乐就行了。”
>
>扩音器：“但是如果你接受我们免费的坦克，我们会派志愿者到你家来免费帮你修，你睡觉的时候就能修好！”
>
>顾客：“离我家远点，你这个怪胎！”
>
>扩音器：“但是……”
>
>顾客：“你没看到大家都在买旅行车吗？”
## 3. 比特投掷者 BIT-FLINGER
当时我坐着那辆MGB兜风的时候，根本想不到汽车和电脑交互方式之间有什么联系。那时我在艾姆斯高中报名参加了一门计算机编程课。上了几节入门课之后，我们几个学生被允许进入一个狭小的房间，里面有一台电传打字机（Teletype）、一部电话和一个老式调制解调器（Modem）——一个金属盒子，上面盖着两个橡胶垫（注：很多读者读到这句话的时候，可能会隐隐觉得这篇文章又要变成一篇枯燥乏味、老气横秋的怀旧文章，讲述我们以前的日子有多艰难；请放心，我其实是在为接下来要讲的真正时髦且与时俱进的话题——比如开源软件（Open Source Software）——做铺垫）。那台电传打字机和几十年来用来收发电报的机器一模一样。它基本上是一台噪音很大的打字机，只能打大写字母。它的一侧安装着一台较小的机器，上面装着一长卷纸带，下面是一个透明的塑料料斗。

为了将这台设备（它根本就不是电脑）连接到城另一头的爱荷华州立大学（Iowa State University）主机，你需要拿起电话，拨打电脑的号码，仔细聆听是否有异响，然后将听筒猛地按入橡胶套中。如果操作得当，一个橡胶套会包裹住听筒，另一个则会包裹住话筒，完成某种信息上的“六十九式”。电传打字机仿佛被远方主机的“灵魂”附身，开始颤抖，并敲击出晦涩难懂的信息。

由于计算机时间非常有限，我们使用了一种批处理（Batch Processing）技术。拨号之前，我们会先打开打孔机（一台固定在电传打字机侧面的辅助机器），然后输入我们的程序。每次按下按键，电传打字机就会在我们面前的纸上打出一个字母，这样我们就能读出自己输入的内容；但与此同时，它还会将字母转换成一组八个二进制数字，也就是比特（Bit），并在纸带上打出相应的孔洞。从纸带上掉下来的小纸片会飘落到透明的塑料料斗里，料斗会慢慢装满我们只能称之为比特的东西。在学年最后一天，班里最聪明的孩子（不是我）从课桌后面跳出来，把好几夸脱的比特像撒彩带一样撒到老师头上，这算是一种半开玩笑半表达爱意的恶作剧。这个人坐在那里，处于一种原始的战斗或逃跑反应（Fight-or-flight response）的初期阶段，数百万比特（兆字节）的数据从他的头发里渗入他的鼻孔和嘴里，随着他情绪的爆发，他的脸逐渐变成紫色，这是我接受正规教育以来最难忘的一幕。

总之，很明显，我与电脑的互动极其正式，被清晰地划分为几个阶段：
1. 我坐在家里，拿着纸笔，离任何电脑都远得很，我会仔细思考我想让电脑做什么，并将我的意图转化为一种计算机语言——纸上的一系列字母数字符号。
2. 我会带着这些符号穿过一道信息隔离带（三英里的雪堆）去学校，把这些字母输入到一台机器——不是电脑——它会将这些符号转换成二进制数，并清晰地记录在磁带上。
3. 然后，通过橡胶杯调制解调器，我会将这些数字发送到大学的主机，
4. 主机会对这些数字进行运算，并将不同的数字发送回电传打字机。
5. 电传打字机将这些数字转换回字母，并打印在纸上，
6. 我看着，会将这些字母解读为有意义的符号。

这一切所隐含的责任划分清晰明了：计算机对信息比特进行算术运算，而人类则将这些比特解读为有意义的符号。但随着现代操作系统的出现，这种区分正变得模糊，或者至少变得复杂。这些操作系统利用（甚至经常滥用）隐喻的力量，使计算机更容易被更广泛的用户群体所接受。在此过程中——或许正是因为这些隐喻将操作系统塑造成某种艺术品——人们开始对软件产生情感，并像我朋友的父亲对待他的MGB跑车那样，对软件产生依恋。

那些只通过图形用户界面（例如MacOS或Windows）与电脑交互的人——也就是说，几乎所有用过电脑的人——听到我1973年用电报机与电脑通信的故事，可能会感到惊讶，或者至少感到困惑。但使用这种特殊技术是有充分理由的。人类有各种各样的交流方式，例如音乐、艺术、舞蹈和面部表情，但其中一些比其他方式更容易用符号串来表达。书面语言是最简单的，因为它本身就是由符号串组成的。如果这些符号恰好属于音标字母（而不是例如表意符号），那么将它们转换成比特就非常简单，而且在19世纪初随着摩尔斯电码（Morse Code）和其他电报形式的出现，这项技术就已经被彻底解决了。

早在计算机出现之前的一百年，我们就有了人机交互界面。二战前后计算机出现时，人们很自然地将计算机与现有的文字和比特相互转换技术（例如电传打字机和穿孔卡片机）结合起来，从而与计算机进行交流。

这体现了两种截然不同的计算方式。使用卡片时，你需要一次性打孔一整叠卡片，然后全部通过读卡器，这叫做批处理。你也可以像我之前描述的那样，使用电传打字机通过纸带阅读器进行批处理，我在高中时也确实被鼓励使用这种方法。但是——尽管有人试图让我们对此一无所知——电传打字机可以做到卡片阅读器做不到的事情。在电传打字机上，一旦调制解调器连接建立，你只需输入一行文字，然后按下回车键。电传打字机会将这一行文字发送到计算机，计算机可能会也可能不会回复几行文字，电传打字机会逐行输出——随着时间的推移，最终生成你与计算机交互的记录。这种方法当时甚至还没有名字，但很久以后，当出现另一种替代方案时，它被追溯性地称为命令行界面（Command Line Interface）。

上了大学之后，我的计算机课是在又大又闷的房间里进行的，几十个学生坐在略微升级过的同款机器前编写程序：这些机器使用点阵打印机制，但（从计算机的角度来看）和老式电传打字机没什么区别。那时，计算机的分时性能（Time-sharing）已经有所提升——也就是说，大型机依然是大型机，但它们能更好地同时与大量终端通信。因此，批处理不再必要。读卡器被搬到了走廊和锅炉房，批处理成了极客们的专属，因此，在我们这些曾经知道它存在的人眼里，它也带上了一种神秘莫测的色彩。我们都告别了批处理，转而使用命令行界面——如果我当时知道的话，这将会是我操作系统范式的第一次转变。

每台这些堪称“豪华”的电传打字机下方，地板上都堆着一大摞摞折叠纸，数英里的纸张在滚筒间颤抖着滑过。几乎所有这些纸张都未经油墨处理就被丢弃或回收——这种对环境的破坏如此触目惊心，以至于这些机器很快就被视频终端——所谓的“玻璃电传打字机”（Glass Teletype）——所取代，后者噪音更小，也不浪费纸张。然而，从计算机的角度来看，这些机器与二战时期的电传打字机并无二致。实际上，直到1984年左右，我们仍然在使用维多利亚时代的科技与计算机进行通信，直到Macintosh电脑及其图形用户界面问世。即便在那之后，命令行仍然作为一种底层机制——一种大脑的本能反应——在许多现代计算机系统中持续存在，贯穿了图形用户界面（以下简称GUI）的鼎盛时期。
## 4. 图形用户界面 GUIs
现在，任何程序员在编写新软件时，首先要做的就是弄清楚如何将正在处理的信息（在图形程序中是图像，在电子表格中是数字网格）转换成线性的字节串。这些字节串通常被称为文件（File），或者（更时髦地）称为数据流（Data Stream）。它们之于电报，就像现代人之于克罗马农人（Cro-Magnon）——换个说法，意思是一样的。你在电脑屏幕上看到的一切——你的《古墓丽影》（Tomb Raider）游戏、你的数字化语音邮件、传真，以及用37种不同字体编写的文字处理文档——从计算机的角度来看，仍然和电报没什么两样，只不过更长，需要更多的运算。

最快捷的体验方法是打开网络浏览器，访问一个网站，然后选择“查看/文档源代码”（View / Document Source）菜单项。你会看到类似这样的计算机代码：
```
<HTML>
 <HEAD>
```
<TITLE> C R Y P T O N O M I C O N</TITLE>（密码学）

```
</HEAD>
 <BODY BGCOLOR="#000000" LINK="#996600" ALINK="#FFFFFF" VLINK="#663300">
``` 
这种乱七八糟的东西叫做HTML（超文本标记语言，HyperText Markup Language），它本质上是一种非常简单的编程语言，用来指示你的网页浏览器如何在屏幕上绘制页面。任何人都可以学习HTML，而且很多人都在学。重要的是，无论HTML文件能够呈现多么精彩的多媒体网页，它们本质上都只是电报。罗纳德·里根（Ronald Reagan）当电台播音员的时候，他解说棒球比赛的方式就是读电报线上打印出来的简短描述。他会独自坐在一个铺着软垫的房间里，手里拿着麦克风，看着印着晦涩缩写的纸带缓缓从机器里滑出来，爬过他的手掌。如果比分是三好两坏，里根就会根据脑海中的画面描述：“强壮的左投手走出击球区，擦了擦额头的汗。裁判上前清扫本垒板上的泥土。”等等。当纸带上的密码报宣布击出安打时，他会用铅笔敲击桌沿，发出轻微的音效，并描述球的飞行轨迹，仿佛他真的能看到一样。他的听众，其中许多人大概都以为里根真的在球场上观看比赛，会根据他的描述在脑海中重现当时的场景。万维网（World Wide Web）的运作方式正是如此：HTML 文件就像纸带上简洁的描述，而你的网络浏览器就是罗纳德·里根。图形用户界面通常也是如此。因此，操作系统就像一堆隐喻和抽象概念，横亘在你和电报之间，体现了程序员用来将你正在处理的信息——无论是图像、电子邮件、视频还是文字处理文档——转换成计算机唯一能够处理的字节串的各种技巧。当我们使用真正的电报设备（电传打字机）或其更先进的替代品（例如“玻璃电传打字机”或 MS-DOS 命令行）来操作计算机时，我们几乎处于信息堆栈的最底层。然而，当我们使用大多数现代操作系统时，我们与机器的交互受到高度中介。我们所做的每一件事都会被反复解释和转换，最终通过各种隐喻和抽象层层传递。 Macintosh 操作系统在“革命”一词的意义上既有好的一面，也有坏的一面。显然，命令行界面并不适合所有人，让计算机更容易被非技术用户使用是一件好事——即便不是出于利他主义，也是因为这类人群构成了一个无比庞大的市场。很明显，Mac 的工程师们看到了一个全新的领域在他们面前展开；你几乎可以听到他们低声说道：“哇！我们再也不用被线性字节流的文件所束缚了，革命万岁！”让我们看看我们能把这玩意儿玩到什么程度！”Macintosh 上没有命令行界面；你只能用鼠标跟它交互，否则就什么都做不了。这算是一种宣言，一种革命性纯粹性的证明。Mac 的设计者似乎打算把命令行界面扫进历史的垃圾堆。我个人对 Macintosh 的热爱始于 1984 年春天，在爱荷华州锡达拉皮兹（Cedar Rapids, Iowa）的一家电脑商店里，我的一个朋友——巧合的是，他正是 MGB 老板的儿子——给我展示了一台运行着 MacPaint（一款革命性的绘图程序）的 Macintosh。这段情缘在 1995 年 7 月戛然而止，当时我试图在我的 Macintosh Powerbook 上保存一个重要的大文件，结果它非但没有保存，反而彻底摧毁了数据，以至于两个不同的磁盘崩溃修复程序都找不到任何痕迹。在接下来的十年里，我对 macOS 的热情在当时看来是正当合理的，但现在回想起来却……我当时对图形用户界面（GUI）的痴迷程度，跟我朋友的爸爸对他的车的痴迷程度如出一辙。Mac 的问世在计算机界引发了一场激烈的争论。GUI 究竟是让计算机更加人性化、从而更容易被大众接受的卓越设计创新，引领人类社会走向前所未有的革命，还是旧金山湾区（San Francisco Bay Area）那些古怪的黑客们炮制出来的、令人作呕的视听噱头，剥夺了计算机的强大功能和灵活性，把原本高尚严肃的计算机工作变成了幼稚的电子游戏？如今看来，这场争论比 20 世纪 80 年代中期更有意思。但当微软推出第一代 Windows 系统，正式认可 GUI 理念后，人们基本上停止了这场争论。此时，命令行拥护者被贬为一群老顽固，而 MacOS 用户和 Windows 用户之间又爆发了一场新的冲突。争论的话题层出不穷。即使在当时，第一代 Macintosh 的外观也与其他 PC 截然不同。它们被关闭了：它们由一个盒子组成，盒子里既包含CPU（计算机中负责比特运算的部分），也包含显示器屏幕。当时，这被宣传为一种哲学宣言：苹果公司想把个人电脑变成像烤面包机一样的家用电器。但这同时也反映了运行图形用户界面（GUI）的纯粹技术要求。在GUI机器中，负责在屏幕上绘制图形的芯片必须与计算机的中央处理器（CPU）高度集成，这远比命令行界面的情况要复杂得多。直到最近，命令行界面甚至都不知道自己不是在和电传打字机对话。这种区别本质上是技术和抽象的，但当机器崩溃时，这一点就变得更加清晰了（通常情况下，通过观察技术的故障，可以更好地了解其工作原理）。当一切都崩溃，CPU开始胡乱输出数据时，在命令行机器上，屏幕上会出现一排排排列整齐但随机的字符——行家们称之为“西里尔字母乱码”（Cyrillic Garbage）。但对于MacOS来说，屏幕不是电传打字机，而是用来显示图形的地方；屏幕上的图像是位图（Bitmap），是对计算机内存特定部分内容的直接渲染。当计算机崩溃并将乱码写入位图时，结果看起来就像坏掉的电视机上的雪花屏——“雪花崩溃”（Snow Crash）。即使在Windows出现之后，这些根本性的差异依然存在；当Windows机器出现问题时，旧的命令行界面会像石棉防火帘一样覆盖在图形用户界面上，就像防火帘遮挡着燃烧的歌剧院的舞台一样。而当Macintosh出现问题时，它会显示一个炸弹的卡通图像，第一次看到时会觉得很有趣。这些差异绝非表面现象。 Windows 在陷入困境时回归命令行界面，这让 Mac 的拥趸们意识到，Windows 只不过是一个廉价的伪装，就像一块艳俗的毯子随意搭在破旧的沙发上。他们感到不安和恼火，因为 Windows 表面上友好的用户界面下隐藏着——字面意义上的——某种潜台词。而 Windows 的粉丝们或许会愤愤不平地指出，所有电脑，甚至包括 Macintosh，都是建立在同样的潜台词之上的，而 Mac 用户拒绝承认这一点，似乎表明他们乐于被欺骗，甚至可以说是渴望被欺骗。总之，Macintosh 需要快速地、以任意复杂的模式切换显卡内存芯片中的单个位。如今这既便宜又容易，但在20世纪80年代初的技术环境下，唯一现实可行的方法是将主板（包含CPU）和视频系统（包含映射到屏幕上的内存）紧密集成在一起——因此才有了Macintosh那独特的单层密封机箱。Windows问世之初，其丑陋的外观令人瞩目，而它的继任者Windows 95和Windows NT也同样不讨人喜欢。微软对美学的全然漠视，让我们这些Mac爱好者有无数机会鄙视它。Windows看起来简直就是MacOS的直接抄袭，这更让我们义愤填膺。在真正了解和欣赏计算机的人群（史蒂文·列维（Steven Levy）对“黑客”一词的非贬义定义）以及其他一些小众群体，例如专业音乐家、平面设计师和教师中，Macintosh 电脑一度就是计算机的代名词。它不仅被视为一项卓越的工程技术，但微软却被视为运用科技造福人类的某些理念的化身，而Windows则被视为拙劣的模仿和阴谋诡计的结合体。因此，很早就形成了一种模式，并延续至今：人们不喜欢微软，这无可厚非；但他们不喜欢微软的理由却考虑不周，最终只会适得其反。
## 5. 桌面上的阶级斗争 CLASS STRUGGLE ON THE DESKTOP
既然我们已经牢牢抓住了“第三条轨道”（指敏感话题），那么有必要回顾一些基本事实：像任何其他上市的营利性公司一样，微软实际上从某些人（其股东）那里借了一大笔钱才得以涉足这个行业。作为这家公司的掌舵人，比尔·盖茨只有一个职责，那就是最大化投资回报。他在这方面做得非常出色。微软在世界上采取的任何行动——例如，他们发布的任何软件——基本上都是附带现象，只有从比尔·盖茨履行其唯一职责的角度来看，这些行动才能被解释或理解。

由此可见，如果微软销售的产品外观不佳或性能欠佳，并不意味着他们是庸俗之辈或愚钝之徒。这是因为微软卓越的管理层已经意识到，与其追求产品美观或完美无瑕，不如推出带有明显缺陷的产品，这样更能为股东创造利润。这固然令人恼火，但最终远不及眼睁睁看着苹果公司莫名其妙地、无情地自我毁灭来得令人恼火。

在网络上，对微软的敌意随处可见，这种敌意大致可以分为两类：一类是怨恨微软权力过大的人，另一类是鄙夷微软庸俗不堪的人。这一切都让人不禁想起共产主义和社会主义的鼎盛时期，那时资产阶级可谓是祸不单行：无产阶级憎恨他们拥有巨额财富，知识分子则憎恨他们挥霍无度，把钱花在草坪装饰品上。微软正是现代高科技繁荣的化身——简而言之，它是资产阶级的——因此也招致了同样的诟病。

微软 Word 6.0 的启动画面可谓一针见血：程序启动时，映入眼帘的是一支昂贵的珐琅钢笔横放在几张精美的手工书写纸上。这显然是为了让软件看起来更高端，或许对某些人来说效果不错，但对我来说却不尽如人意，因为那支笔是圆珠笔，而我偏爱钢笔。如果是苹果公司来做，他们肯定会用万宝龙（Mont Blanc）钢笔，或者中国毛笔。而且我怀疑这绝非偶然。最近我花了不少时间在一台家用电脑上重装 Windows NT 系统，期间多次需要双击“控制面板”（Control Panel）图标。出于某种难以理解的原因，这个图标竟然是一把羊角锤和一把凿子或螺丝刀放在一个文件夹上。

这些美学上的失误让人几乎无法抑制地想要嘲笑微软，但话说回来，这一切都无关紧要——如果微软当初对可能的替代图形进行过焦点小组测试（Focus Group），他们很可能会发现，普通中层办公室职员会将钢笔与软弱无能的高管联系起来，而更喜欢圆珠笔。同样，那些普通人，那些可能承担着设置和维护家用电脑重任的秃顶老爸们，或许更容易接受一把羊角锤的图片——尽管他们可能还幻想过用一把真正的羊角锤来修理那些出故障的电脑。

这是我唯一能解释当前操作系统市场某些奇特现象的方法，例如，尽管街对面就有免费的坦克可以拿，但 90% 的客户仍然从微软购买旅行车。

对比尔·盖茨来说，分发一串0和1并不难，这个想法他早就想到了。难的是如何推销它——如何让客户相信他们花钱确实能得到回报。

凡是在商店买过软件的人，都经历过那种令人沮丧的体验：把包装精美的软件带回家，撕开包装，发现里面95%都是空气，扔掉所有的小卡片、赠品和杂物，然后把光盘装进电脑。最终结果（光盘丢了之后）除了电脑屏幕上的一些图像和一些之前没有的功能之外，什么也没有。有时候甚至连这些都没有——取而代之的是一连串的错误信息。但你的钱肯定是打了水漂。现在我们几乎已经习以为常，但在二十年前，这可是个非常冒险的商业模式。比尔·盖茨却成功了。他并没有靠卖最好的软件或提供最低的价格来取得成功。相反，他设法让人们相信，他们花钱是物有所值的。

世界各地城市的街道上都挤满了那些笨重、嘎嘎作响的旅行车。没有这种车的人会觉得有点怪异，不由自主地会想，是不是该放弃抵抗，买一辆了；而拥有这种车的人，即使在车子被抬到汽车修理厂的升降机上维修的日子里，也觉得自己拥有了一件意义非凡的物品。

这一切都与资产阶级身份完全吻合，资产阶级既是一种精神状态，也是一种物质状态。这也解释了为什么微软经常在网络上遭到来自各方的攻击。那些倾向于感到贫穷和受压迫的人会将微软的一切行为解读为某种险恶的奥威尔式（Orwellian）阴谋。而那些自认为聪明且精通技术的用户则会被Windows系统的笨拙操作搞得抓狂。

对见多识广的人来说，最令人恼火的莫过于看到一个有钱人穿着俗气——除非他们转瞬之间意识到，这些人可能也知道自己俗气，只是毫不在乎，而且会一直这样俗气下去，继续富有，继续快乐下去。因此，微软与硅谷精英的关系，就像《贝弗利山庄人》（The Beverly Hillbillies）里的乡巴佬们与他们那挑剔的银行家德莱斯代尔先生（Mr. Drysdale）的关系一样——德莱斯代尔先生恼火的并非克莱佩特一家（The Clampetts）搬到他家附近，而是他知道，等杰斯罗（Jed Clampett）七十岁的时候，他还会像个乡巴佬一样说话，穿着背带裤，而且还会比他富有得多。

即使是运行Windows系统的硬件，与苹果公司推出的机器相比，看起来也像是廉价货，而且现在大多依然如此。原因在于，苹果过去是、现在也是一家硬件公司，而微软过去是、现在也是一家软件公司。因此，苹果垄断了能够运行macOS的硬件市场，而兼容Windows的硬件则来自自由市场。自由市场似乎已经决定，人们不会为外观炫酷的电脑买单；那些聘请设计师来打造独特外观的PC硬件制造商，最终会被台湾的克隆厂商（Clone Maker）碾压，后者生产的电脑看起来就像是放在某人拖车前用砖块砌成的简易机箱。但苹果可以随心所欲地设计硬件，然后把更高的价格转嫁给像我这样被苹果迷得神魂颠倒的消费者。就在上周（我写下这句话时是1999年1月初），所有报纸的科技版面都充斥着对苹果公司发布新款iMac的赞誉之词，比如蓝莓色和橘色。

除了上世纪90年代中期短暂允许克隆机厂商（Clone Maker）与其竞争，苹果一直坚持硬件垄断地位，但随后又将这些厂商挤出了市场。因此，Macintosh硬件价格昂贵。你不会轻易打开它进行改装，因为这样做会使保修失效。事实上，第一代Mac的设计初衷就是为了难以打开——你需要一套特殊的工具，而这些工具可以通过Mac上市几个月后出现在杂志封底的小广告购买。这些广告总是给人一种不太光彩的感觉，就像那些在低俗侦探杂志封底刊登的开锁工具广告一样。

这种垄断政策至少可以用三种不同的方式来解释。
*   比较宽容的解释是，苹果的硬件垄断政策反映了其致力于实现硬件、操作系统和软件无缝、统一融合的决心。这种说法不无道理。要开发一款能在特定硬件上良好运行的操作系统已经相当困难，而这款硬件是由与你同在一家公司、在你隔壁办公室工作的工程师设计和测试的。更何况，要让操作系统能在国际日期变更线另一侧那些疯狂的克隆厂商生产的任意硬件上运行，难度更是惊人，这也正是人们在使用Windows时遇到诸多问题的原因。
*   从财务角度解释，苹果与微软不同，它始终是一家硬件公司。它完全依赖于硬件销售收入，没有硬件收入，它就无法生存。
*   这种不太友善的解释与苹果公司的企业文化有关，而这种企业文化根植于旧金山湾区的婴儿潮时期（Baby Boomer Era）。

既然我要稍微谈谈文化，那我觉得有必要先坦白一下，以免被指责利益冲突和道德败坏：（1）从地理位置上看，我是西雅图人，性格比较忧郁，对旧金山湾区那种狂欢作乐的氛围总是抱有偏见，就像他们往往对我们感到恼火和反感一样。（2）从年龄上看，我是后婴儿潮一代（Post-Boomer）。至少我是这么觉得的，因为我从未体验过婴儿潮一代生活中那些有趣刺激的部分——我只是花了很多时间，尽职尽责地听着他们那些关于自己如何嗨翻天的无聊轶事，并礼貌地回应他们关于自己音乐有多棒的吹嘘。即使隔着这么远的距离，也能看出一些规律，其中一个像都市传说一样经常出现的规律是：有人搬进一个由穿着凉鞋、比划着和平手势的嬉皮士组成的公社，最终发现，在这层表象之下，管理公社的人实际上是控制狂；而且，由于生活在一个口头上崇尚和平、爱与和谐的公社里，剥夺了他们正常的、社会认可的控制狂发泄渠道，他们的控制狂倾向往往会以其他方式表现出来，而且总是更加险恶。

将此方法应用到苹果电脑公司案例中，留给读者作为练习，而且这并不难。

乍一看，把苹果公司想象成一个控制狂确实有点让人不安，因为这与他们的企业形象完全不符。难道不是他们播放过著名的超级碗（Super Bowl）广告吗？广告里，一群西装革履、蒙着眼睛的高管像旅鼠一样跳下悬崖。难道不是这家公司现在还在广告里播放达赖喇嘛（Dalai Lama）（香港除外）、爱因斯坦（Einstein）和其他特立独行的反叛者的形象吗？

这的确是同一家公司，而他们竟然能在这么多见多识广、饱经媒体洗礼的怀疑论者心中，成功塑造出富有创造力、桀骜不驯的自由思想者的形象，着实令人深思。这既证明了昂贵而精良的广告宣传具有多么强大的影响力，也可能反映了那些轻信广告的人们心中某种程度的美好愿望。这也引出了一个问题：为什么微软的公关能力如此糟糕？苹果的历史表明，只要给优秀的广告公司开出巨额支票，就能在聪明人的脑海中植入一个与现实完全不符的企业形象。 （对于那些不喜欢达摩克利斯之剑（Sword of Damocles）式问题的人来说，答案是：既然微软已经赢得了沉默的大多数——资产阶级——的心，他们就根本不在乎拥有光鲜亮丽的形象，就像尼克松（Nixon）当年一样。“我想相信”（I Want to Believe）——《X档案》（The X-Files）中福克斯·穆德（Fox Mulder）贴在办公室墙上的那句口头禅——对这两家公司有着不同的适用方式；苹果的拥趸们想要相信苹果在广告中塑造的形象，以及苹果电脑与其他电脑有着本质区别的观念，而Windows用户则想要相信他们花钱买到了物有所值的产品，参与了一笔体面的商业交易。）

总之，截至 1987 年，MacOS 和 Windows 都已上市，运行在彼此截然不同的硬件平台上——不仅因为 MacOS 使用的是摩托罗拉（Motorola） CPU 芯片，而 Windows 使用的是英特尔（Intel） CPU 芯片，而且——当时被忽视，但从长远来看，这一点更为重要——苹果硬件业务是一个严格的垄断，而 Windows 方面则是一个瞬息万变的自由竞争市场。

但直到最近，这件事的全部影响才逐渐明朗——事实上，这些影响仍在以极其奇特的方式展开，这一点我会在讲到Linux时详细解释。结果是，数以百万计的人已经习惯了以各种形式使用图形用户界面（GUI）。通过这种方式，他们为苹果/微软赚取了巨额利润。许多人的命运都与这些公司能否继续销售那些销量存疑的产品息息相关。
## 6. 蜜罐、焦油坑，随便什么都行 HONEY-POT, TAR-PIT, WHATEVER
当盖茨和艾伦提出软件销售的概念时，他们遭到了黑客和务实商人的双重批评。黑客们认为软件不过是信息，因此反对出售软件。这种反对部分出于道德考量。黑客们来自科学和学术界，在他们看来，将研究成果免费公开是至关重要的。他们的反对也部分出于实际考虑：如何才能出售一种很容易被复制的东西呢？商人与黑客在很多方面截然相反，他们也有自己的反对意见。习惯于销售烤面包机和保险单的商人，自然很难理解一长串0和1如何能构成一种可销售的产品。

显然，微软和苹果都克服了这些反对意见。但这些反对意见依然存在。所有黑客中最像黑客的，或者说是黑客鼻祖，是理查德·斯托曼（Richard Stallman）。他对软件销售这种邪恶的做法深恶痛绝，于是在1984年（也就是Macintosh上市的同一年），他创立了自由软件基金会（Free Software Foundation），并开始着手开发GNU。GNU是“GNU's Not Unix”（GNU不是Unix）的递归缩写，但这其实是个玩笑，因为GNU实际上就是Unix。由于商标问题（“Unix”是AT&T的注册商标），他们不能声称GNU是Unix，所以为了万无一失，他们干脆否认了这一点。尽管斯托曼先生和其他GNU拥护者拥有无与伦比的才华和干劲，但他们构建一个自由Unix系统来与微软和苹果的操作系统竞争的项目，就像试图用茶匙挖地铁系统一样困难。直到Linux的出现，情况才有所改变，我稍后会详细介绍Linux。

但是，从零开始重新创建操作系统这一基本思路完全合理，也完全可行。事实上，这种做法已经多次成功。这本身就是操作系统固有的特性。

操作系统并非绝对必要。只要程序员足够专注，完全可以从零开始，为每个项目编写全新的代码来处理诸如控制磁盘驱动器读写磁头和点亮屏幕像素等基础底层操作。最早的计算机就是这样编程的。但由于几乎每个程序都需要执行这些相同的基本操作，这种方法会导致大量的重复劳动。

对黑客来说，最令人厌恶的莫过于重复劳动。人们学习编写计算机程序时养成的首要也是最重要的思维习惯就是概括、概括、再概括。为了使代码尽可能模块化和灵活，需要将大型问题分解成可以在不同场景下反复使用的小型子程序。因此，操作系统的开发，尽管从技术上讲并非必要，却也是必然的。因为操作系统的本质就是一个库（Library），其中包含了最常用的代码，这些代码编写一次（希望编写得当），然后提供给所有需要的程序员。

因此，专有、封闭、秘密的操作系统本身就是自相矛盾的。它违背了操作系统存在的意义。而且，无论如何，操作系统的秘密都无法完全保密。源代码（Source Code）——程序员编写的原始文本——可以保密。但操作系统整体是由许多执行非常具体、非常明确的任务的子程序组成的。这些子程序的具体功能必须公开，而且必须非常明确、精确地公开，否则操作系统对程序员来说就完全没用；如果程序员不完全了解这些子程序的功能，就无法使用它们。

唯一未公开的是子程序的具体实现方式。但一旦你了解了某个子程序的功能，通常来说（如果你是个黑客），编写一个功能完全相同的子程序就相当容易了。这可能需要一些时间，而且过程枯燥乏味，没什么成就感，但在大多数情况下，其实并不难。

无论是黑客技术还是小说创作，难点都不在于写作，而在于决定写什么。而商业操作系统厂商们早已做出了决定，并且公布了他们的决定。

这一点早已被普遍理解。MS-DOS 的功能被一款名为 ProDOS 的竞争对手产品完全复制，后者从零开始编写，几乎以相同的方式实现了所有相同的功能。换句话说，另一家公司能够编写出与 MS-DOS 功能完全相同的代码，并从中获利。如果您使用的是 Linux 操作系统，您可以获取一个名为 WINE 的免费程序，它是一个 Windows 模拟器（Windows Emulator）；也就是说，您可以在桌面上打开一个窗口来运行 Windows 程序。这意味着一个功能齐全的 Windows 操作系统被重新创建在 Unix 系统中，就像把船装进了瓶子里一样。而 Unix 本身比 MS-DOS 复杂得多，它已经过多次从零开始构建。Sun、惠普（HP）、AT&T、Silicon Graphics、IBM 等公司都在销售 Unix 的各种版本。

换句话说，人们重写基础操作系统代码已经如此之久，以至于构成传统意义上（图形用户界面出现之前）“操作系统”的所有技术如今都变得如此廉价和普及，以至于它们实际上是免费的。盖茨和艾伦今天不仅卖不出去MS-DOS，甚至连免费赠送都做不到，因为功能更强大的操作系统早已免费提供。就连最初的Windows（在1995年之前是唯一的Windows系统）也变得毫无价值，因为拥有一个可以在Linux（本身也是免费的）中模拟的东西毫无意义。

由此可见，操作系统行业与汽车行业截然不同。即使是一辆破旧的老车也具有一定的价值。你可以用它去垃圾场，或者拆解零件。而制成品的命运就是随着使用年限的增长，以及与更现代的产品竞争，逐渐贬值。

但操作系统注定要走向自由。

微软是一家卓越的软件应用公司。应用软件（Application Software）——例如 Microsoft Word——是创新为用户带来切实、直接、可观收益的领域。这些创新可能是研发部门（Research & Development, R&D）直接推出的新技术，也可能是一些花哨的功能，但无论如何，它们通常都非常实用，而且似乎能让用户满意。微软正在努力成为一家卓越的研发公司。然而，微软并非一家卓越的操作系统公司。这并非是因为他们的操作系统从纯粹的技术角度来看有多糟糕。诚然，微软的操作系统也存在一些问题，但它们比以前好得多，而且足以满足大多数用户的需求。

那么，我为什么说微软不是一家伟大的操作系统公司呢？因为操作系统的本质决定了它不应该由一家特定的公司开发和拥有。首先，这是一项吃力不讨好的工作。应用程序为数百万轻信的用户创造了无限可能，而操作系统却限制了成千上万脾气暴躁的程序员，因此，操作系统开发商永远都会被高科技界任何有影响力的人列入黑名单。应用程序的用户面临的最大问题是理解其所有功能，而操作系统却被那些因自身局限性而恼火的程序员破解。操作系统业务对微软来说唯一的好处就是它提供了启动真正优秀的应用程序业务和聘请大量优秀研究人员所需的资金。现在，它真的应该像火箭上用过的助推器一样被抛弃。关键问题是，微软是否有能力做到这一点。或者，它是否像苹果公司对硬件销售一样，对操作系统销售产生了依赖？

请记住，苹果公司垄断硬件供应的能力曾被一些博学的观察家视为其相对于微软的一大优势。当时，这似乎让苹果处于更有利的地位。然而最终，这几乎毁了苹果，而且未来可能还会再次毁掉苹果。对苹果而言，问题在于世界上大多数电脑用户最终都拥有了价格更低的硬件。但这些廉价硬件无法运行macOS，因此这些人转而使用Windows系统。

把“硬件”换成“操作系统”，把“苹果”换成“微软”，你会发现同样的事情即将重演。微软主导着操作系统市场，这让他们赚得盆满钵满，而且目前看来似乎是个好主意。但是，更便宜、更好的操作系统已经出现，并且在计算机普及率不如美国高的地区越来越受欢迎。十年后，世界上大多数计算机用户最终可能会使用这些更便宜的操作系统。但就目前而言，这些操作系统无法运行任何微软应用程序，因此这些人会选择其他系统。

更直白地说：每当有人选择使用非微软操作系统时，微软的操作系统部门显然就会失去一位客户。但就目前情况而言，微软的应用软件部门也会失去一位客户。只要几乎所有人都在使用微软操作系统，这倒也无妨。但一旦Windows的市场份额开始下滑，对于雷德蒙德（Redmond，微软总部所在地）的微软人来说，形势就相当严峻了。

有人可能会反驳说，微软完全可以重新编译其应用程序，使其能在其他操作系统上运行。但这种策略违背了大多数企业的正常运作模式。苹果的例子再次发人深省。当苹果的处境开始走下坡路时，他们本应将操作系统移植到廉价的PC硬件上。但他们没有。相反，他们试图充分利用其卓越的硬件，不断添加新功能并扩展产品线。但这最终却导致他们的操作系统更加依赖这些特殊的硬件功能，反而对他们自身造成了更大的损害。

同样，当微软在操作系统领域的地位受到威胁时，其企业本能会驱使他们向操作系统中添加更多新功能，然后重新调整软件应用程序以利用这些特殊功能。但这只会使他们的应用程序依赖于一个市场份额不断下降的操作系统，最终对他们自身造成更大的损害。

操作系统市场简直就是个死亡陷阱，一个泥潭，一片绝望的沼泽。投资苹果和微软只有两个理由：(1) 这两家公司都与客户存在着一种我们称之为“相互依赖”（Codependency）的关系。客户想要相信，而苹果和微软知道如何满足他们的需求。(2) 这两家公司都竭尽全力为操作系统添加新功能，这至少在短期内能够巩固客户的忠诚度。

因此，本文余下的大部分内容将围绕这两个主题展开。
## 7. 技术圈 THE TECHNOSPHERE
Unix 是唯一一个图形用户界面（一套名为 X Window 系统的庞大代码套件）与操作系统本身在传统意义上完全分离的操作系统。也就是说，如果你愿意，你可以完全以命令行模式运行 Unix，没有任何窗口、图标、鼠标等等，它仍然是 Unix，并且能够完成 Unix 应该做的一切。但是其他操作系统，例如 macOS、Windows 系列和 BeOS，它们的图形用户界面与传统的操作系统功能紧密交织，以至于它们必须以图形用户界面模式运行，否则就无法真正运行。因此，现在已经无法将图形用户界面视为与操作系统分离的独立部分；它们现在是操作系统不可分割的一部分——而且是迄今为止最大的组成部分，也是迄今为止最昂贵、最难创建的部分。

销售产品只有两种方式：价格和功能。当操作系统免费时，操作系统公司无法在价格上竞争，因此它们只能在功能上展开竞争。这意味着它们总是试图超越彼此，编写一些直到最近才被视为操作系统组成部分的代码：例如图形用户界面（GUI）。这在很大程度上解释了这些公司的行为方式。

例如，这就解释了为什么微软会在其操作系统中添加浏览器。获取免费浏览器和免费操作系统一样容易。如果浏览器和操作系统都是免费的，似乎就无法从中盈利。但如果能将浏览器集成到操作系统中，从而为两者赋予新功能，那么就拥有了可销售的产品。

暂且不谈这会激怒政府的反垄断律师，这个策略本身是有道理的。至少，如果你假设（就像微软管理层似乎认为的那样）操作系统必须不惜一切代价得到保护，那么这个策略就说得通。真正的问题在于，是否应该把所有涌现的新技术趋势都当作拐杖，来维持操作系统的主导地位。面对互联网的崛起，微软不得不开发一款优秀的浏览器，而他们也确实做到了。但随后他们面临一个选择：他们可以让这款浏览器兼容多种不同的操作系统，这样无论操作系统市场份额如何变化，微软都能在互联网领域占据稳固的地位。或者，他们也可以将浏览器与操作系统融为一体，赌一把这会让操作系统看起来更加现代化、更具吸引力，从而有助于他们保住在该市场的主导地位。问题在于，当微软的操作系统地位开始动摇时（鉴于其目前约占90%的市场份额，它只能继续下滑），它将拖垮其他一切。

你在高中地质课上可能学过，地球上所有生命都存在于一层薄如纸片的生物圈（Biosphere）中，它被包裹在脚下数千英里厚的死寂岩层和上方冰冷、死寂且充满放射性的太空之间。销售操作系统的公司则存在于某种技术圈（Technosphere）中。技术圈之下是已经实现自由化的技术，而技术圈之上则是尚未开发或过于天马行空、尚无法产品化的技术。就像地球的生物圈一样，技术圈与上下两层相比也显得非常薄。

但它的演化速度要快得多。在世界各地，人们可以参观丰富的化石层，那里骨骼层层叠叠，较新的骨骼堆在上面，更古老的骨骼则在下面。理论上，它们可以追溯到最早的单细胞生物。如果你稍微发挥一下想象力，就能明白，如果你在那里待得足够久，你也会变成化石，而随着时间的推移，某种更高级的生物也会在你之上变成化石。

软件技术的化石记录——拉布雷亚沥青坑（La Brea Tar Pits）——就是互联网。任何出现在互联网上的东西都可以免费获取（可能违法，但免费）。像微软这样的公司的管理人员必须习惯这种在其他行业难以想象的现象：他们投入数百万美元开发新技术，例如网络浏览器，然后发现相同或类似的软件在两年、一年甚至几个月后就出现在互联网上。

通过不断开发新技术并为产品添加功能，他们可以始终领先于化石化进程一步，但在某些时候，他们一定感觉自己就像被困在拉布雷亚火山口的猛犸象（Mammoth），用尽全力一次又一次地将脚从想要覆盖和吞噬他们的滚烫沥青中拔出来。

在这个生物圈中生存，需要企业一端拥有锋利的獠牙和强劲的步伐，而微软正是以这些著称。但仅仅把其他巨头踩进焦油里，也只能让你苟延残喘一时。危险在于，这些公司一心只想避免被时代淘汰，却忽略了生物圈之上的领域：新兴科技。换句话说，它们必须保留原始的武器和粗犷的竞争本能，同时也要进化出强大的智慧。微软似乎正在通过其研发部门来实现这一点，该部门一直在大举招揽聪明人才（这里我应该说明一下，虽然我认识微软研发部门的几位同事，也和他们保持着联系，但我们从不谈论业务，我对他们的研究方向也几乎一无所知。通过使用Linux操作系统，我对微软的了解远比使用Windows要多得多）。

别管微软过去如何赚钱；如今，它靠的是一种时间套利（Time Arbitrage）。“套利”通常指的是利用不同市场间商品价格的差异来获利。换句话说，它具有空间性，关键在于套利者必须掌握不同地点同时发生的情况。微软正是通过利用不同时期技术的价格差异来赚钱。如果允许我创造一个新词，那么时间套利的关键在于套利者必须知道人们明年会为哪些技术付费，以及这些技术会在多久之后免费。空间套利和时间套利的共同之处在于，两者都依赖于套利者掌握极其丰富的信息；前者需要了解特定时间不同地点的价格梯度，后者则需要了解特定地点不同时期的价格梯度。

因此，苹果和微软几乎每天都在向用户推送新功能，希望源源不断的真正技术创新，再加上“我想相信”的心理，能够阻止用户转向那些更便宜、更好的操作系统。问题是，从长远来看，这种做法是否可行。如果微软像苹果对硬件那样对操作系统上瘾，那么他们就会把所有资源都押在操作系统上，并将所有的新应用和技术都与之绑定。他们的生存将取决于两件事：一是不断为操作系统添加更多功能，以防止用户转向更便宜的替代方案；二是维护一种神秘的形象，让用户觉得物有所值。

后者是一种非常奇特而有趣的文化现象。
## 8. 界面文化 THE INTERFACE CULTURE
几年前，我走进一家杂货店，眼前浮现出这样一幅生动的画面：在入口附近，一对年轻情侣站在一个大型化妆品展示柜前。男人双手稳稳地提着购物篮，他的伴侣则忙着从展示柜上取下一盒盒化妆品，一股脑地塞进篮子里。从那时起，我一直觉得那个男人体现了一种有趣的人类倾向：我们不仅不反感被人工制造的形象所迷惑，反而乐在其中。我们几乎是刻意追求这种迷惑。我们渴望成为这种迷惑的帮凶：花钱去游乐园玩，投票给一个明显在撒谎的人，或者站在那里，看着别人把购物篮装满化妆品。

我最近去了迪士尼世界（Walt Disney World），确切地说是神奇王国（Magic Kingdom）那部分，当时正沿着美国大街（Main Street USA）漫步。这是一个完美的维多利亚时代小镇，宛如姜饼屋一般，尽头是一座迪士尼城堡。那里人山人海，我们只能挪动脚步，而不是走着。我正前方站着一个拿着摄像机的男人。那是一种新型摄像机，不用像传统摄像机那样通过取景器观察，而是通过一块扑克牌大小的彩色平板屏幕实时播放摄像机拍摄到的画面。他把摄像机举得离脸很近，挡住了视线。他没有去亲眼免费体验真正的小镇，而是花钱去看一个虚构的小镇，而且不是用肉眼观看，而是通过电视屏幕观看。

我没有待在家里看书，而是看着他。

美国人偏爱媒介化体验（Mediated Experience）这一点显而易见，我就不多赘述了。我甚至不会对此冷嘲热讽——毕竟，我当时是以付费顾客的身份去迪士尼乐园的。但这显然与图形用户界面（GUI）的巨大成功息息相关，所以我不得不谈谈这个话题。迪士尼在媒介化体验方面无人能及。如果他们能理解操作系统是什么，以及人们为什么使用操作系统，他们或许能在短短一两年内就击败微软。

在迪士尼世界的动物王国（Animal Kingdom）里，有一个名为“大君丛林探险”（Maharajah Jungle Trek）的新景点，计划于1999年3月开放。我去的时候，它正在进行预览。这是一个完全按照印度丛林中一处假想遗址建造的复原建筑。据其背景介绍，它是由一位当地的拉贾（Rajah，印度王公）在16世纪建造的狩猎保护区。他会带着他的贵宾们来这里猎捕孟加拉虎。随着时间的推移，保护区逐渐破败，老虎和猴子占据了这里；最终，在印度独立前后，它成为了一个政府野生动物保护区，现在对游客开放。

与其说这地方像印度任何一座真正的建筑，不如说更像我刚才描述的那般。残垣断壁上的石头都饱经风霜，仿佛几个世纪以来季风雨水一直滴落其上；精美壁画上的颜料斑驳褪色，恰到好处；孟加拉虎懒洋洋地躺在断柱残骸之间。这座古老建筑的现代修缮并非迪士尼工程师的风格，而是印度勤俭的清洁工的风格——用竹子和锈迹斑斑的钢筋拼凑而成。当然，锈迹是涂上去的，表面还涂了一层透明塑料保护层，防止真正的锈蚀，但除非你跪下来仔细看，否则根本看不出来。

在一处地方，你沿着一面石墙漫步，墙上雕刻着一系列古老的、布满凹坑的浮雕。墙的一端已经断裂并沉入地下，或许是源于一场早已被人遗忘的地震，因此一道宽阔的锯齿状裂缝横贯一两块浮雕，但故事依然清晰可辨：首先，原始的混沌孕育出众多动物物种的繁荣。接下来，我们看到生命之树被各种各样的动物环绕。这显然是在影射（或者用演艺圈的术语来说，是“关联”）迪士尼动物王国中心那棵巨大的生命之树（Tree of Life），正如城堡之于魔法王国，球体（Epcot Sphere）之于未来世界（Epcot）。但它的描绘风格符合历史，足以以假乱真，即使是对印度艺术史没有博士学位的人也难以分辨。

下一格画面描绘了一个留着胡子的智人（Homo Sapiens）用弯刀砍倒生命之树，动物们四散奔逃。再下一格画面则展现了这个误入歧途的人类被海啸吞噬，这大概是他愚蠢行为引发的现代大洪水（Modern Flood）的一部分。

最后一格画面描绘了生命之树开始重新生长，但此时人类已经丢弃了锋利的武器，和其他动物一起站在树旁崇拜和赞美它。

换句话说，这是对瓶颈（The Bottleneck）的预言：现代环保主义者普遍认为，世界将面临一段严重的生态灾难时期，这段时期将持续数十年或数百年，直到我们找到与自然和谐相处的新方式，灾难才会结束。

整体而言，这幅浮雕堪称一件杰作。显然，它并非古印度遗址，其功劳应归于当今的某位或某些人。但迪士尼乐园里的“王公狩猎保护区”上没有任何签名。事实上，任何地方都没有签名，因为如果像好莱坞电影那样，在每一块仿旧砖上都挂满长长的制作人员名单，就会破坏整体效果。

在好莱坞编剧眼中，迪士尼素有“恶毒继母”（The Evil Stepmother）之称。这不难理解。迪士尼的生意就是打造天衣无缝的幻象——一面魔镜，将世界映照得比真实面貌更加完美。但作家是在与读者直接对话，而不仅仅是营造氛围或呈现视觉内容；正如命令行界面比图形用户界面更能直接、清晰地连接用户与机器一样，文字、作家和读者之间的关系也是如此。

归根结底，文字是唯一一种编码思想的系统——唯一一种媒介——它不可替代，不会消融于吞噬一切的电子媒体洪流之中（迪士尼乐园里那些富有的游客穿着印有著名设计师名字的T恤，因为设计本身很容易被盗版而不受惩罚。唯一能制造出无法被合法盗版的服装的方法，就是在上面印上受版权和商标保护的文字；一旦完成了这一步，服装本身就无关紧要了，所以一件T恤和其他任何东西一样好。印有昂贵文字的T恤如今成了上流社会的标志。印着廉价文字，或者根本没有文字的T恤，则是平民百姓的专属）。

但文字和书面交流的这种特殊性，对迪士尼的产品来说，就如同在魔镜上喷涂涂鸦一般。因此，迪士尼的大部分沟通都避免使用文字，而且大多数情况下，人们也不会觉得缺少文字有什么不妥。迪士尼的一些早期作品，例如《小飞侠》（Peter Pan）、《小熊维尼》（Winnie the Pooh）和《爱丽丝梦游仙境》（Alice in Wonderland），都源自书籍。但作者的名字很少被提及，甚至从未被提及，而且你也无法在迪士尼商店买到原著。即便能买到，它们看起来也都会显得陈旧怪异，像是对更纯粹、更原汁原味的迪士尼版本的拙劣模仿。与《美女与野兽》（Beauty and the Beast）和《花木兰》（Mulan）等较新的作品相比，根据这些书籍改编的迪士尼电影（尤其是《爱丽丝梦游仙境》和《小飞侠》）显得非常怪诞，并不完全适合儿童观看。这也不难理解，因为刘易斯·卡罗尔（Lewis Carroll）和詹姆斯·巴里（J. M. Barrie）都是非常古怪的人，而文字的本质决定了，他们个人的怪诞之处会像X光穿透墙壁一样，直抵迪士尼化的所有层面。可能正是因为这个原因，迪士尼似乎完全停止购买书籍，现在从民间故事（Folklore）中寻找主题和人物，这些故事具有如同大君遗址中古老砖块般精致而饱经风霜的质感。

如果允许我大胆概括一下，去迪士尼乐园的大多数人对从书中吸收新思想毫无兴趣。这话听起来有点刻薄，但请听我说：他们很乐意接受其他形式的思想。如今，迪士尼乐园里到处都是环保宣传，动物王国的导游们更是能滔滔不绝地讲生物学。

如果你跟着那些游客回家，或许能找到一些艺术品，但那大概是迪士尼乐园非洲和亚洲主题商店里出售的那种没有署名的民间艺术品。总的来说，他们似乎只对那些经过时间考验、广受大众认可，或者两者兼具的艺术形式感兴趣。

在这个世界上，艺术家就像那些默默无闻、不识字的石匠，他们建造了欧洲宏伟的大教堂，最终却消失在教堂墓地里无名的坟墓中。大教堂整体上令人敬畏、令人震撼，或许正是因为我们不知道是谁建造了它，才更显得弥足珍贵。当我们漫步其中时，我们不是与个别石匠交流，而是与整个文化对话。

迪士尼乐园也是如此。如果你是个知识分子，喜欢读书或写作，那么你对它最高的评价就是：制作精良。但你很容易觉得整个环境有点诡异，因为缺少了些什么：没有把所有内容清晰明了地翻译成文字，也没有把这些想法归功于具体的作者。你无法反驳这一点。似乎很多东西都被掩盖了，仿佛迪士尼乐园在欺骗我们，并且可能掩盖了各种隐藏的假设和混乱的思维。

但这与从命令行界面过渡到图形用户界面时所丢失的东西完全相同。

迪士尼和苹果/微软其实殊途同归：它们都致力于用精心设计的界面来简化繁琐冗长的语言沟通。迪士尼本身就是一种用户界面——而且不仅仅是图形界面。我们不妨称之为“感官界面”（Sensory Interface）。它可以应用于世间万物，无论真实存在还是虚构世界，当然，代价也极其高昂。

为什么我们拒绝使用明确的文字界面，而接受图形或感官界面——这种趋势解释了微软和迪士尼的成功？

部分原因在于，如今的世界极其复杂——远比我们大脑进化适应的狩猎采集世界复杂得多——我们根本无法处理所有细节。我们必须进行委托（Delegate）。我们别无选择，只能信任迪士尼的某个无名艺术家，或者苹果或微软的某个程序员，让他们替我们做出一些选择，排除一些选项，然后给我们提供一份简洁明了的概要。

但更重要的是，这源于一个事实：在本世纪，知识分子主义（Intellectualism）失败了，人尽皆知。在俄国和德国等地，普通民众同意放松对传统民俗、习俗和宗教的掌控，任由知识分子大行其道，结果知识分子把一切都搞砸了，把这个世纪变成了屠宰场。那些喋喋不休的知识分子过去只是令人厌烦；现在看来，他们似乎也有些危险了。

我们美国人是唯一在这场动荡中没有遭受重创的民族。我们之所以自由繁荣，是因为我们继承了十八世纪一群知识分子精心构建的政治和价值观体系，而他们恰好做对了。但我们已经与这些知识分子，以及任何类似知识分子的东西失去了联系，甚至到了不再读书的地步，尽管我们识字。我们似乎更乐于通过媒体的熏陶，以非语言的方式将这些价值观传递给后代。显然，这种方式在某种程度上确实有效，因为许多国家的警察现在抱怨说，当地被捕者坚持要被告知米兰达权利（Miranda Rights），就像美国警匪剧里的罪犯一样。当被告知他们身处一个没有这些权利的国家时，他们便勃然大怒。从长远来看，《警探搭档》（Starsky and Hutch）的重播，配上各种语言的译本，或许比《独立宣言》（Declaration of Independence）更能推动人权事业的发展。

一个庞大、富裕、拥有核武库的文化，如果通过媒体传播其核心价值观，这听起来似乎不太妙。这里显然存在误入歧途的风险。文字是我们唯一不变的媒介，因此它成为传播十诫（Ten Commandments）、古兰经（Koran）和权利法案（Bill of Rights）等极其重要概念的首选载体。除非媒体传递的信息与一套固定的、书面的准则紧密相连，否则它们就会四处散播，甚至可能将大量垃圾信息灌输到人们的头脑中。

奥兰多（Orlando）曾经有一个名为麦考伊空军基地（McCoy Air Force Base）的军事设施，拥有长长的跑道，B-52轰炸机可以从那里起飞，携带大量核弹飞往古巴，或者几乎任何其他地方。但现在麦考伊基地已被废弃并改作他用，并入了奥兰多的民用机场。如今，这些长长的跑道被用来降落满载来自巴西、意大利、俄罗斯和日本游客的747客机，以便他们能够前往迪士尼乐园，并在我们的媒体镜头下停留一段时间。

对传统文化，尤其是像伊斯兰教（Islam）这样以语言为基础的文化而言，这比B-52乐队带来的威胁要大得多。对于美国以外的所有人来说，显而易见的是，我们口中的“多元文化主义”（Multiculturalism）和“多样性”（Diversity）不过是虚伪的幌子，它们（在很多情况下是无意中）被用来掩盖一个旨在消除文化差异的全球趋势。多元文化主义（或者“尊重多样性”，或者你想怎么称呼它都行）的基本原则是，人们需要停止彼此评判——停止断言（最终，停止相信）什么是对的，什么是错的；什么是真的，什么是假的；什么是丑的，什么是美的；上帝存在并拥有这样或那样的特质。

二十世纪给大多数人带来的教训是，为了让众多不同的文化在全球（甚至在同一个社区）和平共处，人们必须暂时搁置评判。因此（我认为），我们对现代文化中所有权威人物都抱有怀疑和敌意。正如大卫·福斯特·华莱士（David Foster Wallace）在他的文章《E Unibus Pluram》中所解释的那样，这正是电视传递的根本信息；无论如何，这都是人们在长期沉浸于媒体之后最终会领悟到的信息。当然，它并非以如此高深的语言表达。它表现为一种预设：所有权威人物——教师、将军、警察、部长、政客——都是虚伪的丑角，而时髦的、冷漠的酷（Cool）才是唯一的生存之道。

问题在于，一旦你丧失了判断是非对错、真假等的能力，真正的文化就不复存在了。剩下的只有木屐舞（Clog Dancing）和编织（Weaving）。判断的能力，相信事物的能力，正是文化存在的全部意义所在。我认为这就是为什么像卢克索（Luxor）这样的地方有时会出现荷枪实弹的人，开始向西方人扫射。他们完全明白麦考伊空军基地的教训。当他们的儿子戴着帽檐反戴的芝加哥公牛队（Chicago Bulls）棒球帽回家时，父亲们会气疯的。

电视将这种全球反文化（Global Anti-Culture）传播到世界各地，它本身就是一种文化，而且以伊斯兰教和法国等伟大而古老的文化为标准来看，它似乎远远逊色，至少乍一看是这样。它唯一的好处就是降低了世界大战和纳粹大屠杀（Holocaust）发生的可能性——而这实际上是一件相当不错的事！

唯一真正的问题是，除了这种全球单一文化之外，任何没有其他文化的人都彻底完蛋了。任何从小看电视长大，从未接触过任何宗教或哲学，在道德相对主义（Moral Relativism）的氛围中成长，从电视新闻里那些哗众取宠的言论中学习公民知识，并在后现代主义者（Postmodernist）竞相颠覆传统真理和品质观念的大学里学习的人，最终都会变成一个相当不负责任的人。而且——再说一遍——也许这一切的目的就是让我们变得不负责任，这样我们就不会互相残杀了。

另一方面，如果你在某种特定的文化环境中长大，你最终会掌握一套基本的思考和理解世界的工具。你可能会用这些工具来否定你成长的文化，但至少你拥有一些工具。

在这个国家，那些掌权的人——那些在大型律师事务所和公司董事会任职的人——在某种程度上都明白这一点。他们口头上支持多元文化、多样性和不带偏见，但他们自己却不这样教育孩子。我有一些受过高等教育、技术娴熟的朋友，他们搬到爱荷华州的小镇生活和抚养孩子；纽约也有一些哈西德犹太社区（Hasidic Jewish Community），那里有很多孩子按照传统信仰长大。任何郊区社区都可以被视为持有某些（大多是隐性的）信仰的人们聚集居住的地方，他们与持有相同信仰的人生活在一起。

这些人不仅对自己的孩子负有责任，也对整个国家负有责任。当然，一些上层阶级人士卑鄙无耻、愤世嫉俗，但许多人至少会花一些时间忧心忡忡地思考国家的未来走向以及自身肩负的责任。因此，那些对博览群书的知识分子而言至关重要的问题，例如全球环境崩溃，最终会渗透到大众文化的缝隙中，并以奥兰多古代印度教遗址的形式呈现出来。

你可能会问：这一切到底跟操作系统有什么关系？正如我解释过的，如果不从文化角度来解释苹果/微软对操作系统市场的统治地位，就根本无从谈起。因此，在这篇文章中，如果我不先说明我对当代文化的理解，就无法展开论述。

当代文化是一个双层体系，就像H·G·威尔斯（H. G. Wells）《时间机器》（The Time Machine）中的莫洛克人（Morlocks）和伊洛伊人（Eloi）一样，只不过这种体系被颠倒了。在《时间机器》中，伊洛伊人是颓废的上层阶级，由众多生活在地下的莫洛克人供养，这些人维持着科技的运转。但在我们的世界里，情况恰恰相反。莫洛克人是少数群体，他们掌控着一切，因为他们了解万物的运作方式。数量远超莫洛克人的伊洛伊人，从出生起就沉浸在电子媒体中，而这些媒体又是由博览群书的莫洛克人引导和控制的。如此众多的无知之人一旦被误导，就会变得危险，因此我们发展出了一种流行文化，这种文化（a）几乎具有难以置信的传染性，（b）它会使每个被感染的人变得麻木，使他们不愿做出判断，也丧失了立场。

拥有充沛精力和超凡智慧的莫洛克人能够理解各种细节，他们会外出钻研复杂的课题，制作出类似迪士尼动画般的感官界面，让埃洛伊人无需费力思考或忍受无聊就能掌握要点。这些莫洛克人会前往印度，孜孜不倦地探索上百处遗址，然后回到家乡，打造出干净卫生、无虫害的版本：就像是精华片段集锦。这花费不菲，因为莫洛克人坚持要喝好咖啡、坐头等舱，但这不成问题，因为埃洛伊人喜欢被眼前的景象所震撼，他们乐意为此买单。

现在我意识到，我说的这些话听起来可能很刻薄，很愤世嫉俗，甚至荒谬至极：一个自以为是的知识分子对着那些没文化的庸俗之辈大发脾气。就好像我是个自封的摩西（Moses），独自一人从山上下来，手里拿着刻着十诫的石板——那是最初的命令行界面——对着那些软弱无知、崇拜偶像的希伯来人大发雷霆。不仅如此，听起来还像是我在兜售某种阴谋论。

但这并非我接下来要说的重点。我所描述的情况可能很糟糕，但并非一定糟糕，而且现在也未必很糟糕：

如今，我们实在太忙了，根本无暇顾及所有细节。与其完全不了解，不如通过某种界面粗略地了解一下。与其让一千名心血管外科医生和基金经理去肯尼亚体验“真正的”乞力马扎罗山（Kilimanjaro）之旅，不如让一千万埃洛伊人去迪士尼乐园体验乞力马扎罗山之旅。这两个阶层之间的界限远比我描述的要模糊得多。我经常遇到一些普通人——建筑工人、汽车修理工、出租车司机，总之就是一些普通人——他们原本大多不识字，直到某些事情迫使他们开始阅读并思考问题。也许他们不得不面对酗酒的困扰，也许他们锒铛入狱，也许他们染上了疾病，也许他们经历了宗教信仰危机，也许他们只是感到无聊。这些人往往能很快掌握某些领域的知识。有时，他们缺乏广泛的教育，容易陷入无谓的智力探索，但嘿，至少这种探索还能锻炼身体。一个政治体系被那些真的相信百威淡啤（Bud Light）和米勒淡啤（Miller Lite）之间存在显著差异，并且认为职业摔跤（Professional Wrestling）是真实存在的选民的时尚和一时兴起所掌控，这对于那些不相信这些的人来说，自然令人担忧。但是，如果一个国家像通过命令行界面一样，由那些头脑空空的知识分子——无论是宗教人士还是世俗人士——来控制，那么它通常都是令人痛苦的居住地。见多识广的人会嘲笑迪士尼式的娱乐节目老套又甜腻，但是，嘿，如果其结果是在数亿不识字的媒体受众中，在语言发展之前的阶段，就培养出温暖和同情的本能，那又能有多糟糕呢？昨晚我们在厨房里杀了一只龙虾，我女儿哭了一个小时。日本人曾经是世界上最凶悍的民族之一，如今却迷上了可爱萌萌的卡通人物（Kawaii）。我自己的家人——我最了解的人——大致可以分为两类：一类可能会读到这篇文章，另一类几乎肯定不会读。我无法断言哪一类人就一定比另一类人更热情、更快乐或更适应社会。
## 9. 键盘上的莫洛克人和伊洛伊人 MORLOCKS AND ELOI AT THE KEYBOARD
在命令行界面时代，用户就像莫洛克人一样，必须将想法转换成字母数字符号并输入，这是一个极其繁琐的过程，它抹去了所有歧义，暴露了所有隐藏的假设，并残酷地惩罚了懒惰和不精确。后来，界面开发者开始着手开发图形用户界面（GUI），在人与机器之间引入了一个新的符号层。使用这类系统的人放弃了直接向执行运算的芯片发送比特的责任和权力，并将这种责任和权力交给了操作系统。这很诱人，因为向任何人或任何事物发出清晰的指令都很难。我们无法不思考就做到这一点，而且根据情况的复杂程度，我们可能需要深入思考抽象问题，并考虑各种可能的影响，才能做好这项工作。对我们大多数人来说，这很费力。我们都希望事情变得更简单。我们有多渴望它，可以从比尔·盖茨的财富规模来衡量。

因此，操作系统已经变成了一种节省智力劳动的工具，它试图将人类模糊的意图转化为二进制代码。实际上，我们是在要求计算机承担那些一直以来都被认为是人类专属的责任——我们希望它们理解我们的愿望，预测我们的需求，预见后果，建立联系，在无需请求的情况下处理日常琐事，并在过滤掉无关信息的同时提醒我们应该记住的事情。

在更高层级（也就是更接近用户的层级），这是通过一系列约定俗成的规则来实现的——菜单、按钮等等。这些规则的作用类似于类比：它们通过将抽象或陌生的概念与已知事物进行类比，帮助 Eloi 理解它们。但这里使用的是更高级的词汇“隐喻”（Metaphor）。

macOS 的核心概念是“桌面隐喻”（Desktop Metaphor），它涵盖了许多其他较小的（且经常相互冲突，或至少是混杂的）隐喻。在图形用户界面 (GUI) 下，文件（通常称为“文档”）被隐喻为屏幕上的一个窗口（称为“桌面”）。这个窗口几乎总是太小，无法容纳整个文档，因此你需要“移动”文档，或者更正式地说，通过“点击并拖动”滚动条上的“滑块”来“导航”文档。当你在“窗口”中“输入”（使用键盘）或“绘制”（使用鼠标）内容，或者使用下拉“菜单”和“对话框”来操作其内容时，你的操作结果（至少在理论上）会被存储在一个“文件”中，之后你可以将相同的信息提取到另一个“窗口”中。当你不再需要它时，你可以将其“拖”到“废纸篓”中。

这里充斥着大量混杂的隐喻，我可以没完没了地分析它，但我不会。我们只考虑一个词：“文档”。在现实世界中，当我们记录某件事物时，我们会将其永久保存，不可更改。但计算机文档却是易变的、短暂的数据集合。有时（比如你刚刚打开或保存文档时），窗口中显示的文档与磁盘上同名文件中存储的内容完全相同；但有时（比如你修改后没有保存）则完全不同。无论如何，每次点击“保存”按钮，你都会删除“文档”的先前版本，并用当前窗口中显示的版本取而代之。因此，即使是“保存”这个词本身也被赋予了一种极其误导的含义——“销毁一个版本，保存另一个版本”或许更为准确。

任何长时间使用文字处理软件的人都难免会遇到这种情况：花费数小时精心制作了一份长文档，却因为电脑崩溃或断电而丢失。在文档从屏幕上消失的那一刻之前，它看起来和用墨水在纸上打出来的一样真实、一样清晰。但下一刻，毫无预兆地，它就彻底消失了，仿佛从未存在过。用户会感到一种莫名的失落（更不用说恼怒了），这种失落源于一种隐喻的断裂——你意识到自己一直以来所生活和思考的，其实是一个虚假的隐喻。

所以，GUI使用隐喻来简化计算，但这些隐喻并不好。学习使用它们本质上就是一场文字游戏，一个学习“窗口”、“文档”和“保存”等词语新定义的过程，这些新定义与旧定义截然不同，在很多情况下甚至完全相反。令人有些意外的是，这种方法非常有效，至少从商业角度来看是如此，也就是说，苹果和微软从中赚了很多钱。所有其他现代操作系统都明白，为了被用户接受，它们必须用类似的“粉饰”来掩盖其底层工作原理。这有一些好处：如果你知道如何使用一个GUI操作系统，你可能只需几分钟就能学会使用任何其他操作系统。一切运作方式都略有不同，就像欧洲的管道系统一样——但只要稍加摸索，你就能写备忘录或上网。

大多数购买操作系统的人（如果他们真的会去选购的话）比较的并非底层功能，而是表面的外观和感觉（Look and Feel）。操作系统的普通买家并非真的在为分配内存或向磁盘写入字节的底层代码买单，也并不特别关心这些。我们真正购买的是一套隐喻系统。而且——更重要的是——我们接受的是一种潜在的假设：隐喻是应对世界的一种有效方式。

最近，许多新型硬件的出现赋予了计算机多种影响现实世界的有趣方式：例如，让打印机喷出纸张，让文字出现在数千英里之外的屏幕上，用辐射束照射癌症患者，以及制作逼真的泰坦尼克号（Titanic）动态影像。Windows 操作系统现在被广泛应用于收银机（Cash Register）和银行柜员终端（Bank Teller Terminal）。我的卫星电视系统使用某种图形用户界面 (GUI) 来切换频道和显示节目指南。现代手机的小型液晶显示屏（LCD）上也内置了简易的GUI。就连乐高（Lego）积木现在也有了GUI：你可以购买一套名为 Mindstorms 的乐高套装，它能让你搭建小型乐高机器人，并通过电脑上的GUI对它们进行编程。

所以，我们现在要求GUI的功能远不止于充当一台功能强大的打字机。我们希望它成为应对现实的通用工具。这对于那些以将新技术推向大众市场为生的公司来说，无疑是一笔巨大的财富。

显然，如果没有某种用户界面，就无法将复杂的科技系统卖给消费者。内燃机在当时是一项技术奇迹，但只有当离合器、变速器、方向盘和油门与之连接后，它才能作为消费品发挥作用。这套奇特的装置，至今仍存在于每辆汽车上，构成了我们今天所说的用户界面。但如果汽车是在苹果电脑之后才发明的，汽车制造商就不会费心费力地研发这些晦涩难懂的设备了。我们会用电脑屏幕代替仪表盘，用鼠标（或者最多是操纵杆）代替方向盘，并通过下拉菜单来换挡。

```
停车挡 --- 倒挡 --- 空挡 ---- 3 2 1 --- 求助...
```
因此，只需几行计算机代码就能替代任何你能想象到的机械界面。问题在于，在很多情况下，这种替代方案并不理想。通过图形用户界面（GUI）驾驶汽车将是一次糟糕的体验。即使GUI完全没有漏洞，它也极其危险，因为菜单和按钮的响应速度根本无法与直接的机械控制相媲美。我朋友的父亲，那位正在修复MGB的先生，如果这辆车配备了GUI，他肯定不会费心去修。那将毫无乐趣可言。

方向盘和换挡杆发明于一个大多数家庭最复杂的技术还只是黄油搅拌器（Butter Churn）的时代。早期的汽车制造商运气极佳，他们能够设计出最适合驾驶汽车的任何操作界面，而人们也乐于学习。拨号电话（Dial Telephone）和调幅收音机（AM Radio）也是如此。到了二战时期，大多数人已经掌握了多种操作界面：他们不仅会搅拌黄油，还会开车、拨打电话、打开收音机、点燃打火机，甚至更换灯泡。

但现在，从手表、录像机（VCR）到炉灶，每样小东西都塞满了各种功能，而没有相应的界面，这些功能都毫无用处。如果你和我一样，也和大多数消费者一样，你可能从未用过微波炉、录像机或手机上90%的功能。你甚至都不知道这些功能的存在。它们可能带来的微不足道的好处，远不及学习使用它们所带来的麻烦。这对消费品制造商来说无疑是个大问题，因为如果不提供各种功能，他们就无法参与竞争。

如今，工程师们不再像当年设计汽车那样，为每一款新产品都设计一套全新的用户界面，部分原因是成本太高，部分原因是普通人的学习能力有限。如果录像机是一百年前发明的，它应该会配备一个用于调节磁道（Tracking）的旋钮，一个用于正反转的换挡杆，以及一个用于装卸磁带的大型铸铁手柄。它的正面会有一个大型模拟时钟，用户可以通过拨动指针来设置时间。但由于录像机发明于机械界面和图形用户界面（GUI）过渡的尴尬时期，它的正面只有一堆按钮，用户必须以正确的方式按下这些按钮才能设置时间。对于负责设计的工程师来说，这或许显得合情合理，但对许多用户而言，这简直是天方夜谭。因此，许多录像机上都会出现闪烁的12:00。计算机领域的人把这称为“闪烁的十二点问题”（The Flashing Twelve Problem）。不过，他们谈论这个问题时，通常指的不是录像机。

现代录像机通常都带有某种屏幕编程功能，这意味着你可以通过一种简易的图形用户界面（GUI）来设置时间和控制其他功能。当然，图形用户界面也包含虚拟按钮，但除此之外，它还包含其他类型的虚拟控件，例如单选按钮（Radio Button）、复选框（Check Box）、文本输入框（Text Entry Box）、旋钮（Knob）和滚动条（Scroll Bar）。对于许多人来说，由这些组件构成的界面似乎比按压机器正面那些小按钮要方便得多，因此，闪烁的“12:00”字样正逐渐从美国家庭的客厅中消失。“12:00”字样的闪烁问题已经转移到其他技术领域。

因此，GUI 已经超越了个人电脑的界面范畴，成为一种元界面（Meta-Interface），被强加给每一种新的消费电子产品。它很少能完美契合，但拥有一个理想的，甚至是良好的界面，已不再是首要任务；如今重要的是拥有某种用户真正愿意使用的界面，这样制造商才能面不改色地宣称他们提供了新功能。

我们之所以需要 GUI，主要是因为它们方便易用——或者至少 GUI 给人这种感觉。当然，世上没有真正简单易用的事，再配上漂亮的界面也改变不了这一点。用 GUI 控制的汽车肯定比用踏板和方向盘控制的汽车更容易驾驶，但却极其危险。

由于我们一直使用 GUI，我们不知不觉地接受了这样一个前提：只要配上合适的界面，困难的事情就能变得容易，复杂的事情就能变得简单。如果用同样的标准来评价用户界面，书评会是什么样子呢？“这本书的文笔极其简单肤浅，作者对复杂的主题一带而过，几乎每句话都充斥着肤浅的概括。读者几乎不用思考，也省去了阅读传统书籍时通常会遇到的种种困难和乏味。” 只要我们只是做一些像设置录像机时钟这样简单的操作，这倒也无妨。但当我们尝试用技术去做更复杂的事情时，就不可避免地会遇到以下问题：
## 10. 隐喻剪切 METAPHOR SHEAR
我大约在1985年微软Word第一版发布后就开始使用它了。最初遇到了一些问题，但后来我发现它比当时唯一的竞争对手MacWrite要好用得多。我用早期版本的Word写了很多东西，全部都保存在软盘上，然后把所有软盘上的内容都转移到了我大约在1987年买的第一块硬盘上。随着Word新版本的发布，我都会及时升级，因为我觉得作为一名写作者，在工具上花点钱是理所应当的。

大约在 20 世纪 80 年代中期，我尝试用当时最新的 Word 版本 6.0 打开一份我大约在 1985 年创建的旧 Word 文档。结果失败了。Word 6.0 无法识别由其早期版本创建的文档。通过将其作为文本文件打开，我得以恢复组成文档文本的字母序列。我的文字还在。但是格式却完全被破坏了——我写的文字被大片的空白矩形框和乱码打断了。

现在，在商业领域（Word 的主要市场），这种事不过是件烦人的事——使用电脑难免会遇到的日常小麻烦之一。买些文件转换软件就能轻松解决这个问题。但如果你是一位以文字为生的作家，你的职业身份建立在大量书面文档之上，那么这种事就极其令人不安。我的工作中很少有绝对的规则，但其中一条就是：一旦你写下一个字，它就永远写出来了，无法撤销。墨水染红了纸张，凿子凿开了石头，笔尖在泥板上留下了痕迹，一些不可逆转的事情已经发生了（我的姐夫是一位神学家，他能解读 3250 年前的楔形文字泥板——他能认出特定抄写员（Scribe）的笔迹，并能说出他们的名字）。但是文字处理软件——尤其是那些采用特殊复杂文件格式的软件——拥有着一种神奇的力量，可以抹杀一切。文件格式的微小改动，或者几个细微的程序修改，都可能导致数月甚至数年的文学创作付诸东流。

严格来说，这其实是应用程序（Macintosh 版 Word 6.0）的问题，而不是操作系统（MacOS 7.x）的问题，所以我最初恼火的对象是 Word 的开发人员。但是，另一方面，我本可以选择 Word 的“另存为文本”（Save As Text）选项，把所有文档都保存成简单的电报，这样就不会出现这个问题了。然而，我却被那些花哨的格式选项所诱惑，这些选项在图形用户界面出现之前根本不存在。我养成了用它们来美化文档的习惯（也许美得过分了；那些软盘上的旧文档最终都被证明是一堆垃圾）。现在，我正在为这种自我放纵付出代价。技术进步了，找到了让文档看起来更漂亮的方法，结果就是所有那些丑陋的旧文档都消失了。

——请允许我稍稍展开一段奇特的幻想——就好像我入住了一家度假村，一家设计精美、艺术指导极佳的酒店，把自己完全交托给了感官界面领域的大师们。我坐在房间里，用圆珠笔在一张黄色法律用纸（Yellow Legal Pad）上写了个故事。晚餐回来后，我发现女佣已经把我的作品拿走了，取而代之的是一支羽毛笔和一叠精美的羊皮纸——她解释说，这样房间看起来更精致，而且这只是例行升级的一部分。然而，这些纸上却用完美的笔迹写着一长串随机从字典里挑选出来的词语。这当然令人震惊，但我无法向酒店管理层投诉，因为入住这家度假村就意味着我同意了这一切。我放弃了我的莫洛克人身份，成为了一个伊洛伊人。
### ===LINUX===
在20世纪80年代末和90年代初，我花了很多时间编写Macintosh程序，最终决定花几百美元购买一款名为Macintosh Programmer's Workshop（简称MPW）的苹果产品。MPW虽然也有竞争对手，但它无疑是当时Mac平台上首屈一指的软件开发系统。苹果自己的工程师就是用它来编写Macintosh代码的。考虑到当时macOS的技术远超竞争对手，而Linux甚至还未问世，再加上这是苹果世界一流的创意工程师团队实际使用的程序，我对它抱有很高的期望。它装在一摞摞足足一英尺高的软盘里，所以漫长的安装过程让我有足够的时间去积累兴奋。第一次启动MPW时，我可能期待的是一个充满触感的多媒体展示界面。然而，它却显得十分简朴，甚至有些令人望而生畏。这是一个可滚动的窗口，你可以在其中输入简单的、未格式化的文本。系统随后会将这些文本行解释为命令，并尝试执行它们。

换句话说，它就像一台运行命令行界面的玻璃电传打字机。它自带各种各样晦涩难懂但功能强大的命令，可以通过输入命令名称来调用，而我也是慢慢地才学会使用这些命令的。直到几年后，当我开始接触Unix系统时，我才明白MPW中的命令行界面其实是对Unix的重新演绎。

换句话说，苹果黑客们在成功运行 macOS 之后——甚至可能在系统运行之前——做的第一件事就是重现 Unix 界面，以便他们能够开展一些有用的工作。当时我简直无法理解，但对苹果黑客来说，Mac 引以为傲的图形用户界面反而成了障碍，在 Mac 这款“小烤面包机”上市之前就必须想办法绕过它。

早在1995年7月我的PowerBook崩溃并丢失大文件之前，就已经出现了危险信号。我的一位大学老友，在波士顿创办并运营高科技公司，他开发了一款以Macintosh电脑为前端的商业产品。Macintosh电脑本质上是高性能图形终端，之所以选择它们，是因为它们拥有简洁友好的用户界面，使用户能够访问存储在由功能更强大但用户体验较差的计算机组成的网络中的大型图形信息数据库。顺便一提，这位老友是第二个让我接触Macintosh电脑的人。在20世纪80年代中期，我们共同体验着作为高科技鉴赏家的兴奋，在DOS时代，我们却在使用更先进的苹果技术。他告诉我，他早期的系统运行良好，但当多台机器加入网络后，就开始出现神秘的崩溃；有时整个网络甚至会完全冻结。这是一种难以重现的bug。最后他们发现，每当用户在菜单中搜索特定项目时，如果按住鼠标按钮超过几秒钟，就会触发这些网络崩溃。

从根本上讲，macOS 一次只能做一件事。在屏幕上绘制菜单就是其中之一。因此，当用户下拉菜单时，Macintosh 电脑无法执行任何其他操作，直到犹豫不决的用户松开按钮为止。

在单用户、单进程的机器上，这倒不算太糟（虽然也相当糟糕），但在联网的机器上就麻烦了，因为联网意味着需要与其他机器进行某种持续的底层交互。由于Mac未能响应网络请求，导致了整个网络的崩溃。

为了与其他计算机、网络以及各种不同类型的硬件协同工作，操作系统必须比 MS-DOS 或初代 macOS 复杂得多，功能也强大得多。唯一值得认真对待的互联网连接方式是 PPP，即点对点协议（Point-to-Point Protocol）。PPP（无需赘述细节）使你的计算机——暂时地——成为全球互联网的正式成员，拥有其唯一的地址以及与之相关的各种权限、权力和责任。从技术上讲，这意味着你的计算机运行的是 TCP/IP 协议（Transmission Control Protocol / Internet Protocol）。简而言之，TCP/IP 协议的核心是按照一套巧妙而优雅的规则，以随机顺序和不可预测的时间来回发送数据包（Packet）。但是，发送数据包是一回事，因此，一次只能做一件事的操作系统不可能同时成为互联网的一部分并执行其他任何操作。 TCP/IP协议发明之初，运行它是一种特权，只有“专业计算机”——即用于技术和商业领域的大型机和高性能小型计算机——才能胜任。因此，该协议的设计基于这样的假设：每一台使用它的计算机都是一台“专业机器”，能够同时处理多项任务（Multitasking）。更确切地说，就是一台Unix机器。MacOS和MS-DOS最初的设计并没有考虑到这一点，所以当互联网蓬勃发展时，它们必须进行彻底的变革。

当我的PowerBook让我心碎，Word也无法识别我的旧文件时，我转而使用Unix系统。MacOS之外最显而易见的替代方案是Windows。我其实对微软或Windows并没有什么意见。但现在很明显，老旧的PC操作系统已经不堪重负，开始出现问题，或许最好还是等到它们能够同时兼顾两者时再考虑使用。

事情发生在1995年夏天的某一天。当时我在旧金山待了几个星期，用我的PowerBook电脑处理一份文件。这份文件太大，一张软盘装不下，所以我离开家后就没备份过。结果PowerBook崩溃了，整个文件都丢失了。

事情就发生在我出门去拜访一家叫 Electric Communities 的公司的时候，当时这家公司在洛斯阿尔托斯（Los Altos）。我带上了我的 PowerBook。我在 Electric Communities 的朋友们都是 Mac 用户，他们有很多用于恢复文件和从磁盘崩溃中恢复数据的实用软件，所以我确信我能找回大部分文件。

结果，两款不同的Mac崩溃恢复工具都找不到我的文件存在过的任何痕迹。它被彻底、系统地删除了。我们逐块检查了硬盘，找到了无数早已被丢弃、遗忘的旧文件的零散碎片，但没有找到我想要的任何东西。那天，这种感觉尤其残酷。就像眼睁睁看着你爱了十年的女孩死于车祸，然后去参加她的尸检，发现卸下华丽的妆容和衣着，她也只是血肉之躯。

我当时一定是陷入了某种原始的荣格式（Jungian）迷离状态，在 Electric Communities 的办公室里晕头转向，因为就在这时，发生了三件非常巧合的事情。
1. 公司联合创始人兰迪·法默（Randy Farmer）带着家人来公司小住——当时他正在从背部手术中恢复。他带来了一个劲爆的消息：“Windows 95今天正式发布！” 这意味着微软的新操作系统今天被刻录到一张特殊的光盘上，这张光盘被称为“黄金母盘”（Golden Master），将用于印制数以亿计的拷贝，为几周后盛大的发布做准备。Electric Communities的员工们听到这个消息后都很不高兴，其中一位同事的办公室门上贴满了各种各样的卡通画和新奇玩意儿，比如……
2. 一幅迪尔伯特（Dilbert）漫画的复制品，漫画中饱受折磨的企业软件工程师迪尔伯特遇到了一位身材矮胖、留着胡子、毛发浓密的中年男子——有点像圣诞老人，但肤色更深，也更阴沉。迪尔伯特根据男子的外貌和神态，认出他是一位Unix黑客，并表现出一种紧张、敬畏和敌意交织的复杂情绪。迪尔伯特无力地戳了戳这个令人不安的闯入者，持续了几格画面；Unix黑客带着一种令人恼火却又无比平静的神情听着，然后在最后一格画面中，他伸手进口袋。“给你五分钱，小子，”他说，“去买一台真正的电脑吧。”
3. 这扇门和这幅漫画的主人是道格·巴恩斯（Doug Barnes）。巴恩斯以对操作系统持有某些离经叛道的观点而闻名。与大多数湾区技术人员对麦金塔电脑推崇备至，视其为真正的黑客机器不同，巴恩斯喜欢指出，麦金塔电脑由于其封闭的架构，实际上对那些喜欢捣鼓、并且对开放性持教条态度的黑客并不友好。相比之下，IBM兼容机系列由于可以轻松拆卸和重新组装，因此更容易进行破解。

所以回到家后，我就开始摆弄Linux，它是Unix这个抽象的、柏拉图式的理想系统（Platonic Ideal）的众多具体实现之一。我并不期待换操作系统，因为这些年来我在Mac硬件上花的钱还让我的信用卡额度告急。但Linux最大的优点在于，它能运行在和微软操作系统完全相同的硬件上——也就是说，最便宜的硬件。仿佛是为了证明这有多么棒，回家一两周后，我就免费弄到了一台当时还不错的电脑（一台33MHz的486机器），因为我认识一个在公司上班的人，他那里的电脑都被直接扔掉了。我把电脑弄回家后，一把扯开机盖，把手伸进去，开始更换各种卡带。如果哪个卡带不能用，我就去二手电脑商店，在一堆零件里翻找，花几块钱买个新的。

这些廉价而高效的硬件的出现，是十多年前IBM和微软决策的一个意想不到的后果。Windows的问世，将图形用户界面（GUI）带入了更广阔的市场，硬件格局也随之改变：彩色显卡和高分辨率显示器的价格开始下降，并且仍在持续下降。这种硬件市场的自由竞争意味着，与macOS相比，Windows不可避免地显得笨拙。但图形用户界面将计算机带给了如此庞大的用户群体，使得用户数量激增，价格暴跌。与此同时，苹果公司一直渴望拥有一个简洁、集成的操作系统，并将视频处理功能完美地集成到处理硬件中，却在市场份额上远远落后，这至少部分原因在于其精美的硬件价格昂贵。

但我们这些Mac用户为卓越的美学和工程技术付出的代价，不仅仅是金钱上的。还有文化上的代价，因为我们无法打开机箱自行改造。道格·巴恩斯说得对。苹果公司虽然以不拘一格、富有创造力的黑客们的首选机器而闻名，但实际上它创造了一种阻碍黑客行为的机器；而微软，作为技术落后者和模仿者，却创造了一个庞大而混乱的零件市场——一个最终自组装成Linux的原始汤（Primordial Soup）。
## 11. 操作系统的全貌 THE HOLE HAWG OF OPERATING SYSTEMS
Unix 就像俄罗斯军队一样，一直潜伏在操作系统大战的幕后，伺机而动。大多数人只是听说过它的名声，而正如《呆伯特》漫画所暗示的那样，它的名声褒贬不一。但似乎所有人都认同，如果它能振作起来，不再向蜂拥而至的侵略者拱手让出大片肥沃的农田和数十万战俘，它就能将侵略者（以及所有其他反对者）彻底碾压。

如果不深入探讨令人费解的技术细节，很难解释 Unix 是如何赢得如此尊重的。或许可以通过讲述一个关于钻头的故事来阐明其要点。

Hole Hawg是密尔沃基工具公司（Milwaukee Tool Company）生产的一款电钻。在一般的五金店里，你或许能找到一些尺寸较小的密尔沃基电钻，但找不到Hole Hawg，因为它动力强劲，价格昂贵，不适合家庭用户。Hole Hawg不像廉价家用电钻那样采用手枪式（Pistol-Grip）设计。它是一个实心金属立方体，一面伸出一个手柄，另一面安装一个夹头（Chuck）。立方体内部装有一个动力强劲的电动机。你可以用食指握住手柄并扣动扳机，但除非你力气特别大，否则单手无法控制Hole Hawg的重量；它必须双手操作。为了抵消Hole Hawg的反扭矩（Torque），你需要使用一个单独的手柄（随附），根据你使用左手还是右手扣动扳机，将手柄拧到铁立方体的某一面。这个手柄不像家用电钻那样设计精巧、符合人体工学（Ergonomic）。它只是一段约30厘米长的普通镀锌管，一端带螺纹，另一端连接着一个黑色橡胶手柄。如果弄丢了，你只需去当地的管道用品商店再买一段就行了。

八十年代我做过一些建筑工作。有一天，一个工人把梯子靠在我们正在搭建的建筑物外墙上，爬到二楼，用“洞钻”（Hole Hawg）钻头在墙上钻孔。钻头卡在墙里了。“洞钻”仿佛遵循着它唯一的使命，继续钻着。它把工人像个破布娃娃一样甩来甩去，害得他自己也把梯子碰倒了。幸运的是，他紧紧抓住卡在墙里的“洞钻”，就这么吊在它上面，大声呼救，直到有人过来把梯子扶正。

我亲手用Hole Hawg钻头在木龙骨（Stud）上钻了很多孔，它钻起来就像搅拌机切卷心菜一样轻松。我还用它在老旧的灰泥板条（Lath and Plaster）天花板上钻了几个直径六英寸的孔。我换上新的开孔器（Hole Saw），爬到二楼，把手伸到新装的楼板横梁（Floor Joist）之间，开始钻穿下面的一楼天花板。我家的电钻费力地、呜呜地转动着巨大的钻头，稍微碰到点障碍物就卡住了，而Hole Hawg却像一颗自转的行星一样稳稳地旋转着。开孔器卡住后，Hole Hawg带着我一起转了起来，把我的一只手夹在钢管手柄和横梁之间，造成几处撕裂伤，每处伤口周围都有一大片淤青。开孔器本身也被压弯了，不过弯曲的程度还不至于让我无法继续使用。几次遭遇之后，当我准备使用 Hole Hawg 时，我的心真的开始因原始的恐惧而怦怦直跳。

但我从未责怪过“洞洞怪兽”钻机，我责怪的是我自己。“洞洞怪兽”钻机的危险之处在于它会完全按照你的指令执行。它不受廉价钻机固有的物理限制，也不受那些出于责任意识而安装在家用产品中的安全联锁装置（Safety Interlock）的约束。危险不在于机器本身，而在于使用者未能预见到他所发出指令的全部后果。

小型工具也很危险，但原因截然不同：它会试图执行你的指令，但总会以某种不可预测且几乎总是令人不快的方式失败。而“洞洞猪”则如同古代童话故事里的精灵（Genie），它会严格、精确地执行主人的命令，并且拥有无限的力量，但往往会带来灾难性的、无法预料的后果。

在“钻孔狂人”（Hole Hawg）出现之前，我常常带着自以为是的眼光去五金店挑选电钻，鄙夷那些小巧的低端型号，欣赏地掂量那些昂贵的大钻，心想自己要是能买得起就好了。现在，我对它们嗤之以鼻，甚至不认为它们是真正的电钻——只不过是放大版的玩具，专门用来利用那些手脚不利的房主们自欺欺人的心理，让他们误以为自己买到了真正的工具。它们精心设计、经过焦点小组测试的塑料外壳，旨在营造一种坚固有力的感觉，在我看来却显得廉价而令人作呕。我为自己曾经被这些小玩意儿蒙蔽而感到羞愧。

不难想象，对于一个从小被建筑工人抚养长大，除了Hole Hawg牌电钻之外从未用过其他电钻的人来说，世界会是什么样子。这样的人，即使面对五金店里最好最贵的电钻，也认不出那是电钻。他可能会把它误认为是儿童玩具，或者某种电动螺丝刀。如果销售员或被蒙蔽的房主称它为电钻，他会哈哈大笑，告诉他们搞错了——他们只是用词不当。对方会恼火地离开，而且很可能会为自己地下室里堆满的廉价、危险、花哨、色彩艳丽的工具感到不安。

Unix 就像操作系统界的 Hole Hawg，而像 Doug Barnes、Dilbert 漫画里的那个家伙以及硅谷其他许多人一样的 Unix 黑客，就像是那些从小只用 Hole Hawg 长大的承包商的儿子。他们或许会用苹果/微软的操作系统来写信、玩游戏或记账，但他们始终无法真正认真对待这些操作系统。
## 12. 口头传统 THE ORAL TRADITION
Unix 很难学。学习过程就像是一次次顿悟。通常，当你即将发明某个必要的工具或实用程序时，你会突然意识到别人已经发明并内置了它，这就解释了你之前注意到但从未真正理解的某些奇怪的文件、目录或命令。

例如，操作系统自带的一个名为 `whoami` 的命令（一个小程序），可以让你询问计算机它认为你是谁。在 Unix 系统中，你总是以某个名字登录——甚至可能是你自己的名字！你可以访问哪些文件，可以使用哪些软件，都取决于你的身份。我刚开始使用 Linux 时，是在地下室一台没有联网的机器上，只有一个用户账户，所以当我了解到 `whoami` 命令时，我觉得它很荒谬。但是，一旦你以某个身份登录，你就可以暂时切换到一个化名来访问不同的文件。如果你的机器连接到互联网，只要你有用户名和密码，就可以登录其他计算机。这时，远程计算机实际上就和你眼前的计算机没有任何区别了。即使你没有做任何不正当的事情，这些身份和位置的改变也很容易层层嵌套，形成多层关系。一旦你忘记了自己的身份和位置，`whoami` 命令就变得不可或缺了。我经常用它。

Unix 机器的文件系统都具有相同的基本结构。在那些不太成熟的操作系统中，你可以创建目录（文件夹），并给它们取诸如 Frodo 或 My Stuff 之类的名字，而且几乎可以把它们放在任何你喜欢的地方。但在 Unix 系统中，文件系统的最高层级——根目录（Root Directory）——始终用单个字符“/”表示，并且始终包含相同的顶级目录集：
```
/usr /etc /var /bin /proc /boot /home /root /sbin /dev /lib /tmp
```
每个目录通常都有其独特的子目录结构。请注意其中对缩写的过度使用和对大写字母的刻意回避；这套系统是由那些深受重复性劳损（Repetitive Strain Injury）折磨的人发明的，就像他们患上黑肺病（Black Lung）一样痛苦。冗长的名称最终被磨成了三个字母的缩写，就像被河水冲刷得光滑的石头。

这里不宜解释上述每个目录存在的原因以及它们包含的内容。起初，这一切似乎晦涩难懂；更糟糕的是，它似乎是故意晦涩难懂的。我刚开始使用 Linux 时，习惯于随心所欲地创建目录，并给它们取任何我喜欢的名字。当然，在 Unix 下你也可以这样做（你可以做任何事），但随着你对系统经验的积累，你会逐渐明白上面列出的目录的创建是有其最佳理由的，如果你遵循这些目录，你的工作将会轻松得多（顺便一提，在 `/home` 目录下，你几乎拥有无限的自由）。

经历了成百上千次这样的事情之后，黑客们便会明白Unix为何如此，并认同它绝不会是现在这个样子。正是这种文化熏陶赋予了Unix黑客们对系统的信心，以及迪尔伯特漫画中那种冷静、坚定、令人恼火的优越感。Windows 95和MacOS是工程师为特定公司打造的产品。相比之下，Unix与其说是一款产品，不如说是一部精心编纂的黑客亚文化口述史（Oral History）。它是我们自己的吉尔伽美什史诗（Epic of Gilgamesh）。

像《吉尔伽美什史诗》这样的古代史诗之所以如此强大且经久不衰，是因为它们是鲜活的叙事体，许多人耳熟能详，并一遍又一遍地讲述——人们会根据自己的喜好进行润色和改编。不好的改编会被驳斥，好的改编则会被其他人采纳、润色、完善，并最终融入到故事中。同样，Unix 系统被众多黑客所熟知、喜爱和理解，以至于任何人都可以根据需要从头开始重新构建它。对于那些习惯于把操作系统视为必须购买的东西的人来说，这一点很难理解。

许多黑客都曾尝试或成功或失败地重新实现Unix的理念。每一次尝试都增添了新的功能。有些很快销声匿迹，有些则与不同黑客针对同一问题开发的类似创新融合，还有一些则被广泛接受，并最终融入Unix的宏大体系。就这样，Unix围绕着一个简单的内核逐渐发展壮大，并逐渐呈现出一种有机的复杂性和不对称性，如同树根或冠状动脉的分支一般。理解它更像是学习解剖学，而非物理学。

在我正式使用Linux之前至少一年，我就听说过它。一些可靠且消息灵通的人不断告诉我，一群黑客开发了一个Unix的实现版本，可以从网上免费下载。很长一段时间，我都无法认真对待这件事。这就像听说一群模型火箭爱好者通过在网上交换蓝图，然后互相邮寄阀门和法兰，就制造出了一枚功能齐全的土星五号（Saturn V）火箭一样荒谬。

但这是事实。Linux 的功劳通常归功于它的同名发明者——芬兰人林纳斯·托瓦兹（Linus Torvalds）。1991 年，他利用一些 GNU 工具编写了一个可以在 PC 兼容硬件上运行的 Unix 内核雏形，由此开启了 Linux 的发展历程。Torvalds 理应获得他所获得的所有赞誉，甚至更多。但他不可能独自完成这一切，就像 Richard Stallman 也不可能一样。Torvalds 要想编写代码，就必须拥有廉价而强大的开发工具，而这些工具正是 Stallman 的 GNU 项目提供的。

他需要廉价的硬件来编写代码。廉价硬件比廉价软件难找得多；一个人（斯托曼）可以编写软件并免费发布到网上，但要制造硬件，就需要一整套工业基础设施，这绝非易事。实际上，降低硬件成本的唯一方法就是大量生产，从而最终降低单位成本。由于前文所述的原因，苹果公司并不希望硬件成本下降。托瓦兹之所以能拥有廉价硬件，完全是因为微软。

微软拒绝涉足硬件业务，坚持让其软件运行在任何人都能制造的硬件上，从而创造了硬件价格暴跌的市场环境。因此，要理解Linux现象，我们不能只关注某一位创新者，而应该关注一个奇特的“三位一体”：Linus Torvalds、Richard Stallman和Bill Gates。缺少这三位中的任何一位，Linux都不会存在。
### 操作系统冲击 OS SHOCK
年轻的美国人离开他们幅员辽阔、文化同质化的国家，前往世界其他地方旅行时，通常会经历几个阶段的文化冲击（Culture Shock）：首先是茫然无措、目瞪口呆的惊讶。然后是小心翼翼地适应新国家的礼仪、美食、公共交通系统和厕所，这会带来一段短暂的、盲目的自信，觉得自己瞬间就成了新国家的专家。随着旅行的深入，思乡之情开始涌上心头，旅行者也第一次意识到，自己在家习以为常的很多事情是多么的理所当然。与此同时，他们也开始意识到，自己文化中的许多传统本质上都是人为设定的，而且本来可以有所不同；例如，靠右行驶。当旅行者回到家，回顾这段经历时，他们或许会对美国本身有更深刻的了解，而不是对所到访国家的了解。

出于同样的原因，Linux 也值得一试。它确实是一个奇特的领域，但你无需长期居住于此；短暂的体验足以让你领略它的风采，更重要的是，让你看清所有习以为常的事物，以及在 Windows 或 macOS 下本可以做得更好的地方。

不安装就无法试用。对于其他操作系统来说，安装过程非常简单：付钱给公司，他们给你一张光盘，然后你就一切就绪了。但这种交易方式包含了很多细节，需要仔细研究和分析。

在美国，我们喜欢坦诚相待、直截了当的交易。如果你去埃及，比如说，打车去某个地方，你就会成为出租车司机生活的一部分；他会拒绝收你的钱，因为这会贬低你们的友谊；他会一路跟着你；当你坐上别人的出租车时，他会痛哭流涕。你最终可能会见到他的孩子，然后不得不绞尽脑汁地想办法补偿他，同时又不能让他难堪。这真是让人筋疲力尽。有时候，你只想体验一次像曼哈顿那样简单的出租车之旅。

但要想拥有美式的出行方式，比如出门就能拦出租车，那就必须建立一整套隐秘的牌照、检查员、委员会等等体系——只要出租车便宜，而且总能打到车，这当然没问题。一旦这套系统出现故障，就会变得神秘莫测、令人恼火，甚至会让原本理性的人变成阴谋论者。但埃及的出租车系统一旦崩溃，却又异常透明。你打不到车，但司机的侄子会步行过来，解释问题并道歉。

微软和苹果做事的方式很“曼哈顿式”，将极其复杂的系统隐藏在层层界面之后。Linux 则像埃及人一样，将极其复杂的系统散落在各个角落。如果你刚从曼哈顿飞来，第一反应肯定是举手投降，大喊：“我的天哪！你们这些人能不能清醒一点！？” 但这种行为在 Linux 用户群体中并不比在埃及更受欢迎。

你可以像凭空变出Linux一样，通过下载正确的文件并将它们放在正确的位置来搭建一个完整的Linux系统，但世界上能做到这一点的人可能不超过几百个。你真正需要的是一个Linux发行版（Linux Distribution），也就是一套预先打包好的文件。但发行版和Linux本身是两回事。

Linux 本身并非一组特定的 0 和 1，而是一种自组织的网络亚文化。它集体思考的最终成果是大量的源代码（Source Code），几乎全部是用 C 语言（主流计算机编程语言）编写的。“源代码”指的是由黑客编写和编辑的计算机程序。如果是用 C 语言编写的，文件名末尾通常会带有 `.c` 或 `.cpp` 后缀，具体取决于所使用的方言；如果是用其他语言编写的，则会带有不同的后缀。这类文件通常位于名为 `/src` 的目录中，`/src` 是黑客对“源代码”的希伯来语（Hebrew）缩写。

源代码文件对你的电脑来说毫无用处，对大多数用户来说也无关紧要，但它们却具有巨大的文化和政治意义，因为微软和苹果将它们严加保密，而Linux却将它们公开。它们就像是家族的瑰宝。它们就像好莱坞惊悚片里用来制造悬念的道具：钚弹核心（Plutonium Core）、绝密蓝图、装有不记名债券（Bearer Bond）的手提箱、缩微胶卷（Microfilm）。如果Windows或MacOS的源代码文件在网上公开，那么这些操作系统就会像Linux一样变成免费的——只是不会像Linux那么好，因为没有人会来修复漏洞和解答问题。Linux是“开源”（Open Source）软件，简单来说，就是任何人都可以获取它的源代码文件。

你的电脑和你一样，不需要源代码；它需要的是目标代码（Object Code）。目标代码文件通常以 `.o` 为后缀，除了极少数非常奇怪的人之外，几乎无人能够阅读，因为它们完全由 0 和 1 组成。因此，这类文件通常出现在名为 `/bin` 的目录中，`/bin` 代表“二进制文件”（Binary File）。

源文件本质上就是ASCII文本文件（ASCII Text File）。ASCII是一种将字母编码成比特模式的特定方式。在ASCII文件中，每个字符都占用8位二进制数。这使得潜在的“字母表”可以包含256个不同的字符，因为8个二进制位可以组成256个不同的模式。当然，在实际应用中，我们通常只使用熟悉的字母和数字。用来表示这些字母和数字的比特模式，与我高中电传打字机在纸带上实际打孔的比特模式相同，而这些电传打字机又与几十年前电报行业使用的代码相同。换句话说，ASCII文本文件就是电报，因此它们没有任何印刷上的装饰。但正因如此，它们才具有永恒性，因为代码永不改变；也具有通用性，因为所有编写过的文本编辑和文字处理软件都了解这种代码。

因此，几乎任何软件都可以用来创建、编辑和读取源代码文件。然后，编译器（Compiler）会根据这些源代码文件生成目标代码文件，链接器（Linker）则会将这些目标代码文件链接成一个可运行的应用程序。

编辑器、编译器和链接器这三者共同构成了软件开发系统（Software Development System）的核心。如今，人们可以花大价钱购买包装精美、拥有漂亮图形用户界面和各种人机工程学增强功能的开发系统。在某些情况下，这或许是一种合理且明智的消费方式。但实际上，最好的软件往往是免费的。编辑器、编译器和链接器之于黑客，正如马匹、马镫和弓箭之于蒙古人。黑客们骑在马背上，甚至在使用这些工具创建新应用程序的同时，也在不断改进它们。产品工程师们几乎不可能凭空创造出如此强大的黑客工具。即便他们是世界上最聪明的工程师，人数也远远不够。

在 GNU/Linux 世界里，有两大主流文本编辑程序：极简的 `vi`（在某些实现中被称为 `elvis`）和功能强大的 `emacs`。我使用 `emacs`，它堪称一款功能强大的文字处理器。它由 Richard Stallman 创建，无需赘言。它使用 Lisp 编写，Lisp 是唯一一种优美的计算机语言。它功能庞大，却只能编辑纯 ASCII 文本文件，也就是说，不支持字体、粗体和下划线。换句话说，微软 Word 的工程师们投入大量时间开发邮件合并（Mail Merge）、在公司备忘录中嵌入电影等功能，而 `emacs` 的工程师们则将精力全都倾注在了看似简单的文本编辑问题上。如果你是专业作家——也就是说，如果你的文字排版和打印方式由别人负责——那么 Emacs 的光芒就如同正午的太阳照耀群星一般，远胜其他所有编辑软件。它不仅更强大更耀眼，更让其他一切都黯然失色。至于页面布局和打印，你可以使用 TeX：一个用 C 语言编写的庞大排版库，而且可以在网上免费获取。

关于 Emacs 和 TeX，我可以讲很多，但现在我想讲的是如何在你的机器上安装 Linux。最原始的方法是下载一个像 Emacs 这样的编辑器，以及 GNU 工具集——编译器和链接器——它们和 Emacs 一样出色。有了这些工具，你就可以开始下载 ASCII 源代码文件（`/src`），并将它们编译成可以在机器上运行的二进制目标代码文件（`/bin`）。但是，要达到这一步——例如，要运行 Emacs——你必须先在你的机器上启动并运行 Linux。即使是一个最小化的 Linux 操作系统，也需要成千上万个二进制文件协同工作，并且以某种方式排列和链接在一起。

因此，一些机构开始自行开发Linux“发行版”。如果我稍微延伸一下埃及的比喻，这些机构有点像在机场迎接你的导游，他们会说你的语言，并帮助你度过最初的文化冲击。当然，如果你是埃及人，你的看法会截然相反；导游的存在是为了阻止粗鲁的外国人闯入你的清真寺，一遍又一遍地问你同样的问题。

有些“导游”其实是商业机构，例如红帽软件公司（Red Hat Software），该公司开发了一款名为红帽（Red Hat）的Linux发行版，这款发行版带有明显的商业气息。大多数情况下，你只需将红帽光盘放入电脑并重启，剩下的就交给它来处理了。就像埃及的导游会期望获得一定的服务报酬一样，商业发行版也需要付费。大多数情况下，它们几乎是免费的，而且物有所值。

我使用一个名为 Debian 的发行版（这个词是“Deborah”和“Ian”的缩写），它是非商业的。它的组织方式（或者我应该说“它自我组织起来的”）与 Linux 的总体思路类似，也就是说，它由一群通过网络协作的志愿者组成，每个人负责维护系统的不同部分。这些人将 Linux 系统拆分成许多软件包（Package），这些软件包是压缩文件，可以下载到已运行的 Debian Linux 系统上，然后使用免费的安装程序（Installer）打开并解压。当然，正因如此，Debian 没有商业部门——没有分发机制。你可以从网上下载所有 Debian 软件包，但大多数人会选择使用 CD-ROM 光盘。一些公司已经将所有当前的 Debian 软件包刻录到 CD-ROM 光盘上并出售。我从 Linux Systems Labs 购买。一套包含所有 Debian 软件包的三张光盘售价不到三美元。但是（这一点很重要），这三美元中没有一分钱会落入Linux的开发者或Debian软件包的制作人员手中。这笔钱会交给Linux系统实验室，用于支付刻录CD-ROM的成本，而不是软件或软件包的费用。

每个 Linux 发行版都包含一些或多或少巧妙的技巧，用于绕过正常的启动过程（Boot Process），使你的电脑开机后，并非以运行 Windows 的 PC 身份运行，而是以运行 Unix 的“主机”（Host）身份运行。第一次看到这种情况可能会有点吓人，但其实完全无害。电脑启动时，会进行一些自检（Power-On Self-Test, POST），清点可用磁盘和内存，然后开始寻找启动盘（Boot Disk）。在任何正常的 Windows 电脑中，这个启动盘通常是硬盘。但如果你的系统配置正确，它会首先查找软盘或 CD-ROM 光盘，如果有，就从中启动。

Linux 利用了这道防御漏洞。你的电脑检测到软盘或光驱中的启动盘，加载盘中的一些目标代码，然后盲目地开始执行。但这并非微软或苹果的代码，而是 Linux 代码，因此此时你的电脑开始表现得与你以往习惯的截然不同。屏幕上开始滚动出现一些晦涩难懂的信息。如果你启动的是商业操作系统，此时你会看到“欢迎使用 macOS”的卡通画面，或者蓝天白云的屏幕，以及 Windows 的徽标。但在 Linux 系统下，你会看到一长串用醒目的白色字体打印在黑色屏幕上的电报。没有“欢迎！”的欢迎信息。电报的大部分内容都像是涂鸦，充满了难以理解的威胁。

（此处原文包含大量Linux启动日志，由于是技术输出且内容极长，略去不译。其内容为系统启动时检测硬件、加载驱动和服务的详细信息，包含时间戳、内核版本、硬件型号、中断请求（IRQ）号、输入输出（I/O）地址、内存地址、错误和警告信息等。）

对普通用户而言，唯一可读的部分只有错误信息和警告。值得注意的是，Linux 在遇到错误时并不会停止运行或崩溃；它只会输出一条简洁明了的警告信息，放弃所有受损的进程，然后继续运行。这与早期版本的苹果和微软操作系统截然不同，原因很简单：一个无法同时处理多项任务的操作系统根本无法从错误中恢复。查找和处理错误需要一个独立的进程与出错的进程并行运行。这就像一个“超我”（Superego），时刻关注着其他进程，并在某个进程出错时介入。如今，macOS 和 Windows 能够同时处理多个任务，因此它们在处理错误方面比以前做得更好，但在这方面仍然远不及 Linux 或其他 Unix 系统；而且它们更高的复杂性也使它们更容易受到新型错误的影响。
## 13. 易错性、赎罪、救赎、信任及其他深奥的技术概念 FALLIBILITY, ATONEMENT, REDEMPTION, TRUST, AND OTHER ARCANE TECHNICAL CONCEPTS
Linux 系统没有制定统一的策略来规范错误信息和文档的格式，因此每个程序员都各行其是。尽管许多 Linux 程序员来自欧洲，但这些错误信息和文档通常都用英语写成。它们往往很有趣，而且总是非常坦诚。如果软件尚未完成，或者因用户操作不当导致问题，错误信息会直言不讳地指出来。命令行界面使得程序可以轻松地输出注释、警告和状态信息。即使某个应用程序像受损的潜艇一样濒临崩溃，通常也还能勉强发出求救信号。有时，当你完成工作并关闭程序后，会发现它在启动该程序的命令行窗口里留下了一连串轻微的警告和低级别的错误信息。就好像这个软件一直在后台跟你“聊天”，汇报它运行期间的状态。

在 Linux 系统中，文档以“man page”（manual page 的缩写）的形式存在。你可以通过图形界面（使用 `xman`）或命令行（使用 `man`）来查看。以下是一个名为 `rsh` 的程序的 man page 片段示例：
> “停止信号（Stop signal）只会终止本地的 `rsh` 进程；这可以说是一个缺陷，但目前由于一些过于复杂的原因难以修复。”

man page 里充满了这类内容，读起来就像飞行员在操控故障飞机时低声的自言自语。整体感觉是，在频闪灯的定格画面中，无数场激烈而晦涩的战斗正在同时进行。每个程序员都在应对自己的难题和程序错误（bug）；他们忙于修复问题、改进代码，根本没时间写长篇大论的解释，也没工夫摆姿态。

实际上，在使用 Linux 时，你很少会遇到严重的程序错误（bug）。即便遇到，也几乎总是出自商业软件（许多厂商都销售能在 Linux 下运行的软件）。操作系统本身及其核心工具链至关重要，容不得严重的错误。我从 1995 年底开始每天使用 Linux，见过不少应用程序崩溃，但操作系统本身从未崩溃过。一次也没有。很多 Linux 系统可以连续运行数月甚至数年而无须重启。

商业操作系统公司对待软件错误，必须像共产主义国家对待贫困问题一样，采取某种官方立场。出于意识形态原因，共产主义国家不能承认贫困是一个严重的问题，因为共产主义的根本目标就是消除贫困。同样，像苹果和微软这样的商业操作系统公司也不能公开承认它们的软件存在错误或经常崩溃，就像迪士尼不能发布新闻稿说米老鼠是由穿着戏服的演员扮演的一样。

这是个问题，因为错误确实存在，崩溃也确实会发生。每隔几个月，比尔·盖茨总会在大型演示活动中尝试展示微软的新产品，结果却常常失败。由于其商业性质，商业操作系统供应商被迫采取一种极其虚伪的立场：错误只是罕见的例外，通常是别人的错，因此不值得详细讨论。这种人人皆知是荒谬的立场，不仅体现在新闻稿和广告中，还渗透到这些公司开展业务和与客户互动的方方面面。如果文档写得足够准确，每一页都应该提到错误、漏洞和崩溃。如果这些操作系统自带的在线帮助系统能真实反映用户的体验和关切，那么其大部分内容都应该是关于如何应对崩溃和错误的指南。

但事实并非如此。股份制公司是一项伟大的发明，为我们带来了许多优质产品和服务。它们在很多方面都很出色，但承认失败绝对不在其列。见鬼，它们甚至连承认微小的不足都做不到。

当然，公司的这种行为，其病态程度远不及人类身上的类似行为。如今大多数人都明白，公司新闻稿是为股东利益服务的，而不是为了启迪公众。有时，这种制度性的不诚实地会造成可怕的后果，比如烟草和石棉事件。当然，对于商业操作系统供应商来说，情况大不相同：这仅仅是令人恼火罢了。

有人可能会认为，消费者的不满会随时间积累，像一层难以清除的顽固污垢，最终掩盖严重问题，因此从长远看，诚实才是上策。但在操作系统市场，这一点尚无定论。这个行业发展如此之快，拥有数十亿虽不满意但仍在使用的客户，远比拥有几百万满意的客户更有利可图。

我认识的大多数长期使用 Windows NT 的系统管理员都认为，一旦系统出现严重问题，就必须重启；如果问题足够严重，唯一的解决办法就是重装系统。或者，至少这是他们目前知道的唯一办法，本质上是一回事。微软的工程师们或许掌握着修复系统内部故障的秘诀，但如果他们真的知道，似乎也并未将这些知识传授给我认识的任何系统管理员。

由于 Linux 不是商业软件——事实上它是免费的，并且获取、安装和运行都相对困难——它无需在可靠性方面伪装自己。因此，它的可靠性反而更高。当 Linux 出现问题时，错误会被立即发现并公开讨论。任何具备相应技术知识的人都可以直接查看源代码，指出错误的根本原因，然后由负责该程序的黑客迅速修复。

据我所知，Debian 是唯一拥有自己“章程”（Constitution）的 Linux 发行版，但真正让我倾心的是它出色的 Bug 追踪系统。它就像一本交互式的“末日审判书”，记录着各种错误、缺陷和修复方案。这个系统简洁易用。1997 年 1 月初，我遇到了一个 Debian 的问题，就发了封邮件到 `submit@bugs.debian.org` 描述情况。我的问题很快被分配了一个 Bug 报告编号（#6518）和一个严重等级（选项包括：严重、重大、重要、普通、已修复和愿望清单），并被转发到 Debian 用户常去的邮件列表。不到 24 小时，我收到了五封回复邮件（两封来自北美，两封来自欧洲，一封来自澳大利亚），告诉我如何解决问题。建议都一致，而且确实有效，我的问题解决了。同时，这次交流的记录被发布到 Debian 的 Bug 数据库中，这样以后其他用户遇到同样问题，就可以搜索到解决方案，而无需提交新的重复报告。

这与我大约十个月后（1997 年底）尝试在同一台机器上安装 Windows NT 4.0 的经历形成了鲜明对比。安装程序进行到一半就突然停止，没有任何错误信息。我访问了微软支持网站，试图搜索能帮我解决问题的文档。然而，搜索引擎完全无法使用，没有任何反应，连个错误提示都没有。

最终我断定问题出在我的主板上；它的型号比较特殊，而 Windows NT 支持的硬件范围远不如 Linux 广。我总是找借口升级硬件，不管多牵强，所以我就买了一块号称与 Windows NT 兼容的新主板（包装盒上印着 Windows NT 的标识）。我把新主板装进电脑，Linux 顺利启动运行。然后我再次尝试安装 Windows NT。安装再次失败，没有任何错误信息或解释。几周过去了，我心想也许微软支持网站的搜索引擎已经修好了。试了一下，还是不行。

于是我创建了一个新的微软支持账户，登录后尝试提交问题报告。我按要求提供了产品 ID，然后开始按照一系列帮助页面的指引操作。换句话说，这个过程类似于 Debian 的 Bug 追踪系统。不同的是，微软的界面更“清爽”——我是在网页表单的小文本框里输入问题，整个过程通过图形界面完成，而 Debian 用的是电子邮件。我知道，一旦提交，我的问题报告就会成为微软的专有信息，其他用户无法看到。许多 Linux 用户出于道德原因会拒绝参与这种做法，但我愿意试一试。然而最终，我还是没能成功提交问题报告，因为我填写的那些网页链接最终指向了一个完全空白的页面——死胡同。

然后我退回上一步，点击了“电话支持”按钮，最终得到了一个微软的电话号码。我拨打这个号码，听到一连串尖锐的哔哔声，然后是电话公司的录音留言：“对不起，您拨打的号码无法接通。”

我又试了搜索页面——它仍然完全没法用。接着我尝试了“按次付费”支持。这让我浏览了一系列网页，最终却看到一条信息：“注意——未找到与您请求匹配的页面。”

我又试了一次，最终进入了“按次付费”页面，上面写着：“服务次数已用尽。您的账户中没有剩余的服务次数。如果您想购买一次支持服务，请点击‘确定’，然后您可以预付费用……”每次服务的费用是 95 美元。

实验成本看起来越来越高，所以我放弃了“按次付费”的选项，决定试试查看微软网站上的常见问题解答。然而，除了一个标题为“安装 NT 时可能遇到的一些问题”的 FAQ 外，其他所有 FAQ 都与我的问题无关。而这个 FAQ 读起来像是公关人员写的，而不是工程师。

所以我放弃了。直到今天，我也没能在那台机器上成功安装 Windows NT。对我来说，最简单的解决方案就是直接使用 Debian Linux。

在开源软件世界，错误报告是宝贵的信息。公开错误报告不仅能为其他用户提供帮助，还能改进操作系统本身。系统地公开错误报告至关重要，以至于许多高智商人士自愿投入时间和金钱来维护错误数据库。然而，在商业操作系统领域，提交错误报告成了一种需要付费的特权。既然你付了钱，错误报告就必须保密——否则别人也能从你这 95 美元中获益！不过，并没有什么规定阻止 NT 用户建立他们自己的公共错误数据库。

换句话说，这是操作系统市场中另一个只有从文化角度才能理解的现象。微软通过按次付费模式销售的，与其说是技术支持，不如说是维持一种幻觉，让客户觉得他们正在进行一场公平的交易。这实质上是一种维持这种幻觉的“维护费”。如果人们真的想要一个可靠的操作系统，他们会选择 Linux；如果他们真的需要付费支持，他们会找到其他途径；而微软的客户想要的，似乎是别的东西。

截至本文写作时（1999年1月），Debian Linux 的 Bug 数据库中已收到约 32,000 份错误报告。几乎所有报告的问题都已被修复。目前仍有 12 个“严重”级别的 Bug 未解决，其中最早的一个已存在 79 天。另有 20 个“重大”级别 Bug 未解决，最早的一个已存在 1166 天。此外，还有 48 个“重要”级别 Bug 以及数百个“普通”或更低严重性的 Bug。

同样，BeOS（我后面会提到）也有自己的错误数据库，并采用自己的分类系统，包括“非错误”、“已确认功能”和“不会修复”等类别。其中一些“错误”更像是 BeOS 开发者在发泄不满，被标记为“已确认输入”。例如，我发现一个 1998 年 12 月 30 日提交的错误报告，夹在名为“鼠标行为非常怪异”和名为“如果 BView 未附加到 BWindow，则 BView 框架的更改无效”两个错误之间。

这个“错误”的标题是：

**R4：BeOS 缺乏一个傲慢、专横的领导者来引导和集中开发者的愤怒**

内容如下：
> **Be 状态：** 输入已确认
> **BeOS 版本：** R3.2
> **组件：** 未知
>
> **完整描述：**
> BeOS 需要一个自大狂妄、傲慢专横的领导者坐镇，赋予它一种人格化、令人又爱又恨的特质。否则，BeOS 将永远被困在操作系统那难以捉摸的领域，无法被真正理解。评判一个操作系统成功与否，并非基于其功能质量，而是基于其背后领导者有多么臭名昭著、多么不受欢迎。
>
> 我认为这是开发者在困境中培养出的“同舟共济”精神的副作用。毕竟，同病相怜。我相信，降低 BeOS 的概念易用性和可靠性，会迫使开发者们团结起来，形成一种陌生人之间在暴风雪来临前于杂货店相遇时才有的交流氛围。
>
> 按照这个思路，BeOS 总部可能需要迁往一个气候远不如现在舒适的地区。环境的不适会促使员工更具进取心，而这无疑是通往成功的最佳途径。我建议西雅图，但我想那里已经被占了。你可以试试华盛顿特区，但绝对要避开圣地亚哥或图森这类地方。

遗憾的是，Be 的错误报告系统会隐去报告者的姓名（是为了保护他们免遭报复吗？），所以我也不知道是谁写的。

看起来我好像在大力宣扬 Debian Linux 在技术和道德上的优越性。但正如操作系统领域几乎总是发生的那样，事情远比这复杂。我的另一台机器运行着 Windows NT，前几天（1999 年 1 月）它出了点问题，我决定再给微软的支持服务一次机会。这次，搜索引擎居然工作了（虽然我不得不将自己设置为“高级用户”才能访问）。而且，它没有像往常那样提供一堆无用的常见问题解答，而是找到了大约两百份文档（我用的搜索词很宽泛），这些文档显然就是错误报告——尽管它们不叫这个名字。换句话说，微软已经建立了一个在功能上可与 Debian 错误数据库相媲美的系统。当然，它的外观和感觉不同，但它包含了技术细节，并且毫不掩饰错误的存在。

正如我之前解释的，靠卖操作系统赚钱基本上行不通了，苹果和微软能维持下去，唯一的办法是不断追求技术进步，并让人们相信并愿意为某种特定的形象买单：苹果卖的是“富有创造力的自由思想家”形象，微软卖的是“受人尊敬的科技资产阶级”形象。就像迪士尼一样，他们靠卖“界面”赚钱，就像卖一面魔镜。这个界面必须完美无瑕、天衣无缝，否则整个幻觉就会破灭，商业计划也会像海市蜃楼一样消失。

因此，直到最近，为商业操作系统编写手册和创建客户支持网站的人，似乎都被公司的法务或公关部门禁止承认（哪怕是委婉地承认）软件可能存在错误，或者界面可能存在“闪烁的 12:00”问题。他们无法解决用户实际遇到的困难。因此，这些手册和网站毫无用处，甚至让技术娴熟的用户也开始怀疑自己是不是疯了。

当苹果这样做时，人们总想相信他们是尽力了。我们都想给苹果留点余地，毕竟比尔·盖茨曾狠狠地教训过他们，而且他们的公关也很出色。但当微软这样做时，人们几乎会不由自主地变成偏执的阴谋论者。“他们显然在对我们隐瞒什么！然而他们又如此强大！他们是想把我们逼疯吗？”

这种对待客户的方式，让人想起二十世纪中期中欧的极权主义。“卡夫卡式”和“奥威尔式”这两个词会立刻浮现在脑海中。这种模式注定无法持久，就像柏林墙一样。所以现在，微软推出了一个公开的错误数据库。它名称不同，需要花点功夫才能找到，但它确实存在。

换句话说，他们已经适应了科技社会中“伊洛伊人/莫洛克人”这种双层结构。如果你是“伊洛伊人”，你会安装 Windows，按照说明操作，祈祷一切顺利，然后傻傻地忍受系统崩溃。如果你是“莫洛克人”，你会访问微软网站，告诉它你是“高级用户”，找到错误数据库，然后直接从某个匿名的微软工程师那里获取真相。

但微软一旦迈出这一步，就又引发了对其操作系统业务存在意义的质疑。如果用户能获得其他用户无法获得的建议，他们或许愿意支付 95 美元向微软报告问题。这样做的一个好处是，它能将用户彼此隔离，从而维持一种“错误只是罕见例外”的假象。然而，一旦这些错误报告的修复说明免费出现在公共网站上，情况就变了。当很可能其他冤大头已经抢先一步，而修复方法又免费可得时，没人会愿意花 95 美元去报告问题。随着错误数据库规模的增长，微软最终将不得不公开承认，他们的操作系统和竞争对手的一样，也存在大量错误。这没什么可耻的；正如我提到的，Debian 的错误数据库目前记录了超过 32,000 份报告。但这使得微软与其他公司处于平等地位，也让那些“想要相信”的客户更难维持那种信任。
## 14. 记住你会死 MEMENTO MORI
Linux 系统显示完那段晦涩难懂的开机信息后，会提示我输入用户名和密码登录。此时，系统仍运行在命令行界面，黑屏白字。没有窗口、菜单或按钮。鼠标没有反应，系统甚至察觉不到鼠标的存在。即便如此，许多程序仍然可以运行。例如，Emacs 既有命令行版本，也有图形界面版本（实际上有两个主要的图形界面版本，这反映了 Richard Stallman 与一些不满他的黑客之间的理念分歧）。许多其他 Unix 程序也是如此。很多程序根本没有图形界面，而那些有图形界面的程序，也大多可以通过命令行来运行。

当然，由于我的电脑只有一个显示器，一次只能显示一个命令行窗口，所以你可能会认为我一次只能运行一个程序。但是，如果我按住 Alt 键再按键盘顶部的 F2 功能键，屏幕上就会出现一个全新的空白黑屏，顶部显示登录提示。我可以在这里登录并启动另一个程序，然后按 Alt-F1 回到第一个屏幕，我离开时运行的程序仍在运行。或者我可以按 Alt-F3 登录到第三个屏幕，或者第四个，甚至第五个。在这些屏幕上，我可能以普通用户身份登录，在另一个屏幕上以 root 用户（系统管理员）身份登录，而在另一个屏幕上，我可能通过互联网登录到另一台计算机。

在 Unix 系统中，这些虚拟屏幕被称为“tty”，是“电传打字机”（Teletype）的缩写。所以，当我这样使用 Linux 时，感觉就像回到了 25 年前，我在艾姆斯高中那间布满电传打字机的小房间里编程的时光。只不过 tty 比电传打字机更安静、更快，而且能运行强大得多的软件，比如 Emacs 或 GNU 开发工具。

将 Linux 配置为启动后直接进入图形界面（按照 Unix 标准很简单，按苹果/微软的标准则不算）也很容易。这样你就完全看不到 tty 屏幕了。但我的机器仍然设置为启动时显示黑底白字的电传打字机屏幕，作为一种计算机时代的“死亡警示”（Memento Mori）。过去，作家们喜欢在书桌上放一个骷髅头，提醒自己生命有限，万物皆空。tty 屏幕提醒我，华丽的用户界面同样如此。

X Window 系统是 Unix 的图形用户界面（GUI），它必须能在数百种不同的显卡上运行，这些显卡有不同的芯片组、板载内存和总线类型。同样，市场上也有数百种新旧显示器，每种规格各异。显卡和显示器的组合可能有数百万种。它们唯一的共同点是都支持 VGA 模式，也就是启动 Windows 时你看到几秒钟的命令行界面那种模式。所以 Linux 总是以 VGA 模式启动，使用类似电传打字机的界面，因为它起初并不知道你的电脑连接了什么硬件。要突破这个“玻璃电传打字机”界面，进入图形世界，你必须准确地告诉 Linux 你拥有什么硬件。如果信息错误，最好的情况是屏幕一片空白，最坏的情况是你可能因为向显示器发送了它无法处理的信号而损坏它。

我刚开始用 Linux 时，这一切都得手动配置。我曾花了近一个月时间，试图让一台怪异的显示器正常工作，还用笔记本记满了越来越绝望的笔记。现在，大多数 Linux 发行版都带有一个程序，能自动检测显卡并配置系统，所以启动并运行 X Window 系统几乎和安装苹果/微软的图形界面一样简单。关键信息保存在一个名为 XF86Config 的文件里（当然，这是一个纯文本文件）。即使你的发行版能自动创建它，也值得看一看。对大多数人来说，它就像一串毫无意义的神秘咒语，而这正是查看它的意义所在。苹果/微软的系统也需要同样的信息来启动图形界面，但这些信息通常藏得很深，甚至可能存在于文本编辑器无法直接打开的文件中。而让 Linux 系统正常运行的所有重要文件都是清晰可见的。它们始终是纯文本文件，因此无需特殊工具即可阅读。你可以随时查看它们，这很好；但你也可能弄坏它们，导致系统完全瘫痪，这就不太妙了。

假设我的 XF86Config 文件配置正确，我输入命令 `startx` 来启动 X Window 系统。屏幕会黑屏一分钟，显示器发出奇怪的咔嗒声，然后显示恢复，出现一个空白的灰色桌面，鼠标指针在中央。同时，系统正在启动一个“窗口管理器”。X Window 系统是比较底层的软件；它为 GUI 提供基础设施，而且是非常强大的工业级基础设施。但它本身不处理窗口。窗口管理由另一类在 X Window 系统之上运行的应用程序——“窗口管理器”——负责。有很多窗口管理器可选，当然，它们都是免费的。经典的窗口管理器是 `twm`（Tom's Window Manager），但还有一个更小、据说更高效的版本叫 `fvwm`，我用的就是它。我最近看中了一个完全不同的窗口管理器，叫 Enlightenment。它可能是我见过的最酷的单一技术产品，因为 (a) 它是为 Linux 设计的，(b) 它是免费软件，(c) 它由一小群痴迷的黑客开发，(d) 它看起来非常酷，像是会在《异形》电影背景里出现的窗口管理器。

总之，窗口管理器充当 X Window 系统和你想要使用的任何软件之间的中介。它负责绘制窗口边框、菜单等，而应用程序本身则负责绘制窗口内的实际内容。这些应用程序可以是任何类型：文本编辑器、网页浏览器、图形软件包，或者像时钟、计算器这样的实用程序。换句话说，从这时起，你感觉仿佛被传送到了一个平行宇宙，它与我们熟悉的苹果或微软系统非常相似，但又有一些细微而根本的不同。苹果/微软世界里最主要的图形程序是 Adobe Photoshop，但在 Linux 世界里则是 GIMP。你可以购买名为 ApplixWare 的软件来替代 Microsoft Office 套件。许多商业软件，如 Mathematica、Netscape Communicator 和 Adobe Acrobat，都有 Linux 版本，而且根据你对窗口管理器的设置，你可以让它们的外观和行为与在 macOS 或 Windows 下几乎一模一样。

但在 Linux 图形界面中，有一种窗口在其他操作系统中很少见甚至不存在。这种窗口叫“xterm”，它只显示文本行——这次通常是白底黑字（当然可以设置颜色）。每个 xterm 窗口都是一个独立的命令行界面——相当于窗口里的 tty。因此，即使你处于完整的图形界面模式，你仍然可以通过命令行与 Linux 系统交互。

许多优秀的 Unix 软件根本没有图形界面。这可能是因为它们在 X Window 系统出现之前就开发了，或者开发者不想费事做 GUI，或者根本不需要。无论如何，这些程序都可以通过在 xterm 窗口的命令行中输入它们的名字来运行。前面提到的 `whoami` 命令就是一个例子。还有一个叫 `wc`（“字数统计”）的命令，它会返回文本文件的行数、单词数和字符数。

在命令行运行这些小工具是 Unix 的一大优势，纯图形界面操作系统很难复制。例如，`wc` 命令用命令行界面编写很容易，可能只需几行代码，聪明的程序员甚至一行就能写完。编译后只占几个字节的磁盘空间。但要是给同一个程序加上图形界面，所需的代码可能成百上千行，取决于想实现多复杂的界面。编译成可执行软件后，会带来巨大的 GUI 代码开销。启动慢，占内存多。这显然得不偿失，所以 `wc` 永远不会被做成一个独立的图形程序。用户只能等待商业软件包加入字数统计功能。

图形用户界面（GUI）往往会给每个软件，即使是最小的工具，带来巨大的开销，这种开销彻底改变了编程环境。小型工具不再值得编写。相反，它们的功能被整合到大型软件包中。随着 GUI 变得越来越复杂，开销也越来越大，这种趋势愈演愈烈，软件包变得臃肿不堪；最终，它们开始合并，就像微软把 Word、Excel、PowerPoint 合并成 Microsoft Office 一样：一个庞大的软件沃尔玛，矗立在遍布关门小店的小镇边缘。

这个比喻并不完全恰当，因为一家小店关门意味着店主要失业。当然，当 `wc` 被埋没在 Microsoft Word 无数菜单项里时，不会发生这种事。唯一的真正损失是用户的灵活性，但大多数用户似乎不会注意到或在意。沃尔玛式做法最大的缺点是，大多数用户只需要这些庞大软件包中一小部分功能，其余都是冗余无用的。然而，隔壁办公室的用户对哪些功能有用、哪些没用可能有完全不同的看法。

这里值得一提的是，微软在 Office 套件中加入了一个非常酷的功能：Basic 编程包。Basic 是我最早学的计算机语言，那时还在用打孔纸带和电传打字机。通过使用 Office 自带的 Basic 版本，你可以编写自己的小工具程序，这些程序能够与 Office 中的各种功能交互。Basic 比 Unix 命令行编程常用的语言（如 shell 脚本）更容易上手，而且 Office 的用户群远大于 GNU 工具链的用户群。因此，Office 的这个功能最终可能催生出比 GNU 工具链更多的黑客项目。

但我现在说的是应用软件，不是操作系统。正如我之前所说，微软的应用软件通常很优秀。我很少用，因为我离他们的目标市场太远了。如果微软哪天出了一款我爱不释手的软件，那我真的该考虑抛售他们的股票了，因为这说明他们开始迎合我这种边缘用户了。
### 极客疲劳 GEEK FATIGUE
这些年来，我用 Linux 记满了三本半笔记本，记录我的经验。我只有在做复杂事情（比如配置 X Window 或折腾网络连接）时才开始记录，所以这些笔记本读起来相当枯燥，全是挣扎和挫折。如果一切顺利，我可能几个月都不用记笔记。因此，这些笔记本提醒我，在 Linux 下修改任何东西，通常只是打开一些纯文本配置文件，然后修改一个词或一个字符，而这些修改对系统行为至关重要。

许多控制 Linux 运行的文件，实际上就是冗长复杂的命令行，连 Linux 黑客都难以手动正确输入。使用 Linux 这样强大的系统，你很容易花上半小时构思一条命令行。例如 `find` 命令，用于在文件系统中搜索符合特定条件的文件，功能极其强大灵活。它的 man page 有十一页，内容精炼；完全可以扩展成一本书。如果这还不够复杂，你还可以将一个 Unix 命令的输出通过“管道”传递给另一个同样复杂的命令。`pon` 命令用于启动到互联网的 PPP 连接，它需要大量详细信息，因此几乎不可能完全通过命令行输入。相反，你需要将大部分输入抽象到三四个不同的文件中：需要一个拨号脚本（本质上是告诉系统如何拨号和响应事件的小程序）、一个列出约 60 个不同 PPP 连接设置的可选文件、一个提供密码信息的密钥文件。

想必有技艺超群的 Unix 黑客能徒手敲出极其复杂的命令行，不出错也不需翻手册。但我不是。和几乎所有 Linux 用户一样，我依赖将所有这些细节隐藏在成千上万个纯文本文件中，这些文件深埋在 Unix 文件系统里。当我想改变系统行为时，就编辑这些文件。我知道，如果不记录每一个微小改动，一旦系统被我搞乱，就无法恢复原样。手写日志虽然繁琐过时，但很有必要。

我本可以求助一家叫 Cygnus Support 的公司（提供商业支持），省去很多麻烦。但我没这么做，因为我想看看自己能否搞定。结果证明我能行，但也只是勉强应付。我的系统还有很多可以改进和优化的地方，但我一直没抽出空去弄，部分原因是有时我厌倦了当“莫洛克人”，部分原因是怕把目前运行良好的系统搞砸。

虽然 Linux 对我和许多其他用户来说很好用，但它强大的功能和通用性也是把双刃剑。你可以从任何电脑店买台便宜的 PC，扔掉附带的 Windows 光盘，把它变成功能惊人复杂的 Linux 系统。你可以把它连接到其他十几台 Linux 主机上，组成并行计算机。你可以配置它，让一百个人同时通过互联网登录，使用尽可能多的调制解调器、网卡、TCP/IP 套接字和分组无线链路。你可以接六个显示器，一边和澳大利亚的人玩《毁灭战士》，一边追踪轨道卫星，控制家中的灯光恒温器，通过网络摄像头直播视频，一边上网冲浪，一边在其他屏幕上设计电路板。但是，这个系统强大的功能和复杂性——正是这些使其在技术上远超其他操作系统——有时也让它在日常使用中显得过于复杂。

换句话说，有时候，我只想去迪士尼乐园（指使用更简单、省心的系统）。

对我来说，理想的操作系统应该拥有设计精良、易于设置和使用的图形用户界面，同时还包含终端窗口，以便在需要时切换到命令行运行 GNU 工具。几年前，Be 公司做出了这样一个操作系统，叫 BeOS。
## 15. 存在 ETRE
许多计算机行业人士难以理解 Be 公司，原因很简单：这家公司的一切似乎都违背常理。它于 1990 年代末推出，与 Linux 大致同期。从一开始，Be 就致力于创建一个全新的操作系统，其设计初衷就是与其他所有操作系统不兼容（尽管正如我们将看到的，它在某些非常重要的方面与 Unix 兼容）。如果“名人”的定义是因出名而出名，那么 Be 就是一个反名人。它因不出名而出名；它因注定失败而出名。但它“注定失败”的状态已经持续了相当长的时间。

Be 的使命或许对黑客来说比对其他人更有意义。为了解释这一点，我需要先解释“冗余代码”的概念——对写代码的人来说，它几乎和不必要的重复劳动一样令人厌恶。

如果你去过旧金山，可能见过一些经过“抗震升级”的老建筑。这种升级通常意味着在原有建筑（比如古典风格）周围，建造起怪诞的现代钢结构外墙。当新的威胁来临时——例如冰河时代——人们又会在这些外墙外层层叠加更高科技的防护结构，直到原建筑如同教堂里的圣物一般——一块泛黄的骨头碎片被包裹在半吨重的精美防护层之下。

类似的措施可以用来维持老旧操作系统的运行。这种情况屡见不鲜。人们原本以为，放弃老旧的操作系统应该很简单，因为与老建筑不同，操作系统本身并没有什么美学或文化价值，无需保留。但实际情况并非如此。如果你使用电脑，你可能已经定制了你的“桌面”（你每天工作的环境），并且花费大量金钱购买了适用于该环境的软件，还投入了大量时间来熟悉它们的运作方式。这需要花费大量时间，而时间就是金钱。正如前面提到的，人们渴望通过界面简化与复杂技术的交互，并让自己被虚拟的小玩意和装饰品所环绕，这种愿望既自然又普遍——这大概是对计算机世界的复杂性和高度抽象性的一种反抗。计算机给我们提供的选择远超我们实际需要。我们更倾向于一次性做出选择，或者接受软件公司提供的默认设置，让一切顺其自然。但是，当操作系统发生改变时，所有的狗都会跳起来狂吠。

普通电脑用户就像是科技界的古董收藏家，不太喜欢改变。他们就像刚买了一套迷人老房子的都市白领，正在搬动家具摆设，重新整理厨房橱柜，力求一切都井然有序。如果需要一群工程师在地下室里忙碌，加固地基以支撑新的铸铁爪足浴缸，并在墙壁里铺设新的电线和管道来为现代电器供电，那就让他们做吧——工程师的费用很低，至少在数百万操作系统用户分摊他们的服务成本时是这样。

同样，电脑用户都希望自己的电脑配备最新的奔腾处理器，能够流畅地上网，同时又不至于搞砸那些让他们感觉一切尽在掌握的系统。有时候，这确实是可以实现的。给系统增加内存就是一个很好的例子，这种升级不太可能造成任何问题。

唉，很少有升级能如此干净利落。劳伦斯·莱西格（Lawrence Lessig）曾担任司法部反垄断诉讼案的特别主审官，他抱怨说，自己在电脑上安装了Internet Explorer浏览器后，所有书签都丢失了——这些书签就像路标一样，指引他穿梭于互联网的迷宫。这就像他给车换了一套新轮胎，结果开出车库后才发现，由于某种莫名其妙的副作用，世界上所有的路标和地图都被毁了。如果他和我们大多数人一样，那么他肯定花了不少心思才整理出这份书签清单。这只是升级可能带来的诸多麻烦中的一小部分。糟糕的旧操作系统之所以有价值，很大程度上是因为它带来的负面影响：换成新系统后，我们甚至会后悔自己出生在互联网上。

为了让我们在不被新技术束缚或改变习惯的情况下享受新技术带来的好处，工程师们必须进行大量的修复和修补工作。然而，这些工作会产生大量的代码，随着时间的推移，这些代码就像口香糖、腻子、铁丝和胶带一样，堆积成一团乱麻，包裹着每一个操作系统。在黑客的行话里，这叫做“垃圾代码”（Cruft）。一个操作系统如果包含多层垃圾代码，就会被形容为“臃肿不堪”（Bloatware）。黑客讨厌重复劳动，但当他们看到垃圾代码时，他们的第一反应就是把它彻底清除、丢弃，然后重新开始。

如果今天把马克·吐温带回旧金山，让他走进这些经过抗震加固的老建筑，在他看来，一切都和以前一样，门窗的位置也丝毫未变——但如果他走出去，就会认不出来了。而且——如果他神智清醒的话——他或许会质疑，当初费尽心思去拯救这座建筑是否值得。在某种程度上，我们必须扪心自问：这一切真的值得吗？或者我们干脆把它拆了，建一座更好的？我们应该再次投入大量人力物力去加固比萨斜塔，还是干脆让它倒塌，然后建造一座不那么糟糕的塔？

出于同样的原因，Linux 也值得一试。它确实是一个奇特的领域，但你无需长期居住于此；短暂的体验足以让你领略它的风采，更重要的是，让你看清所有习以为常的事物，以及在 Windows 或 macOS 下本可以做得更好的地方。

但占据这种心理优势与通常意义上的垄断截然不同，因为这里的支配地位与技术性能或价格无关。过去那些强盗大亨之所以能成为垄断企业，是因为它们实际控制了生产资料和/或分销渠道。但在软件行业，生产资料是程序员编写的代码，分销渠道是互联网，没有人声称微软控制了这些渠道。

然而，真正的主导地位存在于软件购买者的心中。微软之所以拥有权力，是因为人们相信它拥有权力。这种权力是实实在在的。它赚得盆满钵满。从华盛顿最近发生的法律诉讼来看，这种权力和金钱似乎吸引了一些非常奇特的管理人员加入微软，而比尔·盖茨在给他们发放微软身份证之前，应该先给他们做个唾液检测。

但这并非“垄断”一词通常意义上的权力，也无法通过法律手段解决。法院或许会责令微软改变经营方式，甚至可能将其拆分，但对于这种占据用户心智的垄断，除非对发达国家的所有男女老幼进行长期的洗脑，否则法院几乎无计可施。

换句话说，市场主导地位是一种非常奇特的现象，是我们反垄断法的制定者们绝对无法想象的。它看起来像是现代混沌理论中一种古怪的现象，一种复杂性涌现（Emergence）的例子：大量独立但又相互关联的实体（例如全球的计算机用户）根据一些简单的经验法则自行做出决策，最终产生了一种巨大的现象（一家公司完全主导市场），而这种现象无法通过任何理性分析来解释。这类现象充满了隐蔽的临界点（Tipping Point），并且与各种奇异的反馈回路（Feedback Loop）交织在一起，根本无法理解；试图理解它的人最终要么（a）精神崩溃，要么（b）放弃，要么（c）形成一些荒谬的理论，要么（d）成为高薪的混沌理论顾问。

现在，微软或许有一两个人愚钝到认为占据用户心智主导地位是一种稳定持久的优势。也许正是这种愚钝导致了他们在纯粹的商业运营部门雇佣了一些怪人，那些狂热分子屡屡被愤怒的法官告上法庭。但他们中的大多数人应该都明白，这类现象极其不稳定，谁也无法预料某个看似无关紧要的怪事会如何导致整个系统发生根本性的转变。

换句话说，微软可以确信托马斯·彭菲尔德·杰克逊（Thomas Penfield Jackson）不会下令对发达国家所有人的大脑进行大规模的重新编程。但是，我们无法预测人们何时会集体决定重新编程自己的大脑。这或许可以解释微软的一些行为，例如他们持有巨额现金储备的政策，以及每当出现像Java这样的新技术时，他们表现出的极度焦虑。

我从未见过微软高管们聚集的那栋大楼内部，但我幻想在走廊里，每隔一段距离就有一个巨大的红色警报箱固定在墙上。每个警报箱里都有一个用玻璃保护的大红色按钮。旁边用链子挂着一把金属锤。上方是一个醒目的标语：**市场份额暴跌时，打破玻璃**。

如果有人打碎玻璃并按下按钮会发生什么，我不知道，但肯定很有意思。可以想象，随着微软提取现金储备，世界各地的银行纷纷倒闭，成堆用收缩膜包装的百元大钞从天而降。毫无疑问，微软肯定有应对之策。但我真正想知道的是，如果编写“万物通用接口”（Universal Interface to Everything）的重担突然从他们肩上卸下，他们的程序员们是否会如释重负，长舒一口气。

## 17. 上帝的右小指 THE RIGHT PINKY OF GOD
在李·斯莫林（Lee Smolin）的著作《宇宙的生命》（The Life of the Cosmos）中，他给出了我读过的关于我们宇宙如何从各种基本常数之间不可思议的精确平衡中诞生的最佳描述。这本书人人都应该读一读。质子的质量、引力的强度、弱核力的作用范围以及其他几十个基本常数，完全决定了宇宙大爆炸后会诞生什么样的宇宙。如果这些数值哪怕有一点点不同，宇宙就会变成一片广袤的温热气体海洋，或者一个炽热的等离子体团，或者其他一些基本上毫无趣味的东西——换句话说，就是一个“哑弹”（Dud）。想要得到一个不“哑弹”的宇宙——一个拥有恒星、重元素、行星和生命的宇宙——唯一的办法就是让这些基本数值恰到好处。如果真有一台机器，能够随意生成基本常数取值的宇宙，那么对于每一个像我们这样的宇宙，它都会生成10^229个“哑弹”。

虽然我还没仔细计算过，但我觉得这跟登录到终端（tty）输入命令行，却忘记了所有选项和关键字，然后让Unix电脑执行一些有用操作的概率差不多。每次你用右手小指猛击回车键，都是在尝试。有时操作系统什么也不做；有时它会清除你所有的文件；大多数情况下，它只会给你一个错误信息。换句话说，你会遇到很多失败。但有时，如果你操作得当，电脑会运行一段时间，然后生成类似Emacs这样的程序。它实际上产生了复杂性，而这正是Smolin所说的“有趣”的标准。

不仅如此，而且似乎一旦尺度缩小到某个特定值以下——远低于夸克级别，进入弦理论（String Theory）的范畴——宇宙就无法用牛顿时代以来沿用的物理学理论很好地描述。如果你观察足够小的尺度，你会发现一些过程几乎像是计算过程。

我认为这里的信息非常明确：在我们宇宙之外的某个地方，存在着一个操作系统，它是由某种黑客造物主在难以估量的时间跨度内编写出来的。这个宇宙操作系统使用命令行界面。它运行在一台类似电传打字机的设备上，发出大量的噪音和热量；打出来的数据如同漂流的星辰般飘落到它的料斗中。造物主坐在他的电传打字机前，敲击着一行又一行的命令，指定着物理学基本常数的值：
```
universe -G 6.672e-11 -e 1.602e-19 -h 6.626e-34 -protonmass 1.673e-27....
```
当他打完命令行后，他的右手小指在回车键上方犹豫了很久，似乎在思考接下来会发生什么；然后它落了下去——你听到的“啪”的一声，就是又一次宇宙大爆炸（Big Bang）。

那才叫酷炫的操作系统！如果真有这么个玩意儿在网上免费发布，全世界的黑客都会立马下载，然后熬夜捣鼓，胡乱拼凑出无数宇宙。大多数宇宙可能平淡无奇，但有些绝对惊艳绝伦。因为这些黑客的目标远不止于创造一个只有几颗恒星和几个星系的宇宙。任何一个普通黑客都能做到那种程度。不，真正能在互联网上声名鹊起的秘诀在于，精通命令行操作，让你的宇宙自发孕育出生命（Life）。一旦这种方法成为普遍知识，这些黑客就会继续前进，试图让他们的宇宙发展出合适的生命，试图找到某个物理常数小数点后第 N 位的一个变化，从而创造出一个地球，在这个地球上，比如说，希特勒最终被艺术学院录取，并最终成为一名拥有古怪政治观点的街头艺术家。

即便这种幻想成真，大多数用户（包括我自己，有时也会如此）也不愿意费心去学习那些晦涩难懂的命令，更不愿面对一次次失败的尝试；几个失败的宇宙就足以堆满你的地下室。当我们花了不少时间敲击命令行、按下回车键，生成一个个乏味又失败的宇宙之后，我们就会开始渴望一个截然相反的操作系统：一个无所不能的操作系统——一个能够替我们生活、替我们活下去的操作系统。在这个操作系统里，所有我们可能想要做的决定都会被聪明的程序员预先设想出来，并浓缩成一系列对话框。通过点击单选按钮，我们可以在互斥的选项（异性恋/同性恋）中做出选择。一列列的复选框可以让我们在生活中选择我们想要的东西（结婚/写一部伟大的美国小说），对于更复杂的选项，我们可以填写小文本框（女儿的数量：____ 儿子的数量：____）。

即使是这样的用户界面，用久了也会显得极其复杂，选项太多，选项之间又隐藏着许多交互。它几乎会变得难以管理——就像当年的“闪烁十二”问题重演一样。开发这款操作系统的开发者们不得不提供模板和向导，给我们一些默认的人生模式，作为设计自己人生的起点。这些默认模式很可能对大多数人来说已经相当不错了，至少足够好，以至于他们不愿轻易修改，生怕弄巧成拙。因此，经过几个版本的迭代，软件会变得更加简洁：启动后，屏幕上会弹出一个对话框，中间只有一个醒目的按钮，上面写着“开始人生”。点击按钮后，你的人生就正式开始了。如果出现任何问题，或者没有达到你的预期，你可以向微软的客户支持部门投诉。如果你接通电话时遇到的是客服人员，他/她会告诉你，你的生活其实挺好的，没有任何问题，而且下次升级后情况会好得多。但如果你坚持不懈，并表明你的用户级别为高级用户，你或许就能联系到真正的工程师。

当你解释了你的问题，并列举了生活中所有不满之处后，工程师会怎么说？他可能会告诉你，生活非常艰难复杂；任何界面都无法改变这一点；任何不这么认为的人都是傻瓜；如果你不喜欢别人替你做选择，那就应该开始自己做选择。
