# 导言（INTRODUCTION）

这是一部将显露出罕见无知的著作：若不盘点自尼采以来已被反复言说的一切，又怎敢只谈“尼采的思想（pensée de Nietzsche）”？这岂不是冒着踩进已被无数次踏过的旧辙、重提早被超越之问题的风险，从而在对近来那些细致注释的轻慢中——它们试图将一道命运自本世纪地平线不断发来的灼热闪电（éclairs de chaleur）解读为信号——暴露出一种疏忽，一种全然缺乏审慎的态度？

那么我们的旨趣究竟何在——倘若我们确有旨趣的话？不妨假定，我们写就了一部虚假的论著（fausse étude）。正因为我们读的是尼采的原文，听的是尼采说话，我们或许会让尼采对“我们自己”开口，并征用那种德语中曾凝成的最具渗透力、也最令人恼怒的散文里的低语、气息、暴怒与大笑的迸发？对于懂得倾听的人，尼采的言语获得一种愈发声色俱厉、力透纸背的效力，因为当代历史、事件与宇宙，正开始以或多或少的谵妄方式，回应尼采约八十年前提出的问题。尼采质问那近在咫尺或遥不可及的未来——这未来如今已成我们的日常现实——他预言它将痉挛不安，乃至在我们的痉挛本身中把他的思想漫画化；而尼采的这一质问，我们将试图理解它是在何种意义上描述了我们当下的生存。

我们绝不能忽略迄今为止在其思想研究中被遮蔽、甚或被默然略过的两个要点。其一是：这一思想在展开过程中逐步放弃纯粹思辨（spéculative）的场域，转而采纳——若不说是模拟——一场密谋（complot）的前奏。由此，它在我们这个时代成为一项默示控告的对象：控告状由马克思主义笺注学（exégèse marxiste）起草，它至少凸显了密谋的意图，因为一切源出资产阶级的个人思想都必然是一场阶级“共谋”。然而存在着一种尼采式密谋，它不属于某个阶级，而属于一个孤立个体（如萨德（Sade）那般），借用该阶级的手段所行之事，不仅反对他自身的阶级，也反对整个人类物种既有的诸种形式。

其二，与上述一点紧密相扣：当人们看到这套思想把一段亲历的事实（fait vécu）冥想至将其翻转为系统性的预谋（préméditation systématique），依凭一种诠释性谵妄（délire interprétatif）而相应削弱了“思想者的责任”时，人们便在某种意义上授予它“从轻情节（circonstances atténuantes）”——这比马克思主义的控告状更糟。因为人们想要减轻的是什么？是同一套思想如绕轴般运转于谵妄之上这一事实。然而尼采从一开始就在自身内部把握到这种倾向，他全部的努力在于抵抗混沌（Chaos）——恰即“裂口”（beance）——对他施加的那种不可抗拒的吸引力：自童年始，他便试图通过自传写作去填平并跨越这道裂罅（hiatus）。他越是探测思想现象及其衍生的诸种行为，越是研究现代世界结构所激发的个体反应——且始终参照他对古代世界的表象——他就越逼近这道裂口。**清醒的思想、谵妄与密谋，在尼采身上构成一个不可分割的整体（tout insoluble）**：这种不可分割性，从此成为衡量一切是否“牵动后果”的准绳。并非因为这思想牵涉谵妄便是“病态的”；而是正因其高度清醒，它才呈现出谵妄式诠释的面貌——一如现代世界中任何实验性创举所要求的那样。

随后由现代性来裁定这一创举是失败还是成功。但因为世界本身即被尼采的创举所牵动，现代世界越是放大其自身失败的威胁，尼采的思想便越是壮大。现代灾变总在或长或短的期限内，与一位“假先知”的“喜讯（joyeuse nouvelle）”混同。

那么，思想这一行动本身究竟是什么？这一猜疑在青年著作中暗中游走，并在《人性的，太人性的（Humain trop humain）》同期未刊片段、尤其在《快乐的科学（Gai Savoir）》的片段中愈发猛烈地显露。思想与行动中何者清醒、何者无意识——这一地下问题在外表上伪装为文化批判，并刻意以仍可被纳入其时代思辨与历史讨论的形式自我阐明。由此，尼采的思想以绝对同时的方式描述两种背反的运动：清醒（lucidité）这一概念，唯在“全然幽暗”持续被思及、因而被肯认的范围内才成立：

> 每一瞬间，混沌仍在我们精神中继续它的劳作：概念、意象、情感在其中偶然并置，杂乱地抛掷。以此生出了令精神惊异的毗邻关系：精神忆起相似者，于其中尝到滋味，依其技艺与学识保留并雕琢二者。——此处是世界上最后一小块碎片，某种新东西在此组合，至少就人类目力所及而言。而终究，这里仍关乎一种化学的新结合，它在世界的生成中确无先例。[^1]

一种思想唯靠下坠而上升，唯靠退行而前行——不可思议的螺旋（spirale），对其直觉性描述令人嫌恶，以至于人们小心避而不承认定：代代相继自身的运动正描画着它——宁可只附着于一种精神在随文化同行、沿历史升势上行时的攀升；余者，则把这一螺旋式思想的下降运动留给那些研究思想与生存机能之失败、残渣与废料的专家：按这种省事的劳动分工，他们几乎不必忧心清醒与幽暗间的张力；除非在那一日，二者借彼此发声，他们才注意到二者都带上了谵妄的腔调。

只想在尼采思想中辨出这腔调，乍看便等于求助于被这思想本身质疑的那些建制（instances）。要么这思想从一开始就因妄图攻击这些建制而谵妄；要么它在其明察中直接攻击了“清醒”这一概念本身？正因此，在它自身步履的每一处，它都被围限：

**内部**：

由语言（日常符号之符码）所依凭的同一性原则（principe d'identité）所限，而该原则服从于现实原则（principe de réalité）；

**外部**：

由既有的主管权威（哲学史家）所限，但同样且首要地由精神病学家——无意识的勘测者——所限，他们由此管控着“思考或行动之人”所应证之现实原则或宽或窄的幅度；

**最后**：

两侧皆受科学与实验所限，科学时而推远、时而拉近内外，从而移置界标并“矫正”内外之分野。

只要尼采的知解尊重这些在探究上各有畛域的球体，它似乎便服从两原则：服从现实原则，乃因它仅从历史角度描述现实、分析之以重组，从而把研究结果传达他人；服从同一性原则，乃因它作为施教者相对于所教内容自行划界。

一旦（体制语言为讲授现实所要求的）论证（démonstration）翻转而为宣言式脾性（humeur déclarative）之运动，且具传染性的脾性或灵魂音调（tonalité d'âme）压倒论证——此即尼采处同一性与现实原则的界限，它们本该向据信支撑其话语的建制负责：尼采在教学中引入了任何担保知识传递的权威（哲学）从未想到要教的东西；但尼采只是暗中引入，反之他的语言将交流所需法则推行至极端严厉：灵魂音调在成为思想之际，作为自身的探究展开，直至其术语在自身中重构成缄默（mutisme）：这思想向自身言说一处障碍，而施教意图从一开始便在此绊倒。

这障碍在其缄默中被感受为强度（intensité）与阻力，使施教这一意图本身受挫。而缄默中障碍的阻力，无非是同一性与现实建制所施的虚拟反应：内部的缄默只是外部的言说；思想对这外部言说的附议，无非是沉默脾性或音调的怨恨（ressentiment）。尼采的宣言把脾性之缄默抛回给思想，恰因思想感受到外部文化（即大学、学者、权威、政党、教士、医师之言）的阻力。

“教授尼采”通过把自身等同于这沉默的脾性障碍并对其进行思考，不仅摧毁了自己的身份，也摧毁了言说建制的身份：他随之取消它们在自身话语中的在场；随其在场一同消去的，是现实原则本身：他的宣言所及的外部，已被他缩减为自己脾性的沉默。

但是，在其宣言中被灭声的言说建制，从来不过是他的脾性之配置：灵魂音调的沉默强度，唯在外部仍有某种阻力（即文化）言说之际才被撑持。

文化——（知识之总和）——即施教与学习的意图——是灵魂音调及其强度的反面，它本身不可教亦不可学：然而文化越累积，越臣服于自身——而其反面即灵魂音调的沉默强度越增长。直至那惊扰施教的灵魂音调终于折断施教的意图：于是文化在撞上尼采话语之缄默时爆裂其奴性。

若教授尼采的临终之言（ultima verba）滑向失语（aphasie），医师将在其中看到现实原则对他们的确认：尼采越界了，他陷入矛盾（incohérence），不再说话，只嚎叫或沉默。

无人看见科学本身即是失语的。倘若它只道出自身并无根基，便无任何现实存续——它哪来的权力决定去计算：是它的决定发明了现实。它计算，是为不说话，免得跌回虚无。

[^1]:译者注：此处为克洛索夫斯基转述尼采笔记大意，原文未标精确出处；对应《尼采全集》后期笔记中关于“混沌在内心的劳作”一段的精神，非逐字引文。
