# 关于 About
Antikythera是一个研究与开发机构，致力于理解行星智能（planetary intelligence）的演化，并展望其通过计算系统实现规模化发展的前景。

Antikythera得名于已知最早的计算机——*安提基特拉机械装置（the antikythera mechanism）*，该装置是一种用于行星定位、导航、预测与规划的工具。此名称旨在启发对计算技术的探索，这些技术不仅能实现巨大的计算壮举，还能揭示并加速行星智能（planetary intelligence）的发展。

Antikythera是一个重新思考行星计算（planetary computation）的过去、现在与未来的思想流派，其产出横跨前瞻研究、思辨设计、情景推演以及可商业化的构想。它与学术界和产业界的合作伙伴联盟共同举办[工作室（Studios）](https://antikythera.org/studios)、[讲座（Lectures）](https://antikythera.org/events)、[沙龙（Salons）](https://antikythera.org/events)，并出版[书籍（Books）](https://antikythera.org/books)及举办展览。安提基特拉（Antikythera）的研究者与创新者网络覆盖设计、技术、哲学、工程、国际关系、社会科学、艺术及人文学科等多个领域。

Antikythera由技术哲学家[本杰明·布拉顿（Benjamin Bratton）](https://bratton.info/)领导。该机构的研究基于他开创性的工作，这些工作勾勒了计算（computation）如何演变为一个全球性系统，并成为行星智能（planetary intelligence）不可分割组成部分的轮廓。布拉顿（Bratton）的奠基性著作《堆栈：论软件与主权》（The Stack: On Software and Sovereignty）于2016年由麻省理工学院出版社（MIT Press）出版，书中描绘了计算基础设施（computational infrastructure）的新架构，并预先描述了行星计算（planetary computation）未来十年的发展。该书在多个学科与文化领域产生了广泛影响，其十周年纪念版将于明年出版。

Antikythera成立于2022年，是[伯格鲁恩研究院（Berggruen Institute）](https://berggruen.org/)孵化的一个项目。伯格鲁恩研究院是一个501(c)3非营利组织，在洛杉矶、北京和威尼斯设有办事处，并持续为Antikythera提供财务赞助和基础性支持。
