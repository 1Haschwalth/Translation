# 通过可扩展消息和在场协议整合通信和合并消息
>**[Martin A. Coleman](https://arxiv.org/search/cs?searchtype=author&query=Coleman,+M+A), [*Integrating Communications and Merging Messaging via the eXtensible Messaging and Presence Protocol*](https://doi.org/10.48550/arXiv.1309.5568)**
### 摘要
影响现代电子邮件使用的常见问题包括垃圾邮件、缺乏发件人验证、缺乏内置安全性和缺乏信息完整性。本文探讨了我们如何利用可扩展消息和在场协议（又称 XMPP）来取代电子邮件设施。我们将介绍几种方法，以便在对现有网络和电子邮件基础设施造成最小干扰的情况下，启动从 SMTP 电子邮件向依靠 XMPP 固有优势的过渡。我们研究了如何使用程序打开现有的 POP3/IMAP 账户，扫描可发送给 XMPP 网络用户的邮件，提取邮件，然后将其发送到 XMPP 用户的客户端。我们将展示该系统的实施和部署过程，并将麻烦和网络中断降到最低，从而证明 XMPP 是当今电子邮件可靠、快速的替代品。

**索引术语**：XMPP、电子邮件、即时消息、集成、网络、安全通信、过渡、Jabber。

## 1 导言 Introduction
随着日常交流变得越来越重要，人们越来越依赖于将自己的想法和话语清晰、快速、完整地表达出来。但是，任何噪音的引入都可能威胁到信息的完整性，事实上，它甚至可能完全破坏信息。因此，应该对信息采取一定的安全保护措施。

电子邮件是世界上最流行的通信方式，无论是个人信息还是商务信函。但是，它容易产生垃圾邮件，没有发件人验证，也没有收件人验证，你必须建立系统才能接收它们，更不用说它们可能会因网络问题而延迟。

优良保密协议（Pretty Good Privacy，P.G.P.）试图引入发件人和收件人验证和认证，但需要一定的技术知识，一般用户无法胜任，而且需要对双方进行配置才能起作用。域名服务（Domain Name Service，D.N.S.）备份和辅助邮件服务器及邮件队列的建立是为了弥补网络中断和分发问题。互联网信息访问协议（Internet Message Access Protocol，I.M.A.P.）的引入是对备份邮件系统的补充，这样信息就可以在任何地方和不同的客户端之间传递。这比另一种流行的系统，即邮局协议 3（Post Office Protocol 3，P.O.P. 3 or POP3）更为有效。

遗憾的是，即使在良好的运行条件下，上述设置仍然存在缺陷，仍然容易产生垃圾邮件。人们开始使用自动调整邮件过滤器的智能软件，但信息访问仍然是个问题，而且使用获取或 "拉取 "信息的客户端，而不是像短信服务（SMS，Short Message Service）那样将信息推送给他们，容易造成过多的数据使用。

可扩展消息和在场协议（eXtensible Message and Prescence Protocol，X.M.P.P.）引入了一个新的信息传输基础，解决了上述所有问题，并带来了许多其他有利于通信的巨大优势。

在本文中，我们将探讨 XMPP 在可靠和安全通信方面能为我们做些什么，如何以友好的方式向用户和现有网络基础设施介绍 XMPP，顺利部署 XMPP，然后探讨从我们现在使用的传统电子邮件系统全面过渡到未来完全由 XMPP 支持的通信骨干网的潜在可行途径。
## 2 评估 Evaluation
### 2.1 什么是 XMPP？ What Is XMPP?
可扩展消息和在场协议（XMPP）是面向消息系统的通信协议，基于可扩展标记语言（eXtensible Markup Language，XML）[^1]。它最初被称为 Jabber，是由一个开放源码社区开发的，为近乎实时的即时消息（instant messaging，IM）、联系人列表维护和存在信息提供了一个平台。考虑到灵活性和可扩展性，它已能为社交网络服务、智能电网设备、游戏、文件传输、VoIP 信号以及许多其他重要的日常常见实用应用提供信息和通知平台。

该系统的优势包括（但不限于）：
- 去中心化 - 任何人都可以运行自己的服务器。你甚至可以与其他人运行的服务器相互连接，创建一个庞大的 XMPP 服务器协作网络。
- 开放标准 - 任何人都可以创建客户端或服务器软件套件来使用它。不会受制于任何特定个人或公司的要求。只要遵循已发布的标准[2]，任何人都可以创建自己喜欢的任何类型的 XMPP 集成，而且免收版权费用。
- 历史 - XMPP 早在 1999 年就已出现[3]。客户端、服务器、附加组件等都有多种实现方式，而且从一开始就存在。
- 安全性 - 如果你想运行一个开放的网络供人们加入，服务器可以是公开的。您也可以为公司内部运行私有网络，以实现快速、有效和安全的网络。您还可以在同一配置中运行开放与公共、私有与封闭的混合网络。强大、安全的身份验证和信息加密是其核心功能之一，因此您可以放心，没有人会窃听您的谈话。
- 灵活 - 群组聊天、网络管理、文件共享、游戏、远程系统监控、云计算、VoIP 信号、身份服务、内容聚合，XMPP 可以实现的功能不胜枚举。

XMPP 的弱点很少，而且很有限，只需一句话就能描述：数据共享。由于需要双方同时同意交易，而且不能离线保存数据附件，因此目前通过 XMPP 发送大型数据传输的效率很低。不过，大多数人还是会使用电子邮件发送附件，或者使用 Dropbox、ownCloud、netMist 等网络文件共享设施，甚至在不确定对方是否在线的情况下使用普通 FTP 发送较大文件。

除此之外，它还提供了其他巨大而实用的好处。如果 XMPP 要像本文所建议的那样取代电子邮件，那么除了上述任何显而易见的细节之外，它还能提供什么？它究竟如何才能与当今通用的电子邮件标准相匹配，并在此基础上进行扩展？

反垃圾邮件。XMPP 将有助于打击垃圾邮件，也就是未经请求的商业电子邮件。未经你的许可和事先同意，任何人都不能向你发送/接收邮件。垃圾邮件无处遁形。实际上，比这更好的是，它根本不会被发送。

内置地址簿。你之前同意接收信息的每一个人都已经在你的通讯录中，因此你可以一目了然地知道谁拥有你的信息并有能力向你发送信息。有人可以发送授权请求，要求添加到你的地址簿（或 XMPP 所称的 "花名册(Roster)"[4]）中，但你可以忽略它，或查看是谁发送的，然后在对方完全不知情的情况下将其删除。

推送电子邮件。人们喜欢 Blackberry 就是因为它，XMPP 也内置了这一功能。你不需要请求发送邮件，它们已经在那里了。对于目前的电子邮件系统（如邮局协议 (POP3)），你需要指定一段时间，然后客户端会重新检查是否有新邮件。IMAP 通过保持与服务器的开放连接，让你离这一目标更近一步，但它会在数据稀缺的地方（如 3G 和 GSM 移动数据系统）占用数据。为了方便起见，XMPP 将把信息发送到你的客户端和/或设备，而你根本不需要做任何事情。发件人按下发送键，你的收件箱和/或客户端就会立即收到信息。

内置安全性[5]。SMTP 是一种未经验证的协议：使用该基本协议，你无法保证发送者的身份，也无法保证接收者的身份。任何电子邮件都可以在未经验证的情况下假装和/或让人以为是由任何人发送的。优良保密协议（PGP）是提供用户和收件人验证的一个重要步骤，但该协议在设计时并没有考虑到这一点，因此它不是任何客户端或系统的默认功能。

从 POP3/IMAP 到 XMPP 的翻译器/转换器使过渡到基于 XMPP 的网络变得非常容易和有效。使用每个人都能访问的当前通用协议，并将其自动复制到更新、更快、更安全的网络上，不仅非常有效、实用，而且非常有用，这正是我们本文所要深入探讨的。

离线信息[6]。这是真正有助于宣传 XMPP 优点的同等功能。上述优点都强调了 "始终连接 "客户端的功能。但是，如果你突然失去了与 XMPP 服务器的连接，有人向你发送了一条信息，服务器会为你保留这条信息，直到看到你重新连接并重新上线。

各种客户端。就像电子邮件一样，无论你是想运行桌面客户端还是通过网络浏览器访问客户端（如网络邮件服务提供的客户端），XMPP 都能为你提供这种功能。从台式机、网络、平板电脑、智能手机到冰箱和烤面包机，都可以访问 XMPP。

既然我们已经知道了什么是 XMPP，以及为什么它对本文和整合通信如此重要，那么我们就来看看将协议整合到现有网络和新网络中的一些可选方案，然后我们就可以立即开始广泛部署 XMPP 了。
## 3 探索一些选择
要将通信合并到基于 XMPP 的基础上，该协议和相关系统必须首先获得认可，从而实现普遍使用。这可以通过设置网络应用程序（如即时通讯工具）来实现，先展示协议的优势，然后再在此基础上进一步发展。这样，他们就能看到它的工作原理，并对它感到满意。

这将不可避免地引出电子邮件的问题，以及在使用电子邮件的同时使用 XMPP，或通过 XMPP 获取电子邮件信息，直到所有共同通信者也都在 XMPP 网络上。让所有人都使用 XMPP 将是一个令人钦佩的目标，事实上，这也是本文和其他一些文章希望激励网络管理员努力实现的目标，但就目前而言，将现有工具集成到新的拟议系统中或与之并行使用，将有望最大限度地提高用户接受的机会。

实现这一目标的各种方法如下
- POP3/IMAP 转 XMPP 账户检查器。
- POP3/IMAP 转 XMPP 处理器
- SMTP 转 XMPP 集成服务器
- 以及从上述 3 种方案衍生出的其他一些方案。
