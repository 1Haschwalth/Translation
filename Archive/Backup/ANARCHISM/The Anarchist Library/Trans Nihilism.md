# 跨虚无主义
>n1x, [Trans Nihilism](https://theanarchistlibrary.org/library/n1x-trans-nihilism). 2017/9/23

与许多其他事物一样，在跨性别社群中常有一种说法：当一个人意识到自己是跨性别者时，会经历不同的阶段。他们会质疑自己是否真的是跨性别者，抑或“这只不过是一种癖好”；他们会写诗；他们会加入各种各样的跨性别社群。在后者中，涌现出大量网络模因（meme）——例如“女阴茎（girldick）”、“雌激素（E-estrogen）”、“杀死所有顺性别者（Kill All Cis People）”等。所有这些都带有强烈的社群化色彩（尽管并非毫无道理；跨性别者需要团结），但传达的主要信息是积极的跨性别态度。然而，一个更为黑暗的真相——一个必然的事实——却被忽视和隐匿了。

让我们回到最基本的概念：跨性别（transgender），从定义上来说，意味着不认同出生时被指派的性别。在许多情况下——尽管并非所有情况，也并非必然——这需要通过医疗干预来解决。跨性别本身蕴含了一种动态变化，一种向另一种状态的转变。“跨性别”一词一方面可能代表着可能性；另一方面，它也可能代表着对不可能之事的追求，代表着一种处于“过渡”状态却可能永远无法真正“完成转变”的状态。

无论跨性别者是否能“过关”（pass），是否接受了性别肯定手术（sex reassignment surgery），无论他们如何竭力跨越二元性别的框架[^1]，成为一名跨性别者始终意味着过着双重生活，一种充满矛盾的生活。一方面是女性[^2]，另一方面是跨性别者；取决于他们选择戴上哪一副面具。他们或许能“过关”，但维持另一身份所需的激素（hormones）及其他措施，却不断地提醒着他们跨性别者的身份。跨性别者的存在永远无法完全实现，而始终处于一种**过渡**状态。

无论你如何看待，成为跨性别者都需要付出努力。这并不是一个永远无法完成的过程，但对许多人而言，他们可能永远也无法真正接近他们心目中那个人的影子。对许多人来说，所有的努力都因无法摆脱生理身体的束缚而付诸东流。宽阔的肩膀、狭窄的臀部、萎缩的阴茎——所有这些本就难以面对的问题，都因社会对待那些“没有过关”的跨性别者的方式而变得更加难以承受。戴着面具、隐藏自我固然糟糕，但时刻面临暴力威胁则更甚。有些人走得比别人更远。

无需引用大量统计数据来证明跨性别女性遭受暴力的比例有多高，也无需对那些跨性别者每天不得不面对的、来自媒体或身边人的各种恐跨（transphobic）言论[^3]进行任何批判性分析。无需证明我们被彻底去人化（dehumanized）了。不，成为一名跨性别者或许本身就与“人”（human）的真正含义背道而驰：相信自己就是你本应成为的那个人。

大多数人都沉浸在这种舒适的错觉中，而意识到自己不过是一具肉身傀儡（meat puppet）则着实令人恐惧。但对跨性别女性而言，前方是一道巨大的深渊，她那过于人性化（human）的自我身份认同感（self-identity）被剥夺，并在彼岸短暂地以美丽的形象重现。然而，无论她如何努力，也只能到达某个临界点。无论她飞得多远，逆风始终不会停息，她将悬停在深渊之上，直到精疲力竭或被吞噬。我们多么渴望拥有那双能带我们飞跃深渊、让我们成为真正自己的翅膀。

这就是跨性别虚无主义（trans nihilism）的定义：去他妈的跨性别积极主义（trans positivity），回归我们真正的家园。我们的王国，我们的天赋权利，我们的诅咒。
[^1]:如果他们确实是二元性别的跨性别者（binary trans）的话。
[^2]:为了简化讨论，这里以我为例，因为我是一名跨性别女性（trans woman）。
[^3]:拼写检查器将“transphobic”标记为一个不存在的词。真是讽刺。
