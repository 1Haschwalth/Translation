# 欲望革命<br>Desirevolution<br>Jean-François Lyotard<br>1973
## 文本零 TEXT 0 
1968年7月余烬中的文字。根据编辑同一血肉之躯的拼贴不尽相同大约二十多块版画中的一个卷宗文字也被混杂其中由于色彩这似乎是一个过于昂贵的项目拼贴今天被毁我们将提出一个不带色灰的不同编辑在那里等待着一只革命不死鸟仍然太昂贵碎片和一口气仍然存在。
## 文本一 TEXT 1
现实被梦见,这就是我们暴力的本质幻想的理论吓坏了每个人甚至我们自己人们像揉眼睛一样冲向投票站我梦到的东西很愚蠢公鸡打鸣了但欲望不是待售品你也逃脱不了它的接近所带来的痛苦这粗鲁地通过一张写有赞助人名字的纸条塞进系统无唇的嘴里来确认权力我们想让眼睛保持睁开注视着幻象要摆脱异化,不是安排一场井然有序合作愉快的辩证法讨论也不是被诠释学的绳索吊死更不是仅仅坐下来写作更不是只是扔砖头这将意味着站在欲望这一边这一边是不朽的它已经是胜利者永远都是不死鸟我们只需要认识到而不是组织它它存在于一切话语中甚至存在于它的形式中存在于意义之中即使在符号化中也存在我们为美而奋斗这是第一次历史革命的开始我们不是被危机和需求所迫运动是由一种呼唤而生的你永远无法用范畴从背后攫取它我们什么也失去不了我们永远也失去不了除了我们的作品。
## 文本二 TEXT 2
形式本身就适合表达革命的运动形式就是革命现代社会无论东方还是西方都是一个用钨碳化物包裹的胃这是一个非常昂贵的胃在那里话语和形象都在耗尽化为尘埃最终加强了它们声称要侵蚀的那堵墙你想表达的是系统和肤浅需求之外的东西正是这些东西毁坏了欲望这最后一个启发了你尽管这是另一个人的视野但不胃让你的话语你的图像物品和身份都成为商品批评和仇恨甚至也被纳入其中梦想用来销售可消费的拜物教物品一切都在服务一切都在服务于解除欲望消散它的他性用建设性的积极的东西来消除它把它转移到令人安慰的词语和事物中很长一段时间以来阶级敌人不仅控制着社会统治的手段而且也控制着与我们自己同时产生的用来保护自己免受欲望侵害的最古老的装置压制在这个被俘获的区域产生作用在欲望的源泉。

拼贴的暴力用自己的手段对抗压制剪刀般的审查反过来对抗它们的功能用于销售一切的杂志图像以性感的魅力为诱饵我们的刀片切断了它的幻想气氛现在场景已经设置好了多形性的无害欲望暴露并炫耀着自己消费社会是它神经质的负面制度诱惑的结束禁忌和供奉的模糊分区被暗示的淫秽场景作为每一个冰箱买家的额外奖励欲望在异化的碎片上打桩。

通过分离一个想要的命令所表达和强加的东西并通过移位和压缩看似无关的元素拼贴作品执行了梦的工作在这组操作中解构给定的坐标越过常规间隔违反禁忌欲望表现为运动和力量压碎权力和意义就像在梦的工作中一样编辑已经切入了外表拼贴产生的图像显示了形象化的颠覆而这种颠覆是首要的被撕裂重新组装成一种句法混乱的奥菲斯身体的幻象这就是意义在符号化中的秩序原始形式暴露出来。
## 文本三 TEXT 3
眼睛不是单一感官的器官它是所有感官及其意义的器官眼睛是垂直距离的主宰正是在这个基础上世界才得以存在这种深度是形式的秘密没有眼睛形象将失去基础正反面将不复存在女性将无从向男性隐瞒秘密言语也无法掩盖沉默这里与那里之间的距离是缺失的最古老存在欲望从中汲取一半的规则和一半的放纵眼睛是越界者它能看见背后看见那些它所看不见的东西以这种方式欲望进入镜子并颠覆它以便看见世界存在是为了被颠覆从而不再存在。

眼睛在移动中才能看见运动是它的状态对某物施加影响就是以全速沿着隐藏的角度和蜘蛛网的边缘移动这些角度和蜘蛛网将事物悬挂在其周围并通过跨越直线和曲线使其在其他事物中获得一致性就像佛罗伦萨的圆顶朝向周围的山丘一样眼睛的过渡沐浴在连续性的优雅中在对立的极点一切皆有可能野蛮的变形女人树卵石逆向太阳中的星星山脉轮廓飞鱼的腿恳请分析家们不要忘记如果没有连续性提供的法则想象本身将是不可能的而这法则正是他们所有注意力所聚焦的图像形成的物质条件眼睛 = 他者 + 连续性。

即使在所谓的话语中也有东西可以被看见话语的形式不是它的意义的属性不是源于语言框架而是通过分解-记忆来产生意义意义来自于违反话语它是力量或姿态存在于意义的领域中它是沉默的在被压抑的话语中它的地下室被唤醒并出现语言秩序的动员在其中开辟了塑性空间另一个秩序可以悄然地固定在其中表达是话语中的眼睛是耳朵中的眼睛。

但通过拼贴这种眼睛的工作也显现出来切割回忆看到所见的操作因此,任何与图像的斜向认同都是不可能的通过看它你看到了看见权力不能再玩弄你的幻想力量了你必须认识到这一点这种认识使你摆脱了系统滑过你眼皮的卑鄙抚摸从而使你的眼睛闭上。
## 文本四 TEXT 4
