《#Accelerate》构建了加速主义的谱系，既追溯其早期预兆，又呈现新论述——这些新论述记录了新型加速主义的兴起：它们既能抵御资本主义现实主义的冲击，又为21世纪重新武装。

加速主义是当代政治异端学说之名：其主张认为，应对资本主义的唯一激进政治策略并非抗议、破坏、批判或挪用，而是加速并加剧其拔根、异化、解码与抽象化的内在倾向。

《#Accelerate》追溯加速主义谱系，从90年代英国暗黑网络文化、尼克·兰德、萨迪·普兰特、伊恩·格兰特（Nick Land, Sadie Plant, Iain Grant）及CCRU的理论虚构，溯及80年代文化地下场域（锐舞、迷幻浩室、科幻电影(rave, acid house, SF cinema)），最终追溯至68年后狂热思潮的源头。这些文本中灼热的虚无主义享乐主义，后来被其作者及马克思主义与学术权威共同否认。

在核心章节的两侧，本书收录了马克思揭示其"普罗米修斯主义（Prometheanism）"的文本，以及近年关键著作——这些作品记录了新型加速主义的非凡崛起：它们既抵御着新自由主义资本主义现实主义的冲击，又为二十一世纪重铸武器。

在围绕这个充满争议的术语展开的当代激辩中，《#Accelerate》引领着关于未来性、技术、政治、享乐与资本的历史性对话。这既是矛盾丛生的思想遗产，亦因当代"理性"政治选择的匮乏而被赋予紧迫的现实意义。
