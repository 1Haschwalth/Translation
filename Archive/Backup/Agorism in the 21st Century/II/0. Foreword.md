# 前言 Foreword

但丁的《神曲》（*The Divine Comedy*）通常因其对地狱（Inferno）的描绘而被阅读，但夹在中间的却是穿越炼狱（Purgatory）的旅程。在炼狱入口处，一位守护天使在但丁的前额刻上了字母P（peccatum / 罪），一共七次，代表七宗死罪。随着他们向上行进，每去除一桩罪，灵魂便满足了进入天堂（Paradise）的必要条件。

傲慢、嫉妒、愤怒、懒惰、色欲、贪婪、暴食。加密的灵魂短期内不太可能进入天堂，但幸运的是，炼狱中尚存希望，这与地狱不同。它需要付出努力、进行反思和时间，但从炼狱出发，依然可以抵达天堂。救赎的共同主线在于对罪的*认识*。我们能否到达第二层？

在本刊，即第二期中，我们邀请读者聚焦于加密世界通过太阳朋克（solarpunk）和月亮朋克（lunarpunk）实践所实现的救赎，并将其夹在两篇关于加密世界与死亡关系的沉思之间——一种最大可提取的铭记终将逝去（Maximum Extractable Memento Mori）。我们将救赎之路视为涉及反经济实践（counter-economic practice）在其所有形式——密码朋克（cypherpunk）、太阳朋克、月亮朋克——中的加速与升级。自由意志，这是我们自己的选择。要么助长腐败，要么超越它。

当但丁踏入天堂时，他发现第一层是月球（Moon）。月球与不恒定性相关联，代表着那些出于某种原因背弃了自己誓言的人，他们虽缺乏一些、但绝非全部的坚韧。出于恩典，上帝将他们评定为满怀最良善之意，却在最后的关头跌倒。你看，对于那些仍在局中之人，始终存在着做出正确抉择的机会。

我们仍在局中。
