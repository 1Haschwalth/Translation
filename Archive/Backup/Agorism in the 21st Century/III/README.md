### III<br>2023

我们的第三期审视了网络国家（network states）和技术前沿（technological frontiers）作为通往自由（freedom）的路径，探讨了超越民族国家（nation-state）的、挑战传统政治结构（political structures）的去中心化治理（decentralized governance）、海洋主权（oceanic sovereignty）以及相互竞争的意识形态愿景（ideological visions）。
